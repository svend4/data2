# Единая теория движения и «Тотальная Система Боя» (`data2`)

## Назначение проекта

Репозиторий `data2` содержит масштабный документально-исследовательский корпус по авторской концепции **Единой Теории Движения (ЕТД)** и 12 архетипов движения, построенный на базе «Тотальной Системы Боя» (ТСБ) В. В. Крюкова и материалов В. Зелендинова («Единый язык фехтования»). Материалы охватывают анализ биомеханики и кинематики, междисциплинарные приложения (робототехника, алгоритмы, ИИ, медицина, педагогика, математика и физика), тренировочные планы и протоколы сессий, а также алгоритм деформированной восьмёрки (`scarab_algorithm.py`).

---

## Архитектура и основные компоненты

### 1. Индексы и серия исследовательских томов (`VOLUME_01_*.md` – `VOLUME_310_*.md`)
- **`SERIES_INDEX.md` (Серия I, тома 1–20):** формулировка 12 архетипов движения (*Петля, Три Сферы МВС/СВС/БВС, ОБД / Мастер-Шаблон, Камуфляж/Угроза, Система Окон, Закон Нечётности, Закон Чёрного Ящика, Режимы, Звери-ОС, Пять Уровней, Закон Памяти, Дистанция-Сложность*), 7 аксиом Манифеста, метрика замкнутости петли `LCI` (`S_enclosed / S_bounding_box`) и условие резонанса сфер (`ω_МВС = ω_СВС = ω_БВС`).
- **`SERIES_II_INDEX.md` (Серия II, тома 21–40):** прикладное применение ЕТД к клинической медицине, спорту, городскому планированию, праву, климатологии, биотехнологиям, энергетике, криптографии, материаловедению, аэрокосмическим и гуманитарным дисциплинам.
- **Последующие серии и синтезы (тома 41–310):** расширение концепции до четвёртой сферы (ЧВС — пространство инструмента/рабочей задачи в `VOLUME_100_Fourth_Sphere_ETD_Robotics.md`, объединяющей кинематику тела по Крюкову и инструмента по Сенчукову/Зелендинову), серия математических и физических обобщений и сводные синтез-тома вплоть до `VOLUME_310_NineteenthSynthesis.md` (Серия XI, «Высшие структуры ЕТД», доказательства #113–#122).
- Отдельные планы серий: `VOLUME_05_Ten_Dissertations_Plan.md`, `VOLUME_06_to_10_Next_Books_Plan.md`.

### 2. Первоисточники и справочные документы
- `totalnaya_sistema_boya.pdf` — книга В. В. Крюкова «Тотальная Система Боя».
- `2cb3bf_61b7a782b1794b6a800f7e0e4dbb1714.pdf` — вспомогательный PDF-материал.
- Материалы В. Зелендинова «Единый язык фехтования. Введение в фехтование. Понятийный аппарат» в форматах `.rtf`, `.txt`, `.html.zip` и `.txt.zip` (анализируются также в `VOLUME_98_Zelendinov_Fencing_ETD.md`).

### 3. Тренировочные планы и протоколы сессий
- `TSB_Annual_Training_Plan.md` — реконструкция годового плана тренировок ТСБ по формуле `Тренировка n = nA (Линейный бой) + nB (Спецусловия) + nC (ОФП/ОБД)`, с 3 курсами, 5 режимами мобильности и разбивкой по 4 кварталам.
- `training_session_L2.txt` и `training_session_dual_L3.txt` — текстовые планы 45-минутных тренировочных сессий (разминка с 6-битными позициями `G1/G2/G3` и режимами ЧВС, переходы между парами, 5-тактовые ката с ASCII-диаграммами, импровизация с лимитом 3.0 с и заминка).

### 4. Алгоритмические материалы
- `scarab_algorithm.py` (~2.56 МБ) и `SESSION_Deformed_Figure8_Scarab_Algorithm.md` (~1.12 МБ) — исходный код на Python и документация сессии по алгоритму деформированной восьмёрки («Scarab Algorithm»).

## Установка и запуск

Репозиторий представляет собой архив текстов, схем и материалов:

```bash
git clone https://github.com/svend4/data2.git
cd data2
```

- Для ознакомления с серией откройте указатели [SERIES_INDEX.md](SERIES_INDEX.md) и [SERIES_II_INDEX.md](SERIES_II_INDEX.md), а также [TSB_Annual_Training_Plan.md](TSB_Annual_Training_Plan.md).
- Скрипт `scarab_algorithm.py` поставляется без файла зависимостей и инструкций запуска в корне.
