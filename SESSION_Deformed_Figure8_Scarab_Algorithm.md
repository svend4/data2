## Часть 1: Размерностная Иерархия Циклов (РИЦ)

### 1.1 Четыре силы = четыре размерности

Центральный тезис: четыре фундаментальные силы соответствуют четырём пространственным размерностям, что объясняет невозможность их объединения сложением (нельзя складывать величины разной размерности).

```
Элемент    Размерность    Состояние     Сезон     Сила
─────────────────────────────────────────────────────────
Земля         3D          Твёрдое       Зима      Гравитация
Вода          2D          Жидкое        Весна     Слабое
Воздух        1D          Газ           Осень     ЭМ
Огонь         0D          Плазма        Лето      Сильное
```

### 1.2 Принцип «семья, а не слияние»

Объединение четырёх сил — не через сложение (каша), а через произведение (семья):

- **Копроизведение** (сумма): A ⊔ B = «каша» — стандартный подход физики, 50 лет неудач
- **Произведение**: A × B = «семья» — оба сохраняют идентичность
- **Тензорное произведение**: A ⊗ B = «ребёнок» — новое качество

Аналогия: муж и жена не складываются в одно тело (гермафродит). Они образуют семью — единицу, состоящую из различий.

### 1.3 Обратная пропорциональность

Все четыре элемента связаны обратно пропорционально: больше одного — меньше других. Как рычажные весы. Сумма постоянна:

```
МВС + СВС + БВС + ЧВС = π = const
```

## Часть 2: Деформируемая X-диаграмма

### 2.1 X вместо +

Крест (+) предполагает фиксированные оси и равные пропорции. Буква X:
- Деформируется (разные пропорции для разных климатов/контекстов)
- Не имеет привилегированных осей
- Вращается под любым углом

### 2.2 Монотонная последовательность размерностей

Поправка: переход между размерностями **монотонный**, без скачков:

```
Зима → Лето (нагревание):    3 → 2 → 1 → 0  (плавное убывание)
Лето → Зима (остывание):     0 → 1 → 2 → 3  (плавное возрастание)
```

Асимметрия: скорость нагрева ≠ скорость остывания (тепловая инерция).

### 2.3 Климатическая поправка (4×4 = 16 подэлементов)

Базовое соответствие «сезон ↔ элемент» — функция от географии:
- Китай (муссонный): Зима = Вода (дожди, тайфуны)
- Россия (континентальный): Зима = Земля (лёд, снег)

Каждый регион имеет **доминанту**, а внутри неё — четыре сезонных варианта:

```
Состояние = Доминанта ⊗ Сезон

16 клеток = «Вода Земли» ≠ «Вода Воды»
```

### 2.4 Пентаграмма и гексаграмма

```
4 элемента = неживая природа (квадрат)
5 элементов = один человек (пентаграмма) = 4 + 1 участник
6 элементов = два человека (гексаграмма) = 4 + 2 участника
```

Шестой элемент — пространство взаимодействия. 6 элементов → 6 цветов → звезда Давида → шестигранная гайка (плотнейшая упаковка на плоскости).

### 3.2 Дьядическое дерево 2^n

```
Уровень 0:  1   = Единство (Тайцзи)
Уровень 1:  2   = Полярность (Инь/Ян)
Уровень 2:  4   = Элементы
Уровень 3:  8   = Роза ветров / Триграммы

Уровень 5:  32  = Суточные циклы

Σ = 127 = 2⁷ − 1 (число Мерсенна, простое)
```

4 царства × 16 подтипов = 64 (произведение, не сумма).

## Часть 4: Деформированная восьмёрка Крюкова

### 4.1 Два запрета

```
ЗАПРЕТ 1 (Антипрямая): Нельзя всё время по прямой → упрёшься в преграду
ЗАПРЕТ 2 (Антикруг): Нельзя всё время по кругу → обойдёшь квартал, вернёшься к себе
```

Единственное решение: кривая с переменным знаком кривизны = восьмёрка (∞).

### 4.2 Математическая формула

Базовая фигура Лиссажу (из Тома 1 ЕТД):
```
x(t) = A · sin(ωt)
y(t) = B · sin(2ωt + π/2)
```

Деформированная восьмёрка с параметром асимметрии k:
```
x(t) = A · sin(ωt)
y(t) = B · [sin(2ωt + π/2) + (k−1)/(k+1) · sin(ωt)]

k = R_большая / R_малая

k = 1:    симметричная ∞
k = 10:   «неваляшка» (одна петля 1 м, другая 10 см)
k → ∞:    почти круг
```

### 4.3 Аналогия с полётом насекомого

Насекомые не машут крыльями — они ими плавают. Крыло описывает восьмёрку в воздухе. Каждый полуцикл рабочий. Нет холостого хода — закон петли Крюкова.

Три уровня вложенных восьмёрок:
- БВС: общая траектория полёта (перемещение)
- СВС: колебания тела (уклонения, развороты)
- МВС: вращение крыла/кисти (удары, захваты)

### 4.4 Пропорции восьмёрок в связках

```
Связка          Пропорция a:b:c    Вид             Уровень
Базовая         1 : 1 : 1          Симметричная     1
Атакующая       3 : 1 : 1          Неваляшка →      2
Защитная        1 : 3 : 1          Неваляшка ←      2
Обманная        5 : 1 : 3          Рывок + финт     3
Мастерская      1 : 1 : 0          Чистая ∞         5

a = размер большой петли
b = размер малой петли
c = размер микровосьмёрки перехода
```

## Часть 5: Алгоритм Скарабея (управляемый хаос)

### 5.1 Правила

```
Правило 1 (Антикруг):
  Если знак кривизны не менялся 4 шага → принудительный разворот

Правило 2 (Антипрямая):
  Если кривизна ≈ 0 последние 3 шага → принудительный поворот на π/4

Правило 3 (Нечётность):
  Длина серии одинаковых поворотов ∈ {1, 3, 5, 7}

Правило 4 (Восьмёрка):
  После серии n поворотов влево → серия m поворотов вправо,
  где m/n = k (параметр деформации)
```

### 5.2 Уравнение Скарабея

```
r(t) = Σᵢ Aᵢ · ∞(ωᵢt, kᵢ, φᵢ)

где ∞(ωt, k, φ) = [sin(ωt), sin(2ωt+φ) + (k-1)/(k+1)·sin(ωt)]

i ∈ {1, 2, 3} — три уровня (МВС, СВС, БВС)

A₁ = 5–15 см   (МВС)
A₂ = 30–40 см  (СВС)
A₃ = 80–200 см (БВС)

Резонанс: ω₁ = ω₂ = ω₃ при мастерстве
```

### 5.3 Псевдокод

```
функция скарабей(пространство, k=1, шаги=100):
    позиция = центр(пространство)
    угол = 0
    серия = 0
    направление = +1

    для каждого шага:
        Δθ = направление · π/4
        серия += 1

        если серия ∈ {1, 3, 5, 7}:
            с вероятностью P(серия):
                направление = −направление
                серия = 0

        если серия ≥ 4:
            направление = −направление
            серия = 0

        если близко_к_границе(позиция):
            Δθ += π/4 · от_границы

        угол += Δθ
        позиция += шаг · (cos(угол), sin(угол))

    вернуть траектория
```

## Часть 6: Комбинаторика двух рук

### 6.1 Данные из Крюкова

- 7 групп техник, 20 техник всего
- 2 состояния руки: угроза / камуфляж

### 6.2 Подсчёт

```
1-тактные:   100 пар «удар + блок» × 2 стороны = 200
2-тактные:   ~600 (с учётом ограничений)
3-тактные:   ~1800 (оптимум по Крюкову)
```

### 6.3 Степени свободы (спичечная модель)

```

Дискретизация:
  Грубая (3 значения/сустав): 27² − ~100 = ~630 положений
  Средняя (5):                 125² − ~2000 = ~13600
  Тонкая (7):                  343² − ~15000 = ~102000
```

### 6.4 Группировка по закону Миллера

630 положений → 7 групп по ~90 = 7 групп техник Крюкова.

## Часть 8: SWOT-анализ модели

### Сильные стороны
- Физическая обоснованность размерностной иерархии (фазовые переходы)
- Два запрета (антикруг + антипрямая) фальсифицируемы
- Восьмёрка как единственное решение — математически строго
- Полёт насекомых подтверждает (Ellington 1984, Dickinson 1999)
- Комбинаторика 7 групп × 3 суставов согласуется с данными Крюкова
- Полная совместимость с аксиомами ЕТД А₁–А₇

### Слабые стороны
- Соответствие «гравитация = земля = 3D» — аналогия, не вывод
- 4+8+16+32 = 60 ≠ 64 (решается через произведение 4×16=64)
- Риск апофении (8 найдётся везде, если искать)
- Нет количественных предсказаний
- Параметр k нужно калибровать на реальных движениях

### Возможности
- Формализация через вейвлет-анализ
- Проверка через фрактальную размерность Хаусдорфа сезонных структур
- Мост к теории фазовых переходов Ландау
- Приложения: робототехника, компьютерные игры, оздоровительная гимнастика

### Угрозы
- Конфликт с китайской 5-элементной системой (решается: 5 = 4+1 участник)
- Масштабирование может не работать бесконечно
- Без эксперимента — только философия

## Часть 9: Четвёртая сфера — ЧВС (пальцы)

### 9.1 Иерархия четырёх сфер

```
Сфера   Часть тела    Размер         Элемент   D    Функция
──────────────────────────────────────────────────────────────
БВС     Плечо         80–200 см      Земля     3D   Стратегия (направление)
СВС     Предплечье    30–40 см       Вода      2D   Тактика (приём)
МВС     Кисть         10–15 см       Воздух    1D   Техника (исполнение)
ЧВС     Пальцы        1–5 см         Огонь     0D   Микрокоррекция (переключение)
```

### 9.2 ЧВС как коробка передач

На высокой скорости БВС/СВС/МВС уже заданы. Изменить действие в последний момент могут только пальцы:
- Сжать = удар кулаком
- Раскрыть = блок ладонью
- Направить = тычок пальцами
- Расслабить = захват

Для алгоритмов: ЧВС = ветвление if/else внутри итерации цикла.

### 9.3 Временные масштабы

```
БВС = выбор алгоритма      (~секунды)
СВС = выбор параметров      (~100 мс)
МВС = итерация цикла        (~50 мс)
ЧВС = микрокоррекция        (~10 мс)
```

## Часть 10: Алфавит Движений (76 символов)

### 10.1 Описание

Источник: рукописная таблица на клетчатой бумаге (Alphavit_Big_76.JPG).

Каждый символ — квадрат (пространство перед телом), внутри которого линии
обозначают положения рук. 76 символов = все физически реализуемые двумя руками
комбинации линий в квадрате.

### 10.2 Строительные блоки

Квадрат содержит:
- 4 стороны (верх, низ, лево, право)
- 2 диагонали (╲ и ╱)
- 4 полудиагонали из центра
- = 10 базовых линий

### 10.3 Математическая модель

Квадрат с диагоналями = полный граф K₄ на 4 вершинах:
- 4 вершины (углы), 6 рёбер (4 стороны + 2 диагонали)
- 2⁶ = 64 комбинации рёбер (= гексаграммы = кодоны ДНК)
- 76 = 64 + 12 полулиний = полный алфавит

### 10.4 Прогрессия первой строки

```
0 линий: точка (исходная позиция)
1 линия: одна рука в одном положении (8 вариантов)
2 линии: две руки (основной массив, 28 вариантов)
3 линии: сложные формы
4+ линий: рамки и полные защиты
```

### 10.5 Соответствие 7 группам Крюкова

```
Группа 1 (мягкая):    одиночные мягкие углы (╲, ╱, └, ┘)
Группа 2 (жёсткая):   горизонтали, вертикали (─, │, ┼)
Группа 3 (МВС):       короткие полудиагонали из центра
Группа 4 (вращение):  X, круговые элементы
Группа 5 (оружие):    длинные диагонали
Группа 6 (мастер):    сложные K, M, N-формы
Группа 7 (пик):       замкнутые □, ☒
```

### 10.6 ЧВС-модификаторы

Каждый из 76 символов может иметь 4 варианта пальцев:
- Кулак (удар)
- Ладонь (блок)
- Пальцы направлены (тычок)
- Расслаблены (захват)

76 × 4 = 304 ≈ 310 (число томов ЕТД).

## Часть 11: Спичечный автомат на основе алфавита

### 11.1 Граф переходов

- 76 состояний (символов)
- Каждое связано с ~10-15 соседями (отличие на 1-2 линии)
- ~500 рёбер в графе
- Диаметр графа: ~7 шагов (закон Миллера)

### 11.2 Формальная грамматика

```
БУКВЫ = 76 символов (отдельные положения)
СЛОГИ = 2-буквенные переходы (~200 вариантов)
СЛОВА = 3-буквенные связки (~1800, оптимум по Крюкову)
ФРАЗЫ = слово + микропереход + слово (восьмёрка)
ТЕКСТ = бой (свободная импровизация)
```

### 11.3 Правила перехода

1. За один такт: изменение ≤ 2 линий
2. Антикруг: нельзя вернуться за < 4 шагов
3. Антипрямая: нельзя > 3 одинаковых переходов подряд
4. Нечётность: серии длиной 1, 3, 5 или 7
5. Камуфляж/угроза: H1 ≠ H2 (постоянная смена ведущей руки)

```
  06: K Левая вертикаль + обе диагонали (110100)
  07: M Обе вертикали + обе диагонали (111100)
  08: ⊤ Верхняя + левая (000101)
  09: △ Обе диагонали + верхняя сторона (110001)
  10: ┘ Нижняя + правая (001010)
  11: □ Все 4 стороны (001111)
  12: □+╲ Квадрат + диагональ 1 (011111)
  13: □+╱ Квадрат + диагональ 2 (101111)
  14: ☒  Квадрат + обе диагонали (111111) = максимум

СТРОКА 2 (10 символов): Одиночные диагонали и 2-линейные комбинации
  15: ╲      Повтор диагонали 1 (подтверждение)
  16: ╳      X-форма (вариант)
  17: ─      Верхняя горизонталь
  18: └      Нижний-левый угол
  19: ╲╱     Два диагональных штриха
  20: ⊢      Правая стена + горизонталь
  21: X+│    X с вертикальной линией
  22: ┘      Правый нижний угол
  23: □      Квадрат
  24: □+╲    Квадрат с диагональю

СТРОКА 3 (10 символов): 2-3 линейные формы
  25: └┐     Два угла
  26: └─     Угол + горизонталь
  27: ╲      Диагональ (контекст)
  28: △      Треугольник верхний
  29: X      Крестовина
  30: □      Квадрат
  31: ┐      Правый верхний угол
  32: ╲+□    Диагональ в квадрате
  33: ╱+□    Антидиагональ в квадрате
  34: ☒      Полный символ

СТРОКИ 4-7 (по 8-10 символов): Систематический перебор 3-4 линий
  Преобладают K-формы, N-формы, Z-формы и их зеркальные отражения.

СТРОКИ 8-9 (по 6-8 символов): Сложные 4-5 линейные формы
  Треугольники, трапеции, неполные квадраты с диагоналями.

СТРОКИ 10-11 (6+3 символа): Последние уникальные комбинации
  M, N, Z-формы максимальной сложности.
  Последние 3: завершающие варианты, замыкающие алфавит.

ИТОГО: 76 символов = 64 (6-битных) + 12 (полулинии из центра)
```

### 12.3 Организационный принцип изображения

Строка 1 — это **обзорная шкала**: от минимума (0 линий = точка) до максимума
(6 линий = ☒), показывающая весь диапазон сложности за 14 шагов.

Строки 2-11 — **систематический перебор** оставшихся комбинаций, сгруппированных
по количеству линий и по типу (углы → стороны → диагонали → смешанные).

Принцип порядка:
1. Простые перед сложными (от 1 линии к 6)
2. Левые перед правыми (зеркальные пары рядом)
3. Открытые перед закрытыми (углы → рамки)
4. Прямые перед диагональными

### 12.4 Интерпретация «перед собой»

Квадрат символа = **пространство перед бойцом** (вид спереди):
```
     ┌─────────────── ВЕРХ (над головой) ──────────────────┐
     │                                                       │
  ЛЕВО                    ЦЕНТР                          ПРАВО
  (левая рука)          (корпус)                    (правая рука)
     │                                                       │
     └─────────────── НИЗ (на уровне пояса) ───────────────┘
```

Каждая линия = положение одной руки или направление движения:
- Верхняя сторона: руки вверх (защита головы)
- Нижняя сторона: руки вниз (защита корпуса)
- Левая сторона: левая рука вертикально
- Правая сторона: правая рука вертикально
- ╲ диагональ: одна рука сверху-слева → вниз-направо
- ╱ диагональ: одна рука сверху-справа → вниз-налево

## Часть 13: ЧВС как «коробка передач» — расширенная теория

### 13.1 Аналогия с механической КПП

```
Передача   ЧВС-состояние    Скорость    Сила      Применение
────────────────────────────────────────────────────────────────
  1-я      КУЛАК (сжат)     Медленно    Макс.     Прямой удар
  2-я      ЛАДОНЬ (раскрыт) Средне      Средне    Блок / отвод
  3-я      ПАЛЬЦЫ (вытянуты)Быстро      Точечно   Тычок / нажатие
  N        РАССЛАБ (мягко)  Адаптивно   Минимум   Захват / перевод
────────────────────────────────────────────────────────────────
```

Как в автомобиле:
- Переключение передач НЕ меняет маршрут (БВС)
- НЕ меняет полосу (СВС)
- НЕ поворачивает руль (МВС)
- НО меняет характер контакта в момент удара/блока

### 13.2 Вычислительная аналогия

```
БВС = Выбор алгоритма (стратегия)
      → Какую функцию вызываем?
      → Время решения: ~секунды

СВС = Выбор параметров (тактика)
      → С какими аргументами?
      → Время решения: ~100 мс

МВС = Итерация цикла (техника)
      → Текущий шаг внутри алгоритма
      → Время решения: ~50 мс

ЧВС = Микрокоррекция (коробка передач)
      → if/else внутри итерации
      → Условное ветвление на ходу
      → Время решения: ~10 мс

ПРИМЕР: Сортировка массива
  БВС: quicksort (стратегия)
  СВС: pivot = median-of-three (параметр)
  МВС: partition step i=42 (итерация)
  ЧВС: swap vs skip (микрорешение на лету)
```

### 13.3 Переключение ЧВС на максимальной скорости

На уровне мастерства 4-5 решение о типе контакта принимается за ~10 мс.
Это возможно только через предварительное программирование 4 реакций:

```
Алгоритм ЧВС-переключения:

ВХОДНЫЕ ДАННЫЕ: тактильная обратная связь (датчик контакта)
  → твёрдое → КУЛАК (усилить удар)
  → мягкое  → ЗАХВАТ (перевести)
  → пустое  → ПАЛЬЦЫ (добить тычком)
  → блок    → ЛАДОНЬ (перенаправить)

Скорость реакции: 10 мс (рефлекторный уровень, без сознательного решения)

Аналог в коде:
  switch(contact_type) {
    case HARD:  return CHVS_FIST;    // усилить
    case SOFT:  return CHVS_GRAB;    // захватить
    case EMPTY: return CHVS_POINT;   // добить
    case BLOCK: return CHVS_PALM;    // перенаправить
  }
```

### 13.4 Математическая модель ЧВС

ЧВС как дискретный модулятор непрерывного сигнала:

```
Полное движение:
  r(t) = [BVS(t) + SVS(t) + MVS(t)] × ChVS(t)

Где ChVS(t) ∈ {σ_fist, σ_palm, σ_point, σ_grab}

σ_fist  = (1.0, 0.0, 0.0)  — жёсткий контакт, максимум силы
σ_palm  = (0.5, 0.5, 0.0)  — распределённый контакт
σ_point = (0.0, 0.0, 1.0)  — точечный контакт, максимум проникновения
σ_grab  = (0.3, 0.3, 0.4)  — адаптивный контакт

Переключение:
  ChVS(t) = σ_i  если  t ∈ [t_switch_i, t_switch_{i+1})

Частота переключения: f_ChVS = 1/(2×0.01) = 50 Гц
  (каждые 10 мс новое решение)
```

### 13.5 ЧВС в контексте больших вычислений

Для алгоритмов, работающих на высокой скорости с микрозадачами:

```
Уровень     Аналог                  Временной масштаб    Применение
──────────────────────────────────────────────────────────────────────
БВС         Общая архитектура       Перед запуском       Map/Reduce стратегия
СВС         Пакетная обработка      ~100 мс пакет        Размер batch-а
МВС         Индивидуальная задача   ~50 мс/задача        Обработка 1 элемента
ЧВС         Микрооптимизация        ~10 мс               Branch prediction,
            (коробка передач)                             prefetch, speculative
                                                          execution
──────────────────────────────────────────────────────────────────────

Конкретный пример: Поисковый движок
  БВС: Выбор индекса (полнотекстовый vs векторный)
  СВС: Шардирование запроса (по серверам)
  МВС: Обработка одного шарда
  ЧВС: На лету — фильтр/ранжирование/кэш-хит?
       4 состояния:
         FIST  = прямой ответ (кэш попал)
         PALM  = перенаправить (кэш устарел, обновить)
         POINT = точный поиск (редкий запрос)
         GRAB  = собрать из нескольких источников (сложный запрос)
```

## Часть 14: Спичечный автомат — полная спецификация

### 14.1 Определение

Спичечный автомат (Match-Stick Automaton, MSA) — конечный автомат,
моделирующий все допустимые положения двух рук перед телом бойца.

```
MSA = (Q, Σ, δ, q₀, F)

Q  = 76 состояний (символы алфавита)
Σ  = {add_line, remove_line, switch_chvs} — входной алфавит
δ  = функция переходов (граф с ~670 рёбрами)
q₀ = 0 (точка — исходная позиция)
F  = Q (все состояния допустимые)
```

### 14.2 Граф переходов

```
Статистика графа (64 базовых состояния):
  Узлы:            64 (+ 12 полулинейных = 76)
  Рёбра (≤2 бита): 672
  Средняя степень:  21.0
  Диаметр:          3 шага (от пустого до любого)
  Плотность:        0.333

Это означает:
  - Из любого положения можно перейти в ~21 другое за 1 такт
  - Любые два положения разделяет максимум 3 перехода
  - Третья часть всех возможных переходов доступна (плотный граф)
```

### 14.3 Матрица переходов (фрагмент для первых 8 символов)

```
Из\В   empty  diag1  diag2  corner  X     K     square full
empty    —      1      1      1     2     3       4     6
diag1    1      —      2      2     1     2       5     5
diag2    1      2      —      2     1     2       5     5
corner   1      2      2      —     3     3       2     4
X        2      1      1      3     —     1       4     4
K        3      2      2      3     1     —       3     3
square   4      5      5      2     4     3       —     2
full     6      5      5      4     4     3       2     —

Значения = расстояние Хэмминга (количество линий для изменения)
Переход допустим если расстояние ≤ 2
```

### 14.4 Классы переходов

```
Тип перехода          Рёбер   Описание               Скорость
──────────────────────────────────────────────────────────────
Добавление 1 линии      6    Усложнение              Быстро
Удаление 1 линии        6    Упрощение               Быстро
Замена 1 на 1           30   Боковое движение        Средне
Добавление 2 линий      15   Резкое усложнение       Медленно
Удаление 2 линий        15   Резкое упрощение        Медленно
Замена 2 на 2+          90   Перестройка              Медленно
──────────────────────────────────────────────────────────────

Скарабей предпочитает быстрые переходы (1 линия) в 70% случаев.
Медленные переходы (2 линии) — для смены направления, обмана.
```

### 14.5 Алгоритм работы автомата

```python
# Цикл работы MSA:
состояние = ПУСТОЕ
уровень_чвс = КУЛАК

пока бой:
    # 1. БВС решает: атака / защита / обман
    стратегия = бвс_решение(противник, позиция)

    # 2. СВС выбирает группу техник (1-7)
    группа = свс_тактика(стратегия, расстояние)

    # 3. МВС выбирает конкретный символ из группы
    целевой_символ = мвс_техника(группа, текущее_состояние)

    # 4. Найти кратчайший путь (≤3 шагов)
    путь = bfs(текущее_состояние, целевой_символ)

    # 5. Выполнить путь с ЧВС-переключением
    для каждого шага в путь:
        выполнить(шаг)
        контакт = получить_обратную_связь()
        уровень_чвс = чвс_переключение(контакт)
        применить(уровень_чвс)

    состояние = целевой_символ
```

### 14.6 Пример: полный цикл атаки

```
Такт 0: · (точка)           ЧВС: расслаб  — готовность
Такт 1: ╲ (диагональ)       ЧВС: кулак    — замах
Такт 2: K (K-форма)         ЧВС: кулак    — удар с прикрытием
Такт 3: X (крест)           ЧВС: ладонь   — двойной блок
Такт 4: ┘ (угол)            ЧВС: захват   — перехват руки
Такт 5: ╱ (антидиагональ)   ЧВС: пальцы   — тычок в горло
Такт 6: · (точка)           ЧВС: расслаб  — возврат

Этот цикл проходит через 4 группы: 1→5→4→2→3→1→1
Длительность: 7 тактов (НЕЧЁТНОЕ!)
Маршрут = деформированная восьмёрка в пространстве символов.
```

## Часть 16: Двойной спичечный автомат (жонглёр)

### 16.1 Концепция: два спаренных MSA

Один MSA описывает одну руку перед собой. Для двух рук — два MSA,
работающих синхронно с правилами координации.

```
DualMSA = (MSA_left, MSA_right, Rules)

MSA_left  = 76 состояний × 4 ЧВС = 304 (левая рука)
MSA_right = 76 состояний × 4 ЧВС = 304 (правая рука)

Полное пространство: 304 × 304 = 92,416 двойных состояний (сырые)
После фильтрации: ~30,000 допустимых пар (~27% от сырых)
```

### 16.2 Пять правил координации (закон жонглёра)

```
Правило 1 — ЗОНЫ (пространственное разделение):
  Квадрат перед бойцом делится на 4 квадранта.
  Две руки не могут одновременно занимать один квадрант.
  → Как два жонглёра на одной сцене: у каждого своя территория.

Правило 2 — АНТИСИММЕТРИЯ (H1 ≠ H2):
  Если одна рука атакует → другая защищает.
  Если одна вверху → другая внизу.
  Если одна слева → другая справа.
  → Комплементарность: bits(L) ≈ ~bits(R) (побитовое дополнение)
  → Минимум 3 из 6 битов должны быть комплементарными.

Правило 3 — ЧЕРЕДОВАНИЕ ВЕДУЩЕЙ РУКИ:
  Ведущая рука (lead) переключается каждые 1 или 3 такта (НЕЧЁТНО!).
  → lead делает первый ход (инициатива)
  → follow реагирует (комплемент)
  → Как вопрос-ответ или солист-аккомпанемент.

Правило 4 — ФАЗОВЫЙ СДВИГ:
  Левая рука опережает правую на π/2 (или отстаёт).
  → Нет одновременного удара двумя руками (неэффективно).
  → Каскадный принцип: L1 → R1 → L2 → R2 → ...

Правило 5 — СОХРАНЕНИЕ СЛОЖНОСТИ:
  complexity(L) + complexity(R) ≈ const
  → Если одна рука делает сложное движение (4 линии),
    другая делает простое (1-2 линии).
  → Общая когнитивная нагрузка не превышает 7±2.
```

### 16.3 Аналогия с жонглированием

```
Жонглёр подбрасывает шарики:
  - Каждая рука идёт по своей восьмёрке
  - Шарики привязаны (не летят далеко) = ограниченная амплитуда
  - Руки не сталкиваются = зонное разделение
  - Ритм: 1-2-3, 1-2-3 = нечётные серии
  - Каждый шарик вращается = ЧВС (пальцы крутят)

Боец:
  - Каждая рука идёт по своему MSA
  - Удары/блоки ограничены зоной досягаемости = bounded space
  - Руки не перекрещиваются = антиколлизия
```

### 17.2 Мудры как переключатели в высокоскоростном режиме

```

  Время между тактами: 50 мс
  Время на переключение мудры: 10 мс
  → 5 переключений мудры за 1 такт (если нужно)

Пример быстрого каскада:
  t=0ms:  Удар кулаком (FIST)
  t=10ms: Контакт мягкий → переключение на GRAB
  t=20ms: Захватил → переключение на BLADE (ребро ладони для отвода)
  t=30ms: Отвёл → переключение на POINT (тычок)

Это рефлекторный уровень (мышечная память).
```

### 17.3 Мудры в вычислительном контексте

```
8 мудр = 8 микрооптимизаций в алгоритме:

FIST  = direct return (прямой ответ из кэша)
PALM  = redirect (перенаправление запроса)
POINT = deep search (точный поиск)
GRAB  = aggregate (собрать из нескольких источников)
BLADE = filter (отсечь нерелевантное)
HOOK  = prefetch (предварительная загрузка)
SPEAR = speculative exec (спекулятивное выполнение)
CUP   = broadcast (рассылка по всем каналам)

Пример: обработка HTTP-запроса
  → кэш попал? → FIST (отдать сразу)
  → кэш устарел? → PALM (перенаправить на обновлённый)
  → редкий запрос? → POINT (полнотекстовый поиск)
  → сложный запрос? → GRAB (join из 3 таблиц)
  → спам? → BLADE (фильтр, отсечь)
  → следующий будет похож? → HOOK (предзагрузить)
  → неизвестный тип? → SPEAR (попробовать оба варианта)
  → уведомление? → CUP (broadcast всем подписчикам)
```

## Часть 20: Правила 4 и 5 — фазовый сдвиг и сохранение сложности

### 20.1 Правило 4: Фазовый сдвиг (Phase Offset)

Руки двигаются не одновременно, а каскадом:

```
Без фазового сдвига:     С фазовым сдвигом:
  L1, R1 → L2, R2          L1 → R1 → L2 → R2 → L3 → R3
  (параллельно)             (каскад, π/2 сдвиг)

Аналогия:
  Без сдвига = удар двумя руками одновременно (неэффективно)
  С фазовым сдвигом = джеб-кросс комбинация (каскадная мощность)
```

Реализация в DualMSA:
- Ведущая рука (lead) принимает решение первой
- Ведомая рука (follow) реагирует на позицию lead
- На высоком мастерстве (≥3): follow использует «смешение» текущей
  и предыдущей позиции lead для предсказания (anticipation)
- При смене lead фаза инвертируется

```python
# Фазовое смешение (anticipation):
blend_mask = random_bits(6)
phase_reference = (lead_current & mask) | (lead_previous & ~mask)
# → follow реагирует на «среднее» между текущим и прошлым
```

### 20.2 Правило 5: Сохранение сложности (Complexity Conservation)

```
Закон сохранения: C(L) + C(R) ≈ const ∈ [2, 6]

Где C(sym) = количество активных линий (0-4 шкала)

Примеры:
  L: K-форма (C=3) + R: одна линия (C=1) = 4  ✓ OK
  L: квадрат (C=4) + R: точка (C=0)     = 4  ✓ OK
  L: полный (C=4) + R: полный (C=4)     = 8  ✗ OVERLOAD
  L: пусто (C=0) + R: пусто (C=0)       = 0  ✗ UNDERLOAD
  L: диаг1 (C=1) + R: диаг2 (C=1)      = 2  ✓ OK (минимум)
```

Когнитивное обоснование:
- Закон Миллера (7±2): общая нагрузка на оба полушария ≈ 7
- Две руки: 7/2 ≈ 3.5 → целевая сложность = 4 (с допуском ±2)
- Если одна рука выполняет сложный приём → другая упрощается
- Мозг компенсирует: сложность «перетекает» как в сообщающихся сосудах

```
Метафора:
  Два жонглёра делят 7 мячей:
    5+2, 4+3, 3+4, 2+5 — все допустимо
    7+0 — один всё делает, другой стоит (неэффективно)
    0+0 — оба стоят (нет действия)
```

## Часть 21: Оценка ката, сезонный генератор, ритм и темп

### 21.1 Система оценки ката (Score)

Каждая двуручная ката оценивается по всем 5 правилам:

```
Правило          За такт            За ката            Вес
──────────────────────────────────────────────────────────────
1. Зоны          0/1 (нет коллизии) Σ / N тактов       Жёсткий
2. Антисимметрия 0/1 (≥3/6 бит)    Σ / N тактов       Мягкий
3. Чередование   —                  0/1 (серия нечёт.) Жёсткий
4. Плавность     0/1 (≤2 бит Δ)    Σ / (N-1)          Мягкий
5. Сохранение C  0/1 (C ∈ [2,6])   Σ / N тактов       Мягкий

Итоговая оценка: total / max → процент → буква

Шкала:
  A (90-100%): Мастерская ката — все правила соблюдены
  B (75-89%):  Хорошая ката — 1-2 мягких нарушения
  C (60-74%):  Средняя ката — требуется работа
  D (40-59%):  Слабая ката — существенные нарушения
  F (<40%):    Неудовлетворительно — переучивать
```

Пример отчёта:
```
Grade: B (86%) [24/28]
  Rule 1 (Zones       ): 7/7    ← все зоны чистые
  Rule 2 (Anti-sym    ): 5/7    ← 2 такта без дополнения
  Rule 3 (Alternation ): 1/1    ← чередование корректно
  Rule 4 (Smoothness  ): 5/6    ← 1 резкий переход
  Rule 5 (Conservation): 6/7    ← 1 перегрузка
  Lead pattern: LRRRRR
```

### 21.2 Жёсткое исполнение Правила 1 (Zone Enforcement)

В предыдущей версии зоны проверялись, но не блокировались. Теперь:

```
Алгоритм step() с жёстким Правилом 1:

1. Ведущая рука выбирает следующий символ:
   → Фильтрация: zones_conflict(candidate, follow_current) = False
   → Если нет кандидатов: ослабить антикруг, сохранить зоны
   → Если всё равно нет: любой без конфликта

2. Ведомая рука выбирает комплемент:
   → _get_complementary_symbol уже проверяет зоны
   → Дополнительная проверка (belt-and-suspenders):
     если zones_conflict(lead_next, follow_next):
       → аварийная замена на безопасный символ

Результат: Правило 1 теперь 100% — ни одна ката не содержит коллизий.
```

### 23.2 Мост траектория ↔ MSA (k-деформация)

Ключевое достижение: параметр k теперь ВЛИЯЕТ на ката.

```
trajectory_kata(k, length, mastery_level, use_dual):

1. Генерирует 4-уровневую траекторию Скарабея:
   four_level_scarab(k_bvs=k, k_svs=0.7k, k_mvs=0.4k, k_chvs=1)

2. Семплирует length точек через равные интервалы
   indices = [0, n/6, 2n/6, ..., n-1]

3. Каждую точку (x,y) отображает на ближайший символ:
   sym = xy_to_nearest_symbol(x, y, available)

4. Для dual: правая рука = π-сдвиг на восьмёрке
   mirror_idx = (idx + n/2) % n
   → руки находятся на противоположных петлях

Влияние k на ката:
  k=1.0: симметричная 8 → сбалансированные символы
  k=5.0: асимметричная 8 → более сложные на одной стороне

  k=5:  Grade B (75%), 6 групп, антисимметрия 86%
  k=10: Grade B (75%), 6 групп, стабильные паттерны
```

Физический смысл: деформация восьмёрки определяет,
какие движения (символы) доминируют в ката.
- Малое k: обе петли равны → одинаковые атаки в оба направления
- Большое k: одна петля больше → акцент на одну сторону

## Часть 24: Кватернион, LCI, закон сохранения, визуализация

### 24.1 Кватернион 4-сферной системы

Из Крюкова (Том 103):
```
A = a·1 + b·i + c·j + d·k

где:
  a = БВС (тело/плечо)    — скалярная часть — 3D Земля
  b = СВС (локоть/предплечье) — компонента i — 2D Вода
  c = МВС (кисть/запястье)    — компонента j — 1D Воздух
  d = ЧВС (пальцы)            — компонента k — 0D Огонь
```

Реализация `ScarabQuaternion`:
```python
q = ScarabQuaternion(bvs=0.55, svs=0.15, mvs=0.05, chvs=0.015)

q.norm()        # |A| = √(a² + b² + c² + d²) = LCI
q.lci()         # алиас для norm()
q.conjugate()   # Ā = a - b·i - c·j - d·k
q * other       # произведение Гамильтона (композиция движений)
q.normalized()  # |A| = π (нормализация к закону сохранения)
q.components_pct()  # % вклад каждой сферы в общую энергию
```

Произведение кватернионов = КОМПОЗИЦИЯ движений:
```
q1 × q2 = (a1+b1·i+c1·j+d1·k) × (a2+b2·i+c2·j+d2·k)

Физический смысл: выполнить движение q1, затем q2.
Некоммутативность: q1 × q2 ≠ q2 × q1
→ порядок ударов ИМЕЕТ ЗНАЧЕНИЕ (как в реальном бою!)
```

### 24.2 LCI — Line Complexity Index

```
LCI = |A| = √(БВС² + СВС² + МВС² + ЧВС²)

Прогрессия по уровням мастерства:

Уровень  |A|     БВС%  СВС%  МВС%  ЧВС%   Статус
──────────────────────────────────────────────────
  1      0.550   100%   0%    0%    0%    Только тело
  2      0.570    93%   7%    0%    0%    + предплечье
  3      0.572    92%   7%    1%    0%    + кисть
  4      0.574    92%   7%    1%    0%    + пальцы
  5      3.142    92%   7%    1%    0%    МАСТЕРСТВО: |A| = π
```

Закон: на уровне 5 происходит НОРМАЛИЗАЦИЯ — |A| → π.
Это значит: все 4 сферы резонируют, общая энергия = π.

### 24.3 Закон сохранения: |A| = π

```
Теорема Нётер → инвариант системы → |A| = π = const

Верификация:
  Level 1: |A| = 0.5500, π = 3.1416, match = False
  Level 3: |A| = 0.5723, π = 3.1416, match = False
  Level 5: |A| = 3.1416, π = 3.1416, match = True  ← ДОКАЗАНО

Физический смысл:
  Уровни 1-4: сферы не сбалансированы, энергия < π
  Уровень 5 (мастерство): ВСЕ сферы резонируют:
    ω_БВС = ω_СВС = ω_МВС = ω_ЧВС
    → |A| нормализуется к π
    → увеличение одной сферы = уменьшение другой
    → СОХРАНЕНИЕ: БВС + СВС + МВС + ЧВС = const = π
```

### 27.1 Генератор дриллов (микро-упражнения)

```python
generate_drill(target='rule', rule_num=2, n_reps=5, mastery_level=3, seed=42)

```

Дрилл = 3 такта × N повторений с вариациями. Три типа:

```
target='rule':       отработка конкретного правила (1-5)
  → генерирует мини-ката, пока правило не будет соблюдено
  → Пример: Rule 2 (anti-symmetry) — 3 репа, avg 78%

target='group':      символы из конкретной группы Крюкова
  → левая рука из целевой группы, правая — антисимметричная
  → Пример: Group 5 (Triple) — тренирует сложные символы

target='transition': плавные переходы (Hamming ≤ 2)
  → каждый шаг — сосед в графе переходов
  → Пример: avg 58% (труднее, так как не контролирует правила)
```

Применение совместно с `StudentProfile.weaknesses()`:
```python
for w in student.weaknesses():
    if w['type'] == 'rule':
        drill = generate_drill(target='rule', rule_num=w['rule'])
    elif w['type'] == 'group':
        drill = generate_drill(target='group', group_num=w['group'])
```

5 типов мутаций:

```
Мутация      Описание                   Сохранение оценки  Сходство
─────────────────────────────────────────────────────────────────────
mirror       L ↔ R (смена рук)          высокое            ~0.997
reverse      обратный порядок тактов     среднее            1.000*
shift        каждый символ → сосед ±1    низкое             ~0.968
recolor      новые ChVS, символы те же   высокое            1.000*
crossover    первая половина + shift     среднее            ~0.937

```

```
  shift      → [ebb434fce610] Grade C (68%) sim=0.968
  recolor    → [0a9c0d655b77] Grade A (93%) sim=1.000
  crossover  → [fa297270f445] Grade C (71%) sim=0.937
```

Применение мутаций:
- **Вариативность тренировки**: не повторять одну и ту же ката
- **Прогрессия сложности**: shift снижает оценку → ученик исправляет
- **Левша/правша**: mirror для смены ведущей руки
- **Тест понимания**: recolor — символы те же, ChVS другой

Пример (6 участников):
```

  Round 1:

  Round 3:

```

Правила:
- Случайная жеребьёвка в первом раунде
- Нечётный игрок получает BYE (проход)
- Ничья → первый игрок проходит (преимущество хозяина)
- `decisive` = разница > 0.1 (отмечается `*`)
