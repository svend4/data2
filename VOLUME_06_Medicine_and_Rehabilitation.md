## ПРЕДИСЛОВИЕ

Что общего между мастером кунг-фу и пациентом после инсульта, заново учащимся поднимать руку?

На первый взгляд — ничего. На самом деле — всё.

Оба занимаются одним и тем же: **восстановлением оптимальной траектории движения**. Мастер совершенствует её до предела возможного. Пациент возвращает её после разрушения.

Система Крюкова, изложенная в «Тотальной Системе Боя», описывает **оптимальное человеческое движение** с математической точностью: петлевые траектории, иерархия трёх сфер, резонанс уровней. Именно поэтому отклонение от этих траекторий служит **диагностическим маркером** двигательных нарушений, а возврат к ним — **целью и мерилом** реабилитации.

Этот том — первое систематическое применение аппарата боевого искусства к медицинской реабилитации. Он адресован:
- врачам лечебной физкультуры и реабилитологам
- нейрофизиологам и эрготерапевтам
- разработчикам медицинских устройств и VR-систем
- исследователям, изучающим двигательные расстройства

## ЧАСТЬ I. ТЕОРЕТИЧЕСКИЕ ОСНОВЫ

### Глава 1. Архетипы движения как норма и патология

#### 1.1 Петля как фундаментальная единица здорового движения

В системе Крюкова **петля** (замкнутая траектория) — базовый строительный блок любого движения. Рука мастера никогда не движется прямолинейно «туда и обратно». Она описывает замкнутые кривые — овалы, восьмёрки, спирали.

Математически идеальная петля описывается как кривая Лиссажу:

```
x(t) = A · sin(ω·t + φ_x)
y(t) = B · sin(2ω·t + φ_y)
```

При A = B и φ_y = π/2 получаем **восьмёрку** — универсальный двигательный архетип.

Физиологическая основа петли:
- Мышцы-антагонисты работают в непрерывном режиме
- Суставная жидкость распределяется равномерно
- Нет «мёртвых точек» — моментов нулевой скорости
- Переход между сгибанием и разгибанием плавный

**Это не просто эстетика движения. Это биомеханическая необходимость.**

При прямолинейном движении «туда-обратно» неизбежны:
- Резкие торможения и ускорения
- Избыточная нагрузка на суставы в крайних точках
- Неравномерный износ хрящевой ткани
- Повышенный мышечный тонус на «разворотах»

#### 1.2 Метрика петли: Loop Closure Index (LCI)

Для количественной оценки «петлевости» движения вводим **Индекс Замкнутости Петли** (ИЗП / Loop Closure Index, LCI):

```
LCI = S_enclosed / S_bounding_box

где:
S_enclosed — площадь, охватываемая траекторией
S_bounding_box — площадь описывающего прямоугольника

LCI ∈ [0, 1]:
  0.0 — абсолютно прямолинейное движение
  0.5 — круговое движение
  0.7 — восьмёрка (две петли)
  1.0 — идеальное заполнение пространства
```

**Клинические пороговые значения LCI:**

| LCI | Интерпретация | Клиническое значение |
|-----|---------------|----------------------|
| < 0.3 | Критическая линейность | Тяжёлая патология |
| 0.3–0.6 | Сниженная петлевость | Умеренные нарушения |
| 0.6–0.7 | Субнорма | Лёгкие нарушения / начало восстановления |
| 0.7–0.85 | Норма | Здоровое функциональное движение |
| 0.85–1.0 | Высокая петлевость | Спортивный уровень / мастерство |

Измерение LCI возможно с помощью:
- IMU-датчиков (инерциальные измерительные блоки) на запястье
- Систем захвата движения (motion capture)
- Оптических трекеров смартфона (±15% точность)
- Видеоанализа с AI-скелетонизацией (MediaPipe, OpenPose)

#### 1.3 Три сферы как анатомический атлас

Модель трёх сфер Крюкова — не абстракция. Она точно соответствует анатомическим функциональным единицам руки:

```
МВС (Малая Внутренняя Сфера):
  Анатомия: кисть, пальцы
  Суставы: лучезапястный, пястно-фаланговые
  Мышцы: собственные мышцы кисти, сгибатели/разгибатели пальцев
  Функция: точные манипуляции, захват, щипок
  Радиус действия: 0–15 см

СВС (Средняя Внутренняя Сфера):
  Анатомия: предплечье
  Суставы: локтевой, лучелоктевой (пронация/супинация)
  Мышцы: двуглавая, трёхглавая, круглый пронатор, супинатор
  Функция: размах, перенос, рычаговое усиление
  Радиус действия: 15–45 см

БВС (Большая Внешняя Сфера):
  Анатомия: плечо, плечевой пояс, туловище
  Суставы: плечевой, грудино-ключичный, лопаточно-грудной
  Мышцы: дельтовидная, большая грудная, трапециевидная
  Функция: ориентация, позиционирование, баланс
  Радиус действия: 45–100+ см
```

**Ключевое клиническое правило:** каждая из трёх сфер имеет собственную нейрологическую иннервацию и собственный путь восстановления. Поражение одной сферы не означает поражения других.

### Глава 2. Нейрофизиология петлевого движения

#### 2.1 Центральные паттерны движения (CPG) и петли

В спинном мозге и стволе головного мозга существуют **центральные паттерн-генераторы** (Central Pattern Generators, CPG) — нейронные сети, автономно генерирующие ритмические двигательные паттерны (ходьба, жевание, дыхание).

Принципиальное открытие: CPG генерируют **именно петлевые траектории**.

Нейронный осциллятор CPG описывается уравнением Ван-дер-Поля:

```
ẍ - μ(1 - x²)ẋ + ω²x = 0

где:
μ — нелинейное затухание (амплитудный контроль)
ω — частота осцилляции
x — двигательная переменная (угол сустава)
```

Это уравнение имеет **аттрактор в виде замкнутой кривой** — петли на фазовом портрете (x, ẋ).

Практический вывод: **реабилитация через ритмические петлевые движения активирует CPG напрямую**, минуя кортикальный контроль. Это объясняет, почему даже при тяжёлом инсульте ритмические упражнения на нижние конечности помогают восстановить ходьбу.

#### 2.2 Нейропластичность и петлевая тренировка

Нейропластичность — способность мозга перестраивать нейронные связи — максимально активируется при:
1. **Повторяемости** движения (≥300 повторений в сессию)
2. **Ритмичности** (фиксированная частота)
3. **Постепенном усложнении** амплитуды и скорости
4. **Обратной связи** (пациент видит/чувствует результат)

Все четыре условия естественно выполняются при **петлевой тренировке**:
- Петля — замкнутая, значит легко повторяется
- Петля — ритмическая фигура по определению
- Амплитуду петли легко увеличивать градуально
- Замкнутость петли даёт мгновенную тактильную ОС (рука «вернулась»)

#### 2.3 Резонанс сфер и нейромышечная синхронизация

Условие резонанса из системы Крюкова:

```
ω_МВС = ω_СВС = ω_БВС → РЕЗОНАНС
```

В нейрофизиологии это соответствует **межуровневой нейромышечной синхронизации**:
- Кортикальные осцилляции (γ-ритм, 30–80 Гц) модулируют
- Мозжечковые ритмы (10–25 Гц) которые управляют
- Спинальными CPG (1–5 Гц)

Нарушение этой иерархии — при болезни Паркинсона, ДЦП, инсульте — проявляется как **десинхронизация сфер**: МВС, СВС и БВС работают в разных ритмах.

Цель реабилитации с этой точки зрения: **восстановить нейромышечный резонанс** — добиться синхронной работы всех трёх уровней.

## ЧАСТЬ II. НОЗОЛОГИИ И ДИАГНОСТИКА

### Глава 3. Болезнь Паркинсона

#### 3.1 Паркинсон через призму архетипов движения

Болезнь Паркинсона (БП) — нейродегенеративное заболевание, при котором дефицит дофамина в базальных ганглиях нарушает инициацию и регуляцию движений.

**Симптомы БП в терминах системы Крюкова:**

| Симптом БП | Архетип | Нарушение |
|-----------|---------|-----------|
| Тремор покоя | Петля | Неконтролируемые малоамплитудные петли МВС |
| Ригидность | Резонанс | Невозможность синхронизации сфер |
| Брадикинезия | Петля | «Разрыв» петли — движение прерывается |
| Постуральная нестабильность | БВС | Нарушение большой сферы (туловище) |
| Микрография | МВС | Схлопывание малой сферы |
| Гипомимия | МВС | МВС лица = микрообластная малая сфера |

**Ключевая особенность:** при БП петли **разрываются** — пациент не может завершить плавное замкнутое движение. Рука движется «рывками» через прямолинейные сегменты. LCI падает до 0.2–0.4.

#### 3.2 Диагностика БП через LCI

Предлагаемый протокол оценки:

```
ТЕСТ «СПИРАЛЬ КРЮКОВА» для диагностики БП:

1. Пациент рисует на бумаге спираль от центра наружу (10 см диаметр)
2. Сканируем рисунок / фотографируем
3. Вычисляем LCI алгоритмически:
   a. Скелетонизация линии
   b. Вычисление кривизны в каждой точке
   c. Обнаружение «разрывов» кривизны (прямолинейных сегментов)
   d. LCI = 1 - (длина_прямых_сегментов / общая_длина)

Норма:   LCI > 0.80
Ранний:  LCI 0.65–0.80 → наблюдение
БП:      LCI < 0.65 → направить к неврологу
```

Дополнительная метрика — **Индекс Ритмичности** (ИР):

```
ИР = 1 - (σ_период / μ_период)

где σ_период — стандартное отклонение периода петли,
    μ_период — средний период петли

ИР при норме: > 0.85
ИР при БП:   < 0.60
```

#### 3.3 Терапия БП через резонансный протокол

Клинически доказанный метод — **ритмическая аудиторная стимуляция** (RAS, Rhythmic Auditory Stimulation) — объясняется через резонансный принцип Крюкова:

Метроном задаёт внешнюю частоту → пациент синхронизирует движение → все три сферы захватываются этим ритмом → резонанс восстановлен временно.

**Расширенный резонансный протокол для БП:**

```
Сессия: 30 минут, 5 дней в неделю

Фаза 1 (10 мин): БВС-якорение
  - Пациент сидит, раскачивает туловище вперёд-назад под метроном (60 уд/мин)
  - Цель: «захватить» БВС метрономом

Фаза 2 (10 мин): Подключение СВС
  - Добавляем движения предплечий: петли локтями под тот же ритм
  - Цель: синхронизировать СВС с уже захваченным БВС

Фаза 3 (10 мин): МВС-интеграция
  - Добавляем движения кистей: восьмёрки под тот же ритм
  - Цель: трёхуровневый резонанс

Оценка: записываем LCI в начале и конце сессии
Ожидаемый прирост LCI за сессию: +0.10–0.15
```

### Глава 4. Инсульт и Постинсультная Реабилитация

#### 4.1 Инсульт через призму архетипов

Инсульт (ОНМК) нарушает кортикоспинальные тракты — «командные линии» от коры к мышцам. В зависимости от локализации поражается преимущественно одна из сфер:

```
Поражение лобных долей → нарушение БВС (постуральный контроль)
Поражение теменных долей → нарушение СВС (проприоцепция предплечья)
Поражение моторной коры → тотальное нарушение, МВС страдает больше всего
Поражение мозжечка → нарушение резонанса (интенционный тремор)
Поражение базальных ганглий → нарушение «нечётного закона» (ритм движений)
```

#### 4.2 Протокол «Три Сферы» для постинсультной реабилитации

**Принцип иерархического восстановления:**

Восстановление идёт сверху-вниз по сферам:
1. **Сначала БВС** — грубый контроль туловища и плеча
2. **Затем СВС** — контроль предплечья и локтя
3. **В последнюю очередь МВС** — кисть и пальцы

Это противоречит интуиции («начнём с пальцев»), но соответствует нейрофизиологии: без базовой стабильности БВС МВС не может функционировать.

**Поэтапный протокол:**

```
═══════════════════════════════════════════
ЭТАП 1: «БВС-фундамент» (Недели 1–3)
═══════════════════════════════════════════

Упражнения:
  1.1 Маятник Кодмана (пассивное, БВС)
      Пациент наклоняется, рука свисает. Раскачивает круговыми движениями.
      Режим: 5 мин × 3 раза/день
      Цель: восстановить синовиальную жидкость, базовую подвижность

  1.2 Скольжение по столу (активное, БВС)
      Рука на гладкой поверхности. Скользит по эллипсу 20×30 см.
      Режим: 100 повторений × 3 раза/день
      LCI-цель: > 0.50

  1.3 Захват мяча (БВС-СВС)
      Мяч 20 см диаметра. Обхват двумя руками, подъём и опускание.
      Режим: 50 повторений × 3 раза/день

═══════════════════════════════════════════
ЭТАП 2: «СВС-активация» (Недели 4–8)
═══════════════════════════════════════════

Критерий перехода: LCI на этапе 1 достиг > 0.55

Упражнения:
  2.1 Петля предплечья
      Локоть прижат к боку. Предплечье рисует горизонтальные восьмёрки.
      Амплитуда: начать с 10 см, добавлять 2 см в день.
      Режим: 150 повторений × 3 раза/день
      LCI-цель: > 0.65

  2.2 Пронация-супинация с петлёй
      Поворот предплечья (ладонью вверх/вниз) в петлевом ритме.
      Режим: 100 повторений × 3 раза/день

  2.3 Переброс мяча через голову
      Мяч 15 см, обе руки, дуга через верх (БВС + СВС).
      Режим: 50 повторений × 2 раза/день

═══════════════════════════════════════════
ЭТАП 3: «МВС-интеграция» (Недели 9–16)
═══════════════════════════════════════════

Критерий перехода: LCI на этапе 2 достиг > 0.65

Упражнения:
  3.1 Восьмёрка пальцами
      Большой палец обводит пальцы по восьмёрке.
      Режим: 200 повторений × 3 раза/день
      LCI-цель: > 0.75

  3.2 Лепка петель из пластилина
      Руками создавать петли и восьмёрки.
      Режим: 30 мин × 2 раза/день

  3.3 Набор текста: петлевая клавиатура
      Специальное приложение: клавиши активируются петлевым движением.
      Режим: 20 мин × 2 раза/день
```

### Глава 5. Детский Церебральный Паралич (ДЦП)

#### 5.1 ДЦП как нарушение резонанса сфер

При ДЦП (спастическая форма) наблюдается **гиперактивность кортикоспинального тракта** — «командные линии» перевозбуждены. Это приводит к:
- Постоянному мышечному напряжению (спастика)
- Невозможности плавных петлевых движений
- Неравномерной работе сфер (МВС «переактивирована», БВС — нет)

**ДЦП в терминах архетипов:**
- Петли «ломаются» — спастика обрывает кривую на углах
- Резонанс нарушен — каждая сфера «застыла» на своей частоте
- Нечётный закон не работает — движение не завершается симметрично

#### 5.2 Музыкотерапия как резонансный инструмент

Для детей с ДЦП особенно эффективен **музыкальный резонанс**. Музыка с чёткой ритмической структурой:

1. Захватывает БВС через слуховой ритм (туловище качается)
2. Ритм тела «затягивает» СВС (руки начинают двигаться)
3. МВС подключается последней (пальцы по клавишам или барабану)

**Протокол «Музыкальный Резонанс»:**

```
Инструмент: электронный барабан или игрушечное пианино

Шаг 1 (2 недели): Слушание и раскачка
  Ребёнок слушает ритмичную музыку (80–100 уд/мин).
  Взрослый раскачивает ребёнка за плечи в такт (БВС-пассив).

Шаг 2 (2 недели): Активное БВС
  Ребёнок самостоятельно качается в такт.
  Метроном при необходимости.

Шаг 3 (4 недели): СВС + хлопки
  Хлопки в такт — простой ритм.
  Переход к хлопкам по барабану.

Шаг 4 (4 недели): МВС + инструмент
  Игра на барабане петлевым ударом (замах — удар — отскок).
  LCI-цель: > 0.60 для руки, держащей палочку.
```

## ЧАСТЬ III. ТЕХНОЛОГИИ РЕАБИЛИТАЦИИ

### Глава 6. Носимый «Сферический Тренажёр»

#### 6.1 Аппаратная архитектура

**Компоненты системы:**

```
┌─────────────────────────────────────────────────┐
│           СФЕРИЧЕСКИЙ ТРЕНАЖЁР v1.0             │
├─────────────────────────────────────────────────┤
│                                                 │
│  [Датчик МВС]    [Датчик СВС]    [Датчик БВС]  │
│  IMU на запястье  IMU на локте  IMU на плече    │
│  9-DOF: акселер.  9-DOF        9-DOF           │
│  + гироскоп                                    │
```

#### 6.2 Алгоритм вычисления LCI в реальном времени

```python
import numpy as np
from scipy.spatial import ConvexHull

class SphericalTrainer:
    """
    Носимый тренажёр для реабилитации на основе архетипов Крюкова.
    Вычисляет Loop Closure Index и Resonance Score в реальном времени.
    """

    WINDOW_SIZE = 200  # 2 секунды при 100 Гц
    UPDATE_RATE_HZ = 100

    def __init__(self):
        self.mvs_buffer = []  # МВС: запястье
        self.svs_buffer = []  # СВС: локоть
        self.bvs_buffer = []  # БВС: плечо

        self.lci_mvs = 0.0
        self.lci_svs = 0.0
        self.lci_bvs = 0.0
        self.resonance_score = 0.0

    def add_sample(self, mvs_xyz, svs_xyz, bvs_xyz):
        """Добавить новый отсчёт с трёх датчиков."""
        self.mvs_buffer.append(mvs_xyz)
        self.svs_buffer.append(svs_xyz)
        self.bvs_buffer.append(bvs_xyz)

        # Скользящее окно
        for buf in [self.mvs_buffer, self.svs_buffer, self.bvs_buffer]:
            if len(buf) > self.WINDOW_SIZE:
                buf.pop(0)

        # Обновляем метрики каждые 20 отсчётов (5 раз/с)
        if len(self.mvs_buffer) % 20 == 0:
            self._update_metrics()

    def _compute_lci(self, trajectory):
        """
        Вычислить Loop Closure Index для траектории.

        LCI = Площадь_выпуклой_оболочки / Площадь_описывающего_прямоугольника
        """
        pts = np.array(trajectory)[:, :2]  # XY-плоскость

        if len(pts) < 4:
            return 0.0

        try:
            hull = ConvexHull(pts)
            hull_area = hull.volume  # В 2D это площадь
        except Exception:
            hull_area = 0.0

        # Описывающий прямоугольник
        x_range = pts[:, 0].max() - pts[:, 0].min()
        y_range = pts[:, 1].max() - pts[:, 1].min()
        bbox_area = x_range * y_range

        if bbox_area < 1e-6:
            return 0.0

        return min(1.0, hull_area / bbox_area)

    def _compute_frequency(self, trajectory):
        """Вычислить доминирующую частоту движения через FFT."""
        pts = np.array(trajectory)[:, 0]
        fft_vals = np.abs(np.fft.rfft(pts))
        freqs = np.fft.rfftfreq(len(pts), d=1.0/self.UPDATE_RATE_HZ)
        dominant_freq = freqs[np.argmax(fft_vals[1:]) + 1]
        return dominant_freq

    def _update_metrics(self):
        """Обновить все метрики."""
        self.lci_mvs = self._compute_lci(self.mvs_buffer)
        self.lci_svs = self._compute_lci(self.svs_buffer)
        self.lci_bvs = self._compute_lci(self.bvs_buffer)

        # Резонанс: насколько близки частоты трёх сфер
        f_mvs = self._compute_frequency(self.mvs_buffer)
        f_svs = self._compute_frequency(self.svs_buffer)
        f_bvs = self._compute_frequency(self.bvs_buffer)

        # Отклонение частот от среднего
        f_mean = (f_mvs + f_svs + f_bvs) / 3
        if f_mean > 0:
            deviation = (abs(f_mvs - f_mean) +
                        abs(f_svs - f_mean) +
                        abs(f_bvs - f_mean)) / (3 * f_mean)
            self.resonance_score = max(0.0, 1.0 - deviation)
        else:
            self.resonance_score = 0.0

    def get_feedback(self):
        """Сформировать обратную связь для пациента."""
        overall_lci = (self.lci_mvs + self.lci_svs + self.lci_bvs) / 3

        if overall_lci >= 0.85 and self.resonance_score >= 0.80:
            return {'color': 'GOLD', 'vibration': 'triple_pulse',
                    'message': 'РЕЗОНАНС! Отличное движение!'}
        elif overall_lci >= 0.70:
            return {'color': 'GREEN', 'vibration': 'single_pulse',
                    'message': f'LCI={overall_lci:.2f} — хорошо'}
        elif overall_lci >= 0.55:
            return {'color': 'YELLOW', 'vibration': 'continuous_slow',
                    'message': f'LCI={overall_lci:.2f} — стараемся'}
        else:
            return {'color': 'RED', 'vibration': 'continuous_fast',
                    'message': f'LCI={overall_lci:.2f} — плавнее'}

    def get_clinical_report(self):
        """Сгенерировать клинический отчёт."""
        return {
            'lci_mvs': round(self.lci_mvs, 3),
            'lci_svs': round(self.lci_svs, 3),
            'lci_bvs': round(self.lci_bvs, 3),
            'resonance_score': round(self.resonance_score, 3),
            'overall_lci': round(
                (self.lci_mvs + self.lci_svs + self.lci_bvs) / 3, 3),
            'interpretation': self._interpret()
        }

    def _interpret(self):
        lci = (self.lci_mvs + self.lci_svs + self.lci_bvs) / 3
        if lci < 0.3:
            return 'ПАТОЛОГИЯ — немедленная консультация врача'
        elif lci < 0.55:
            return 'УМЕРЕННЫЕ НАРУШЕНИЯ — активная реабилитация'
        elif lci < 0.70:
            return 'СУБНОРМА — поддерживающая реабилитация'
        elif lci < 0.85:
            return 'НОРМА — профилактическая тренировка'
        else:
            return 'МАСТЕРСТВО — поддержание уровня'
```

#### 7.1 Архитектура реабилитационного робота

Реабилитационный робот, работающий по принципу трёх сфер, имеет следующую структуру:

```python
class RehabilitationRobot:
    """
    Робот-ассистент реабилитации на основе архетипов Крюкова.
    Направляет руку пациента по петлевым траекториям.
    Размер: 0.8–1.2 м высотой (уровень рабочего пространства руки).
    """

    def __init__(self):
        # Три управляющих модуля (три сферы)
        self.bvs_controller = ShoulderGuide()      # БВС: плечо
        self.svs_controller = ForearmGuide()       # СВС: предплечье
        self.mvs_controller = WristFingerGuide()   # МВС: запястье/пальцы

        # Датчики
        self.force_sensors = ForceTorqueSensor()   # Сила и момент
        self.patient_tracker = SphericalTrainer()  # LCI-трекер

        # Параметры помощи (fade-out)
        self.assistance_level = 1.0   # 1.0 = полная помощь, 0.0 = пассивно
        self.fade_out_rate = 0.01     # Снижение помощи на 1% за сессию

    def guide_loop_motion(self, loop_params, patient_intent=None):
        """
        Направлять руку пациента по петлевой траектории.
        Постепенно уменьшает помощь по мере восстановления.
        """
        target_trajectory = self._generate_loop(loop_params)

        for t, target_pos in enumerate(target_trajectory):
            # Измеряем текущую позицию пациента
            current_pos = self._get_patient_position()
            error = target_pos - current_pos

            # Вычисляем намерение пациента
            if patient_intent is not None:
                intent_vector = patient_intent[t]
            else:
                intent_vector = np.zeros(3)

            # Комбинируем помощь робота и намерение пациента
            robot_force = self.assistance_level * error * 10.0  # Жёсткость
            patient_force = (1 - self.assistance_level) * intent_vector

            total_force = robot_force + patient_force

            # Применяем по уровням (иерархически: БВС → СВС → МВС)
            self.bvs_controller.apply(total_force[:3])
            self.svs_controller.apply(total_force[3:6])
            self.mvs_controller.apply(total_force[6:])

        # Обновляем метрики
        current_lci = self.patient_tracker.lci_mvs

        # Fade-out: если LCI улучшился, снижаем помощь
        if current_lci > 0.65:
            self.assistance_level = max(0.1,
                self.assistance_level - self.fade_out_rate)

    def _generate_loop(self, params):
        """Генерировать петлевую траекторию."""
        amplitude = params.get('amplitude', 0.10)  # 10 см
        frequency = params.get('frequency', 0.5)   # 0.5 Гц (2 сек/петля)
        loop_type = params.get('type', 'figure_eight')

        t = np.linspace(0, 1/frequency, 200)

        if loop_type == 'circle':
            x = amplitude * np.cos(2 * np.pi * frequency * t)
            y = amplitude * np.sin(2 * np.pi * frequency * t)
        elif loop_type == 'figure_eight':
            x = amplitude * np.sin(2 * np.pi * frequency * t)
            y = amplitude * np.sin(4 * np.pi * frequency * t) / 2
        elif loop_type == 'ellipse':
            x = amplitude * np.cos(2 * np.pi * frequency * t)
            y = amplitude * 0.6 * np.sin(2 * np.pi * frequency * t)

        return list(zip(x, y, np.zeros(len(t))))

    def adaptive_session(self, duration_minutes=30):
        """
        Полная адаптивная сессия реабилитации.
        """
        session_log = []

        # Начинаем с маленьких петель (5 см)
        amplitude = 0.05

        for minute in range(duration_minutes):
            # Проверяем LCI каждую минуту
            report = self.patient_tracker.get_clinical_report()
            session_log.append({
                'minute': minute,
                'lci': report['overall_lci'],
                'resonance': report['resonance_score'],
                'assistance': self.assistance_level,
                'amplitude': amplitude
            })

            # Увеличиваем амплитуду если LCI достаточный
            if report['overall_lci'] > 0.70 and amplitude < 0.30:
                amplitude *= 1.10  # +10% амплитуды

            # Выполняем петлевые движения
            self.guide_loop_motion({
                'amplitude': amplitude,
                'frequency': 0.5,
                'type': 'figure_eight'
            })

        return session_log
```

## ЗАКЛЮЧЕНИЕ

Этот том демонстрирует, что система Крюкова — это не только боевое искусство. Это **теория оптимального движения**, с прямым выходом на медицинские применения.

**Ключевые выводы Тома 6:**

1. **LCI (Loop Closure Index)** — новый объективный биомаркер качества движения, применимый при БП, инсульте и ДЦП.

2. **Протокол трёх сфер** — иерархический подход к реабилитации: от БВС (грубая моторика) к МВС (тонкая моторика), а не наоборот.

3. **Резонансный протокол** — синхронизация трёх уровней через метроном/музыку восстанавливает нейромышечную координацию при БП и ДЦП.

4. **Носимый тренажёр** — устройство для объективного измерения LCI в реальном времени с геймификацией.

5. **VR-среда «Кунг-Фу Мастер»** — реабилитация через идентификацию с мастерством, а не через осознание болезни.

6. **Программа «Серебряные Петли»** — профилактика падений у пожилых через восстановление БВС.
