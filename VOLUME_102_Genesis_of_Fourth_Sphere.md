## ЧАСТЬ I: ГЛАВА 11 ТСБ — РОЖДЕНИЕ ТРЁХ СФЕР (ПЕРВОИСТОЧНИК)

### 1.1 Полный текст Главы 11 «Ещё один метод: применение шаров и сфер»

**Источник: Крюков В.В. «Тотальная Система Боя, Книга 1», стр.59**

> Это ещё один вариант описания Основного Базового Движения... Данный метод имеет широкое распространение в школах кунг-фу. Боец, прошедший по этому методу лишь самый начальный курс обучения, но зная основные положения теории, в состоянии самостоятельно выйти на мастерский уровень квалификации.

#### Технология «рождения» сфер из Главы 11:

**МВС — Малая Внутренняя Сфера:**
- Образована движениями пальцев и кистей (наименьший «шар»)
- Диаметр: от 3-4 см до длины предплечья
- Функция: «сканирующие» движения, программирование атаки

**СВС — Средняя Внутренняя Сфера:**
- Образована движениями предплечий и локтей
- Диаметр: длина предплечья — размах обоих предплечий
- Функция: блоки, захваты, средний уровень

**БВС — Большая Внешняя Сфера:**
- Образована движением всего тела бойца
- Диаметр: максимальный размах обоих рук
- Функция: перемещения, макро-атаки, захват пространства

#### 5 базовых операций с шарами (нечётное):

| # | Операция | Боевое применение |
|---|---------|-------------------|
| 1 | Вращение шара | Защита + контратака по эталонной схеме |
| 2 | Деление шара | Одновременная защита верх/низ |
| 3 | Уход от шара | Уклон под 45° — наиболее эффективный |
| 4 | Проход через шары | Вход под атаку + «печать мастерства» |
| 5 | Движение с шарами | «Кошачий шаг» — базовое перемещение |

> **Цитата Крюкова (Гл.11):** «В данной главе Автор намерен показать лишь отдельные элементы практических решений... изложить полную технологию построения (на базе этого метода) Основного Базового Движения. На основе этого материала в части 6 будут изложены принципы квалификации мастерства бойцов кунг-фу по **пяти уровням**...»

### 2.1 Полный текст ключевых фрагментов Главы 18 «Уровень 4: Направленного взрыва»

**Источник: Крюков В.В. «Тотальная Система Боя, Книга 1», стр.107**

#### Язык боя Уровня 4 — психологические ключи:

> «Языком боя бойца четвёртого уровня являются уже не технические элементы, как на предыдущих уровнях квалификации... а **образы, понятия, стихии, категории** или психологические установки...»

Образы: змея, леопард, дракон, тигр, журавль (5 образов — нечётное!)
Стихии: огонь, вода, дерево, железо, земля (5 стихий — нечётное!)

#### Характер движений — рождение 4-й системы:

> «**Характер движений бойца усложняется ещё на один порядок за счёт сканирующих движений пальцами внутри Малой Внутренней Сферы.** Пальцы бойца прорисовывают ту схему, которая идёт на выполнение. При этом происходит своеобразное **программирование** предстоящих боевых действий...»

#### Цепочка передачи (CAPSLOCK оригинала Крюкова):

> **«ПЕРЕДАЧА БОЕВЫХ СХЕМ ИЗНУТРИ НАРУЖУ ПРОИЗВОДИТСЯ ПО ЦЕПОЧКЕ:**
> **СНАЧАЛА ЧЕРЕЗ МЕЛКИЕ СУСТАВЫ (НОГТЕВЫЕ ФАЛАНГИ ПАЛЬЦЕВ, ПАЛЬЦЫ),**
> **ПОТОМ ВСЁ БОЛЕЕ И БОЛЕЕ КРУПНЫЕ (КИСТИ, ПРЕДПЛЕЧЬЯ),**
> **ПОСТЕПЕННО ВОВЛЕКАЯ В ДВИЖЕНИЕ ВСЁ ТЕЛО БОЙЦА.»**

**Это — формула ЕТД:** пальцы (nano) → МВС → СВС → БВС. Четыре уровня!

#### Спутниковая система из четырёх планет:

> **«Телодвижения бойца, работающего на четвёртом уровне квалификации, можно рассматривать как движения саттелитной системы, состоящей из вложенных друг в друга по принципу матрёшки четырёх планетарных систем. Каждая такая планетарная система двигается в своей системе координат.»**

Это и есть первое явное описание **4-сферной модели** в тексте Крюкова!

## ЧАСТЬ III: АНАЛИЗ — ОТ ТСБ К ЕТД

### 3.1 Эволюция 4-й сферы: три этапа

| Этап | Документ | Что такое 4-я сфера | Направление |
|------|----------|---------------------|-------------|
| ТСБ 1994 (Кн.1, Гл.18) | Пальцы (ногтевые фаланги) | **Вовнутрь** (микро-уровень ниже МВС) |
| ТСБ 2003 (Кн.3) | Физический инструмент (шест, меч, ключ) | **Наружу** (макро-уровень выше БВС) |
| ЕТД 2024+ (Тома 100-101) | Абстрактная задача/домен/контекст | **Наружу** (концептуальный уровень) |

**Ключевое открытие:** 4-я сфера сначала была **внутренней** (пальцы, nano-уровень), а потом **внешней** (инструмент, context). ЧВС ЕТД = эволюция исходной концепции пальцев в концепцию внешнего адаптера!

### 3.2 Картина боя Уровня 4 (рис.18.3 в тексте)

```
Условные обозначения Крюкова:
  (—)  = реализованные движения          → БВС-уровень
  ( )  = условно выполненные движения    → БВС-уровень
  [-]  = элементы на базе СВС            → СВС-уровень
  [•]  = элементы на базе МВС            → МВС-уровень
  [O]  = элементы, кодированные пальцами → 4-я сфера (пальцы)

Итого: 4 типа элементов = 4 сферы = 4 планетарные системы
```

### 3.3 Почему пальцы = ЧВС v1.0?

Из Главы 18:
> «Поэтому, когда пальцы бойца кунг-фу заковывают в бинты и перчатки, то ему выдавать "на гора" имеющиеся у него в арсенале технические приемы **много сложнее**: одно из важнейших "передаточных колёс" движений бойца — **блокировано**...»

Это в точности концепция ЧВС: **если 4-я сфера отключена (remove_CHS()), система деградирует к 3-сферному режиму**. Пальцы = первый исторический ЧВС-plug-in!

```python
def enforce_odd(value: int, name: str) -> int:

DIRECTION_HISTORY = {

@dataclass

    def __post_init__(self):
        enforce_odd(self.n_active_levels, "n_active_levels")


class FourthSphereDirCHS(ABC):
    direction_type: FourthSphereDirection

    @abstractmethod
    def compute_direction_fit(self) -> float: ...
    @abstractmethod
    def compute_evolution_coverage(self) -> float: ...
    @abstractmethod
    def sphere_nesting_score(self) -> float: ...

    def get_context(self) -> GenesisContext:
        return GenesisContext(
            direction_type     = self.direction_type,
            class_name         = self.__class__.__name__,
            direction_fit      = self.compute_direction_fit(),
            evolution_coverage = self.compute_evolution_coverage(),
            history            = DIRECTION_HISTORY[self.direction_type],
        )

    """
    Внутреннее: пальцы как 4-я планетарная система (ТСБ Книга 1, 1994)

    """
    Система для анализа ГЕНЕЗИСА 4-й сферы.
    МВС = Пальцы / ногтевые фаланги

        print(f"[FREEZE] 3-сферное тело зафиксировано (ТСБ Кн.1 Гл.11)")
        print(f"  МВС=пальцы/кисти | СВС=предплечья | БВС=всё тело")

    def set_direction(self, direction: FourthSphereDirCHS):
        if not self._body_frozen:
            raise RuntimeError("Сначала вызовите freeze_body()")
        self._active_dir = direction
        ctx = direction.get_context()
        print(f"[ЧВС SET] {ctx.class_name}")
        print(f"  История: {ctx.history}")
        print(f"  {direction}")

    def remove_direction(self):
        removed = self._active_dir.__class__.__name__ if self._active_dir else "None"
        self._active_dir = None
        print(f"[ЧВС REMOVE] {removed}")

    def compute_4sphere_lci(self) -> Dict:
        """ЛЗП v2.0 = sphere_nesting × direction_fit × evolution_coverage"""
        if not self._active_dir:
            raise RuntimeError("ЧВС не установлена")
        ctx = self._active_dir.get_context()

        nesting      = self._active_dir.sphere_nesting_score()
        dir_fit      = ctx.direction_fit
        evo_coverage = ctx.evolution_coverage

        # Нечётный бонус: 5 уровней мастерства
        odd_bonus = 0.07 if (self._n_mastery_levels % 2 == 1) else 0.0
        resonance  = nesting * odd_bonus

        lci_v1 = nesting
        lci_v2 = nesting * dir_fit * evo_coverage + resonance * 0.1

        # Для Internal (пальцы): спец. расчёт с π/4
        note = ""
        if ctx.direction_type == FourthSphereDirection.INTERNAL:
            lci_pi4 = PI_4 * dir_fit * evo_coverage + resonance * 0.1
            note = f"→ π/4 path: {lci_pi4:.4f}"

        return {
            'direction':      ctx.direction_type.value,
            'history':        ctx.history,
            'nesting':        round(nesting, 4),
            'direction_fit':  round(dir_fit, 4),
            'evo_coverage':   round(evo_coverage, 4),
            'lci_v1':         round(lci_v1, 4),
            'lci_v2':         round(lci_v2, 4),
            'pi_4':           round(PI_4, 4),
            'note':           note,
        }

    def audit_9axioms(self) -> Dict:
        if not self._active_dir:
            raise RuntimeError("ЧВС не установлена")
        ctx = self._active_dir.get_context()
        axioms = {
            'A1': ('Матрёшка сфер (МВС⊂СВС⊂БВС⊂ЧВС)',            True),
            'A2': ('Передача изнутри наружу (пальцы→тело)',         True),
            'A3': ('Сохранение боевой схемы при смене ЧВС',         True),
            'A4': ('Минимальность: пальцы = эффективнейший plug-in', True),
            'A5': ('5 уровней мастерства = нечётное',               self._n_mastery_levels % 2 == 1),
            'A6': ('5 образов зверей = нечётное',                   self._n_beast_images % 2 == 1),
            'A7': ('5 операций с шаром = нечётное',                 self._n_ball_ops % 2 == 1),
            'A8': ('ЧВС direction_fit >= 0.70',                     ctx.direction_fit >= 0.70),
            'A9': ('ЧВС evolution_coverage >= 5/9',                 ctx.evolution_coverage >= 5/9),
        }
        passed = sum(1 for _, (_, ok) in axioms.items() if ok)
        return {'passed': passed, 'total': 9, 'score': round(passed/9, 3)}

        audit = system.audit_9axioms()
        results.append((name, lci, audit))
        system.remove_direction()
        print()

    print(f"\n{'Направление':<12} | {'Nesting':>7} | {'Fit':>5} | {'LCI v1':>7} | {'LCI v2':>7} | {'Ax':>4} | История")
    print("-" * 90)
    for name, lci, audit in results:
        hist = lci['history'][:35]
        print(f"{name:<12} | {lci['nesting']:>7.4f} | {lci['direction_fit']:>5.2f} "
              f"| {lci['lci_v1']:>7.4f} | {lci['lci_v2']:>7.4f} | {audit['passed']}/9 | {hist}")
```

### 6.2 Закон развития ЧВС

**Теорема 102.v1 (направление эволюции):**
Четвёртая сфера эволюционирует в двух направлениях одновременно:
1. **Вглубь** (внутрь): нано-уровень = ногтевые фаланги пальцев
2. **Вширь** (наружу): макро-уровень = инструмент → домен → среда → виртуал

**Доказательство:**
- 1994 (Гл.18): «4-я планетарная система» = пальцы → **вглубь**
- 2003 (Кн.3): инструмент в руках = физический предмет → **наружу**
- 2024 (vol 100): рабочая задача робота = абстракция → **наружу+концептуально**
- Конвергенция: обе ветви встречаются в Domain (максимальный LCI v2.0 = 0.873)
