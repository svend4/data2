## ЧАСТЬ I: 4 ЗАКОНА СОХРАНЕНИЯ В СИСТЕМЕ 4 СФЕР

### Закон I: Сохранение энергии

**Физика**: Полная энергия системы (кинетическая + потенциальная) сохраняется при отсутствии диссипации.

```
E = T + U = const
```

**ЕТД-интерпретация**: Суммарный потенциал системы 4 сфер сохраняется при переключении ЧВС.

```python
def energy_conservation(bvs_energy: float, svs_energy: float,
                        mvs_energy: float, cvs_energy: float) -> float:
    """
    Закон сохранения энергии в 4-сферной системе.
    При смене ЧВС сумма остаётся постоянной.
    """
    total = bvs_energy + svs_energy + mvs_energy + cvs_energy
    # При ЧВС-переключении: cvs_energy меняется,
    # но (bvs + svs + mvs + cvs) = const = LCI_total
    return total
```

**Аксиома E**: Смена ЧВС перераспределяет, но не уничтожает энергию системы. Уход из одного домена = вход в другой с той же энергией.

### Закон II: Сохранение обобщённого импульса

**Физика**: При отсутствии обобщённой силы — обобщённый импульс `p = ∂L/∂q̇` сохраняется.

```
p = m·v = const  (при отсутствии внешних сил)
```

**ЕТД-интерпретация**: Направление движения системы сохраняется при переключении ЧВС.

```python
@dataclass
class SphereImpulse:
    """Обобщённый импульс 4-сферной системы"""
    direction: tuple  # (dx, dy, dz) - направление движения
    magnitude: float  # |p| = m·v

    def switch_cvs(self, new_cvs: str) -> 'SphereImpulse':
        """
        При смене ЧВС импульс НЕ исчезает — он перенаправляется.
        Тот же импульс — новый инструмент/контекст.
        """
        return SphereImpulse(
            direction=self.direction,   # СОХРАНЯЕТСЯ
            magnitude=self.magnitude    # СОХРАНЯЕТСЯ
        )
```

**Аксиома P**: Тактический вектор (намерение бойца) сохраняется при смене ЧВС. Одна и та же цель — разные инструменты.

### Закон III: Сохранение количества движения

**Физика**: Вектор количества движения центра масс системы:

```
p_cm = M · v_cm = const  (нет внешних сил)
```

**ЕТД-интерпретация**: Движение центра тела (БВС) не прерывается при активации МВС, СВС или ЧВС.

```python
class SphereSystem:
    """Система 4 сфер с законами сохранения"""

    def __init__(self):
        self.bvs_velocity = 0.0  # скорость тела
        self.svs_velocity = 0.0  # скорость предплечий
        self.mvs_velocity = 0.0  # скорость кистей
        self.cvs_velocity = 0.0  # скорость ЧВС-переключения

    @property
    def center_of_mass_velocity(self) -> float:
        """
        Скорость центра масс системы = сохраняется.
        МВС/СВС добавляют локальную скорость,
        но v_cm тела не прерывается.
        """
        # Упрощённая модель: центр масс ≈ БВС
        return self.bvs_velocity

    def activate_mvs(self, mvs_impulse: float):
        """МВС активируется НЕ останавливая БВС"""
        self.mvs_velocity += mvs_impulse
        # bvs_velocity НЕ МЕНЯЕТСЯ — закон сохранения
```

**Аксиома Q**: Тело бойца движется непрерывно. МВС и СВС — это «волны на поверхности океана», а не остановка океана.

### Закон IV: Сохранение кинетического момента → ЗАКОН π/4

**Физика**: Момент количества движения (угловой момент):

```
L = I · ω = r × p = const  (нет моментов внешних сил)
```

где `I` — момент инерции, `ω` — угловая скорость.

**ЕТД-интерпретация**: Это самый важный из 4 законов для ЕТД!

Если система вращается с угловой скоростью `ω` и **момент инерции I не меняется**, то **ω = const**.

Для сферы: `I = (2/5)·m·R²`

При переключении ЧВС (смена радиуса сферы R):

```
I₁·ω₁ = I₂·ω₂

(2/5)·m·R₁²·ω₁ = (2/5)·m·R₂²·ω₂

ω₂ = ω₁·(R₁/R₂)²
```

**Ключевой результат**: При переходе МВС→СВС→БВС радиус увеличивается, угловая скорость уменьшается. При переходе БВС→МВС — наоборот.

```python
def angular_velocity_after_switch(omega_1: float, R_1: float, R_2: float) -> float:
    """
    Угловая скорость сферы после смены ЧВС (новый радиус).
    Закон сохранения кинетического момента.
    """
    return omega_1 * (R_1 / R_2) ** 2


# Типовые радиусы сфер ЕТД
R_MVS = 0.3   # метра (кисть)
R_SVS = 0.6   # метра (предплечье)
R_BVS = 1.0   # метра (тело)
R_CVS = None  # ЧВС не имеет физического радиуса — контекст

# При переходе МВС → БВС:
omega_BVS = angular_velocity_after_switch(omega_1=1.0, R_1=R_MVS, R_2=R_BVS)
# omega_BVS = 1.0 × (0.3/1.0)² = 0.09
# Тело вращается медленнее — но с бо́льшим моментом инерции
# L = I·ω = const ✓
```

## ЧАСТЬ II: КАК ЗАКОНЫ СОХРАНЕНИЯ ПОРОЖДАЮТ УСЛОВИЕ π/4

### 2.1 Оптимальный кинетический момент

При каком распределении энергии между сферами суммарный кинетический момент максимален?

```
L_total = L_BVS + L_SVS + L_MVS + L_CVS
        = I_BVS·ω + I_SVS·ω + I_MVS·ω + I_CVS·ω

Максимизируем L_total при условии E_total = const:

∂L/∂ω = 0  →  оптимальное ω
```

При равном распределении энергии между 4 сферами:

```
E_BVS = E_SVS = E_MVS = E_CVS = E_total/4

L_i = √(2·I_i·E_i)

Для равновесия: угол между компонентами = π/4
```

### 2.2 Теорема об угле π/4

**Теорема**: В системе 4 равноэнергетических вращающихся сфер угол оптимальной синхронизации = π/4.

**Доказательство**:

```
Пусть ω₁ = ω·cos(α), ω₂ = ω·cos(π/2 - α) = ω·sin(α)
(проекции на две оси)

Суммарный момент: L = I₁·ω·cos(α) + I₂·ω·sin(α)

dL/dα = -I₁·ω·sin(α) + I₂·ω·cos(α) = 0

tan(α) = I₂/I₁

При I₁ = I₂ (равные моменты инерции):
tan(α) = 1  →  α = π/4  ✓
```

> **Условие π/4 ЕТД = условие равных моментов инерции всех 4 сфер = условие максимального суммарного кинетического момента системы.**

| Закон сохранения | Физическая величина | Аксиома ЕТД | Формула |
|-----------------|--------------------|--------------|---------|
| Энергии | E = T + U = const | A-E: Смена ЧВС перераспределяет, не уничтожает энергию | ΣE_сфер = ЛЗП = const |
| Обобщённого импульса | p = ∂L/∂q̇ = const | A-P: Тактический вектор сохраняется при смене ЧВС | p_вектор → неизменен |

| **Кинетического момента** | **L = I·ω = const** | **A-L: Угол синхронизации сфер = π/4 при I₁=I₂=I₃=I₄** | **α* = π/4** |

## ЧАСТЬ IV: ПРАКТИЧЕСКИЕ СЛЕДСТВИЯ

### 4.1 Почему нельзя «остановить» одну сферу

Из Закона III (сохранение количества движения):
- Остановка БВС требует внешней силы (противник)
- МВС и СВС не могут остановить БВС — только перенаправить

### 4.2 Почему ЧВС переключается мгновенно

Из Закона I (сохранение энергии):
- ЧВС = контекст, не имеет физической массы
- Переключение ЧВС не требует энергетических затрат (нет инерции)
- ЧВС переключается со скоростью мысли

### 4.3 Почему угол атаки = π/4 оптимален

Из Закона IV (кинетический момент):
- Угол π/4 = равновесие всех 4 составляющих момента
- Любое отклонение от π/4 → потеря суммарного ЛЗП
- Мастер ЕТД → постоянное поддержание угла π/4

### 4.4 Код: Полная модель законов сохранения

```python
from dataclasses import dataclass
import math

@dataclass
class SphereDynamics:
    """Динамика 4-сферной системы с законами сохранения"""

    # Моменты инерции сфер
    I_bvs: float = 0.4    # кг·м² (тело)
    I_svs: float = 0.05   # кг·м² (предплечья)
    I_mvs: float = 0.01   # кг·м² (кисти)
    I_cvs: float = 0.0    # ЧВС не имеет инерции

    # Угловые скорости
    omega_bvs: float = 1.0   # рад/с
    omega_svs: float = 2.0
    omega_mvs: float = 6.0
    omega_cvs: float = float('inf')  # мгновенное переключение

    @property
    def angular_momentum(self) -> float:
        """L = Σ(I·ω) = const"""
        return (self.I_bvs * self.omega_bvs +
                self.I_svs * self.omega_svs +
                self.I_mvs * self.omega_mvs)

    @property
    def kinetic_energy(self) -> float:
        """T = Σ(I·ω²/2) = const"""
        return 0.5 * (self.I_bvs * self.omega_bvs**2 +
                      self.I_svs * self.omega_svs**2 +
                      self.I_mvs * self.omega_mvs**2)

    @property
    def sync_angle(self) -> float:
        """Угол синхронизации (оптимум = π/4)"""
        ratio = self.omega_mvs / self.omega_bvs
        return math.atan(ratio)

    def is_optimized(self, tolerance: float = 0.05) -> bool:
        """Проверка оптимума π/4"""
        return abs(self.sync_angle - math.pi/4) < tolerance

    def switch_cvs(self, new_context: str) -> 'SphereDynamics':
        """
        Переключение ЧВС: сохраняем L и E,
        перераспределяем при необходимости.
        """
        # ЧВС меняется мгновенно, тело продолжает движение
        return SphereDynamics(
            I_bvs=self.I_bvs,
            I_svs=self.I_svs,
            I_mvs=self.I_mvs,
            I_cvs=0.0,
            omega_bvs=self.omega_bvs,   # сохраняется
            omega_svs=self.omega_svs,   # сохраняется
            omega_mvs=self.omega_mvs,   # сохраняется
            omega_cvs=float('inf')      # мгновенное переключение
        )
```
