## ВВЕДЕНИЕ: 4 ОСОБЫЕ ТОЧКИ ДИНАМИЧЕСКИХ СИСТЕМ

Франц Герман (стр. 3):
> «4 типа особых точек: **узел, седло, фокус, центр**»

В теории дифференциальных уравнений эти 4 типа описывают **все возможные поведения** динамической системы вблизи точки равновесия. Они исчерпывающи — других типов нет.

**Тезис тома**: Любая боевая ситуация в системе ЕТД имеет **топологический тип** из этих четырёх — узел, седло, фокус или центр. Распознав тип, боец автоматически знает оптимальное решение.

## ЧАСТЬ I: 4 ТИПА ОСОБЫХ ТОЧЕК — ФИЗИЧЕСКОЕ ОПИСАНИЕ

### 1.1 УЗЕЛ (Node)

**Математика**: Все фазовые траектории сходятся к точке равновесия (или расходятся от неё).

```
Устойчивый узел:          Неустойчивый узел:
    ↘ ↓ ↙                    ↗ ↑ ↖
    → ● ←      vs            ← ● →
    ↗ ↑ ↖                    ↘ ↓ ↙
```

**ЕТД-смысл УЗЛА**: Стяжка — момент жёсткой фиксации удара / захвата.

- **Устойчивый узел** = удар/бросок завершился, противник зафиксирован
- **Неустойчивый узел** = начало взрыва (старт мощного удара): все траектории расходятся от центра тела

**Характеристики узла в ЕТД**:
```python
class NodePoint:
    """Узловая точка — стяжка/фиксация"""
    phase = "завершение"
    sphere_behavior = "все сферы движутся к единой точке"
    lci_change = "максимальный ЛЗП → стабилизация"
    time_scale = "короткое (0.05-0.1 с)"
    cvs_role = "ЧВС фиксирует контекст (не переключается)"

    @staticmethod
    def detect(sphere_velocities: dict) -> bool:
        """Узел: все скорости сфер коллинеарны и сходятся"""
        vecs = list(sphere_velocities.values())
        # Упрощённая проверка: все векторы сонаправлены
        return all(v > 0 for v in vecs) or all(v < 0 for v in vecs)
```

### 1.2 СЕДЛО (Saddle)

**Математика**: Одни траектории сходятся к точке (устойчивые направления), другие расходятся (неустойчивые). Сама точка неустойчива.

```
     ↑  ↑
← ← ● → →
     ↓  ↓
```

**ЕТД-смысл СЕДЛА**: Момент выбора схемы / развилка.

Система находится в точке, где **одни варианты ведут к победе** (сходящиеся траектории), а **другие — к поражению** (расходящиеся). Это самая опасная точка схватки.

- Устойчивые направления (вдоль «сёдла»): правильный ЧВС-выбор
- Неустойчивые направления: ошибочный ЧВС-выбор

**Характеристики седла**:
```python
class SaddlePoint:
    """Седловая точка — момент критического выбора ЧВС"""
    phase = "развилка"
    sphere_behavior = "МВС/СВС сходятся, БВС расходится (или наоборот)"
    lci_change = "нестабильный ЛЗП — может как вырасти, так и упасть"
    time_scale = "мгновенное (< 0.05 с)"
    cvs_role = "ЧВС ДОЛЖНО переключиться — иначе система уходит в неустойчивость"

    @staticmethod
    def requires_cvs_switch() -> bool:
        """В седловой точке переключение ЧВС — ОБЯЗАТЕЛЬНО"""
        return True
```

**Практика**: Боец в седловой точке = «поймал чужое движение» и должен **мгновенно** переключить ЧВС (выбрать домен: добавить, убрать, перенаправить). Промедление = падение по неустойчивой траектории.

### 1.3 ФОКУС (Focus / Spiral)

**Математика**: Траектории спирально сходятся к точке (устойчивый фокус) или расходятся по спирали (неустойчивый фокус).

```
Устойчивый фокус:     Неустойчивый фокус:
  ↙ ← ↖              ↗ → ↘
  ↓  ●  ↑            ↑  ●  ↓
  ↘ → ↗              ↙ ← ↖
  (затухающая спираль)  (нарастающая спираль)
```

**ЕТД-смысл ФОКУСА**: Захват / входение в зону сферы.

- **Устойчивый фокус** = захват: постепенное спиральное приближение к противнику
- **Неустойчивый фокус** = выход из клинча: спиральное разворачивание

**Характеристики фокуса**:
```python
class FocusPoint:
    """Фокус — захват/спираль, плавное вхождение в контакт"""
    phase = "сближение / контроль"
    sphere_behavior = "ЧВС управляет спиральной траекторией МВС/СВС"
    lci_change = "плавное нарастание или убывание ЛЗП"
    time_scale = "длительное (0.2-1.0 с)"
    cvs_role = "ЧВС задаёт ось спирали"

    @staticmethod
    def spiral_trajectory(radius_0: float, omega: float,
                         decay: float, t: float) -> tuple:
        """
        Спиральная траектория входа в контакт.
        radius(t) = r0 · e^(-decay·t)
        angle(t) = omega · t
        """
        import math
        r = radius_0 * math.exp(-decay * t)
        angle = omega * t
        x = r * math.cos(angle)
        y = r * math.sin(angle)
        return (x, y, r)
```

**Связь с ЕТД**: Многие техники Тай-Цзи, Айкидо, захваты — это **устойчивые фокусы** в пространстве 4 сфер. ЧВС при этом = ось вращения спирали.

### 1.4 ЦЕНТР (Center)

**Математика**: Замкнутые орбиты вокруг точки равновесия. Система вечно движется по периодическим траекториям — никуда не сходясь.

```
  ← ←
↓      ↑
↓  ●   ↑
↓      ↑
  → →
```

**ЕТД-смысл ЦЕНТРА**: Нейтральное движение / пасс / уход.

Система движется по замкнутым орбитам — **не теряя и не набирая ЛЗП**. Это состояние «нейтрального контакта» — пасс, уход, нейтрализация без контратаки.

**Характеристики центра**:
```python
class CenterPoint:
    """Центр — замкнутые орбиты, нейтральное движение, пасс"""
    phase = "нейтрализация"
    sphere_behavior = "все сферы движутся по замкнутым орбитам"
    lci_change = "ЛЗП = const (нет приобретения, нет потери)"
    time_scale = "циклическое (повторяющееся)"
    cvs_role = "ЧВС не переключается — поддерживает орбиту"

    @staticmethod
    def orbital_period(omega: float) -> float:
        """Период замкнутой орбиты = 2π/ω"""
        import math
        return 2 * math.pi / omega
```

**Практика**: Уход от удара по круговой траектории без встречного действия = **центр**. Круговой пасс ногой (подпрыжка) = центральная орбита МВС/СВС.

## ЧАСТЬ II: ТОПОЛОГИЧЕСКАЯ КАРТА СХВАТКИ

### 2.1 Последовательность особых точек

Типичная схватка в ЕТД = последовательность особых точек:

```
Старт
  ↓
[ЦЕНТР]         ← нейтральная позиция, разведка
  ↓
[ФОКУС]         ← сближение, входение в зону
  ↓
[СЕДЛО]         ← момент выбора схемы, переключение ЧВС
  ↓
[УЗЕЛ]          ← нанесение удара/захвата, фиксация
  ↓
[ЦЕНТР]         ← возврат в нейтраль или новый цикл
```

### 2.2 Код классификатора особых точек

```python
from enum import Enum
from dataclasses import dataclass

class SingularityType(Enum):
    NODE   = "узел"    # стяжка/фиксация
    SADDLE = "седло"   # развилка/выбор ЧВС
    FOCUS  = "фокус"   # захват/спираль
    CENTER = "центр"   # нейтраль/пасс

@dataclass
class SphereTrajectoryPoint:
    """Точка на траектории системы 4 сфер"""
    lci: float              # текущий ЛЗП
    lci_derivative: float   # dЛЗП/dt
    omega: float            # угловая скорость
    is_cvs_switching: bool  # идёт ли переключение ЧВС

    def classify(self) -> SingularityType:
        """Определение типа особой точки по параметрам"""

        if self.is_cvs_switching and abs(self.lci_derivative) > 0.5:
            return SingularityType.SADDLE   # критический выбор

        if abs(self.omega) > 2.0 and self.lci_derivative < -0.1:
            return SingularityType.FOCUS    # спиральное сближение

        if abs(self.lci_derivative) < 0.05 and abs(self.omega) > 0.1:
            return SingularityType.CENTER   # замкнутая орбита

        if abs(self.lci_derivative) > 0.5 and abs(self.omega) < 0.5:
            return SingularityType.NODE     # стяжка (сходимость)

        return SingularityType.CENTER       # по умолчанию

    def recommended_cvs_action(self) -> str:
        """Рекомендуемое действие ЧВС для данного типа точки"""
        actions = {
            SingularityType.NODE:   "Зафиксировать текущую ЧВС",
            SingularityType.SADDLE: "СРОЧНО переключить ЧВС (выбрать схему)",
            SingularityType.FOCUS:  "Поддерживать ЧВС как ось спирали",
            SingularityType.CENTER: "ЧВС не трогать — поддерживать орбиту",
        }
        return actions[self.classify()]
```

## ЧАСТЬ III: 4 ТИПА ТОЧЕК → 4 ТАКТИЧЕСКИХ РЕЖИМА ЕТД

| Особая точка | Тактический режим | ЧВС | Пример техники |
|-------------|-------------------|-----|----------------|
| **Узел устойч.** | Атака (завершение) | Зафиксирована | Прямой удар: контакт → ЛЗП сходится |
| **Узел неустойч.** | Взрыв (старт) | Зафиксирована | Старт с места: все сферы расходятся |
| **Седло** | Выбор / переключение | ОБЯЗАТЕЛЬНО переключить | Захват → освобождение → контратака |
| **Фокус устойч.** | Контроль / захват | Ось спирали | Мельница, захват с скручиванием |
| **Фокус неустойч.** | Выход из захвата | Обратная спираль | Освобождение от захвата |
| **Центр** | Нейтраль / пасс | Не переключается | Уход, блок без контратаки |

## ЧАСТЬ IV: ФАЗОВЫЙ ПОРТРЕТ СХВАТКИ

### 4.1 Концепция фазового портрета

Фазовый портрет = полная картина всех траекторий системы в пространстве (ЛЗП, dЛЗП/dt).

```
dЛЗП/dt
  ↑
  |  ↗      ← неустойчивый узел (взрыв)
  | ↗↗
--+-------→  ЛЗП
  | ↘↘
  |  ↘      ← устойчивый узел (стяжка)
```

### 4.2 Матрица переходов между типами

```
ИЗ\В    Узел  Седло  Фокус  Центр
Узел     -      -     нет    да
Седло   да      -     да     да
Фокус    -     нет    -      да
Центр   нет    да    да      -
```

**Читать как**: «из Узла можно перейти в Центр (после фиксации — нейтраль), но нельзя сразу в Фокус»

### 4.3 Код фазового портрета схватки

```python
from typing import List

class CombatPhasePortrait:
    """Фазовый портрет схватки в пространстве ЛЗП"""

    def __init__(self):
        self.trajectory: List[SphereTrajectoryPoint] = []
        self.phase_sequence: List[SingularityType] = []

    def add_moment(self, point: SphereTrajectoryPoint):
        """Записать момент схватки"""
        self.trajectory.append(point)
        current_type = point.classify()

        # Записываем только смену типа (не повторы)
        if not self.phase_sequence or self.phase_sequence[-1] != current_type:
            self.phase_sequence.append(current_type)

    def analyze(self) -> str:
        """Анализ тактической структуры схватки"""
        sequence = [s.value for s in self.phase_sequence]
        pattern = " → ".join(sequence)

        is_optimal = (
            self.phase_sequence == [
                SingularityType.CENTER,
                SingularityType.FOCUS,
                SingularityType.SADDLE,
                SingularityType.NODE
            ]
        )

        return f"Паттерн: {pattern}\nОптимален: {is_optimal}"
```

## ЧАСТЬ V: 4 ОСОБЫЕ ТОЧКИ И 4 СФЕРЫ

### 5.1 Соответствие точек и сфер

| Особая точка | Ведущая сфера | Объяснение |
|-------------|--------------|------------|
| **Узел** | БВС | Тело фиксирует — масса создаёт стяжку |
| **Седло** | ЧВС | Только ЧВС-переключение разрешает развилку |
| **Фокус** | СВС | Предплечья управляют спиральным движением |
| **Центр** | МВС | Кисти поддерживают мягкий контакт на орбите |

### 5.2 «Четвёрка порождает четвёрку» (Герман)

Четыре сферы → четыре особые точки:
- **БВС** (масса) → **Узел** (притяжение, сходимость)
- **ЧВС** (контекст) → **Седло** (развилка, выбор)
- **СВС** (ротация) → **Фокус** (спираль, закручивание)
- **МВС** (контакт) → **Центр** (орбита, мягкость)

## ЗАКЛЮЧЕНИЕ

4 типа особых точек (узел, седло, фокус, центр) — это **полная классификация** всех возможных тактических ситуаций в схватке ЕТД:

1. **Узел** = стяжка, удар, фиксация (БВС ведёт)
2. **Седло** = выбор схемы, переключение ЧВС (КРИТИЧНО!)
3. **Фокус** = захват, спираль, контроль (СВС ведёт)
4. **Центр** = нейтраль, пасс, разведка (МВС ведёт)

> Мастер ЕТД распознаёт тип текущей точки **мгновенно** и действует согласно топологии: в Седле — переключает ЧВС; в Узле — фиксирует; в Фокусе — закручивает; в Центре — наблюдает.

> «Четыре типа особых точек определяют топологию любой динамической системы» (Герман) → Четыре тактических режима определяют топологию любой схватки (ЕТД).
