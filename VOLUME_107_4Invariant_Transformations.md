## ЧАСТЬ I: 4 ПРЕОБРАЗОВАНИЯ И ИХ ЕТД-АНАЛОГИ

### Преобразование I: ПАРАЛЛЕЛЬНЫЙ ПЕРЕНОС (Трансляция)

**Физика**: Уравнения физики одинаковы в Москве и в Токио. Законы природы не зависят от места.

```
Математически: x' = x + a (сдвиг на вектор a)
Инвариант:     F(x') = F(x)  →  закон сохранения импульса
```

**ЕТД-аналог**: Уравнение ЛЗП системы 4 сфер **не зависит от места схватки**.

```python
def lci_translation_invariance(lci_func, sphere_state, translation_vector):
    """
    Проверка инвариантности ЛЗП при параллельном переносе.
    Переносим всю систему сфер на вектор a.
    ЛЗП не меняется — только позиции центров, не сам потенциал.
    """
    # Исходное состояние
    lci_original = lci_func(sphere_state)

    # Перенос: все ρ_сфер сдвигаются на вектор a
    translated_state = {
        sphere: {**params, 'rho': params['rho'] + translation_vector}
        for sphere, params in sphere_state.items()
    }
    lci_translated = lci_func(translated_state)

    # ЛЗП ИНВАРИАНТЕН:
    assert abs(lci_original - lci_translated) < 1e-10

    return True
```

**Следствие для ЕТД**:
- Техника, работающая у стены — работает и на открытом пространстве
- ЛЗП не зависит от позиции в зале/ринге
- **Закон сохранения**: Суммарный «импульс» системы сфер сохраняется при трансляции

**Аксиома T**: *Эффективность схемы ЕТД не зависит от места её применения.*

### Преобразование II: ПРОСТРАНСТВЕННЫЕ ВРАЩЕНИЯ

**Физика**: Уравнения физики одинаковы при любой ориентации системы отсчёта.

```
Математически: x' = R·x (поворот матрицей R)
Инвариант:     F(R·x) = F(x)  →  закон сохранения момента импульса
```

**ЕТД-аналог**: ЛЗП системы сфер **инвариантен при повороте всей системы**.

```python
import math

def rotation_matrix_z(angle: float) -> list:
    """Матрица поворота вокруг оси Z"""
    c, s = math.cos(angle), math.sin(angle)
    return [
        [c, -s, 0],
        [s,  c, 0],
        [0,  0, 1]
    ]

def rotate_direction(direction: tuple, angle: float) -> tuple:
    """Поворот вектора направления на угол"""
    R = rotation_matrix_z(angle)
    x, y, z = direction
    return (
        R[0][0]*x + R[0][1]*y + R[0][2]*z,
        R[1][0]*x + R[1][1]*y + R[1][2]*z,
        R[2][0]*x + R[2][1]*y + R[2][2]*z
    )

def lci_rotation_invariance(lci_func, sphere_state, angle):
    """
    ЛЗП инвариантен при повороте всей системы сфер.
    Повернём систему на произвольный угол — ЛЗП тот же.
    """
    rotated_state = {
        sphere: {
            **params,
            'direction': rotate_direction(params['direction'], angle)
        }
        for sphere, params in sphere_state.items()
    }
    return abs(lci_func(sphere_state) - lci_func(rotated_state)) < 1e-10
```

**Следствие для ЕТД**:
- Удар, нанесённый правой рукой → при повороте тела на 90° даёт тот же ЛЗП левой рукой
- Схема работает в любой ориентации бойца (лицом, боком, спиной)
- **Закон сохранения**: Кинетический момент системы сфер сохраняется при вращении

**Аксиома R**: *Схема ЕТД инвариантна при повороте тела бойца на любой угол.*

### Преобразование III: ПРЕОБРАЗОВАНИЯ ЛОРЕНЦА (Принцип относительности)

**Физика**: Законы физики одинаковы для всех инерциальных наблюдателей (движущихся с постоянной скоростью).

```
Математически: t' = γ(t - vx/c²), x' = γ(x - vt)
               γ = 1/√(1 - v²/c²)
Инвариант:     s² = c²t² - x² - y² - z² = const
```

**ЕТД-аналог**: ЛЗП системы сфер **инвариантен при изменении скорости всей системы** (переходе к движущейся системе отсчёта).

Это самое глубокое из 4 преобразований для ЕТД:

```python
class LorentzInvarianceETD:
    """
    Принцип относительности ЕТД.
    Схема 4 сфер работает независимо от скорости
    движения системы боец-противник.
    """

    def __init__(self, c_etd: float = 10.0):
        """
        c_etd = характеристическая скорость системы ЕТД
                (аналог скорости света в теории ЛЗП)
                ≈ максимальная скорость переключения ЧВС
        """
        self.c = c_etd

    def lorentz_factor(self, v: float) -> float:
        """γ = 1/√(1 - (v/c)²)"""
        return 1.0 / math.sqrt(1 - (v/self.c)**2)

    def invariant_interval(self, lci: float, t: float, rho: float) -> float:
        """
        Инвариантный интервал ЕТД:
        s² = (c·t)² - ρ² - ЛЗП² = const
        аналог интервала Минковского
        """
        return math.sqrt((self.c * t)**2 - rho**2 - lci**2)

    def time_dilation_in_combat(self, t_rest: float, v: float) -> float:
        """
        'Замедление времени' в бою:
        При высокой скорости переключения ЧВС
        'субъективное время' противника растягивается.
        Боец в состоянии потока (v → c_etd) видит больше.
        """
        gamma = self.lorentz_factor(v)
        return t_rest * gamma
```

**Следствие для ЕТД**:
- Схема 4 сфер работает одинаково: в медленном спарринге и в реальной схватке
- ЛЗП = инвариант Лоренца ЕТД: не зависит от «скорости наблюдателя»
- Состояние потока (мастер ЕТД) = движение со скоростью близкой к `c_etd` → восприятие времени растягивается (субъективное «замедление»)

**Аксиома L**: *ЛЗП системы сфер инвариантен при изменении темпа схватки. Принцип относительности ЕТД: одна и та же схема эффективна в медленном и быстром движении.*

### Преобразование IV: ИНВЕРСИЯ (Зеркальное отражение)

**Физика**: Некоторые законы симметричны при зеркальном отражении (x → -x), некоторые — нет (нарушение P-симметрии в слабом взаимодействии).

```
Математически: x' = -x (инверсия координат)
Инвариант:     F(-x) = F(x) — чётные функции
               F(-x) = -F(x) — нечётные функции
```

**ЕТД-аналог**: Схема «правой» руки зеркально отражается в схему «левой» руки.

```python
def mirror_scheme(scheme: dict) -> dict:
    """
    Зеркальное отражение схемы ЕТД:
    правая рука ↔ левая рука
    ЛЗП при этом СОХРАНЯЕТСЯ (инвариантен).
    """
    mirrored = {}
    for sphere, params in scheme.items():
        mirrored_direction = (
            -params['direction'][0],  # X инвертируется (право↔лево)
             params['direction'][1],  # Y сохраняется (верх/низ)
             params['direction'][2]   # Z сохраняется (вперёд/назад)
        )
        mirrored[sphere] = {
            **params,
            'direction': mirrored_direction,
            'phi': -params['phi']   # угол скрута инвертируется
        }
    return mirrored

def is_lci_p_symmetric(lci_func, scheme) -> bool:
    """
    P-симметрия ЛЗП: ЛЗП зеркальной схемы = ЛЗП оригинала?
    Обычно ДА (как в ЭМ-взаимодействии).
    """
    lci_original = lci_func(scheme)
    lci_mirror = lci_func(mirror_scheme(scheme))
    return abs(lci_original - lci_mirror) < 1e-10
```

**Три случая зеркальной симметрии в ЕТД**:

| Тип | ЛЗП зеркала = ЛЗП оригинала? | Пример |
|-----|------------------------------|--------|
| P-симметричная схема | ДА | Прямой удар: правая = левая |
| P-несимметричная схема | НЕТ | Крюк с шагом по диагонали |
| P-антисимметричная схема | -ЛЗП (знак меняется) | Обратный удар, захват |

**Следствие для ЕТД**:
- Любую схему ЕТД можно зеркально отразить
- Зеркальная схема имеет тот же ЛЗП (P-симметрия ЕТД)
- Обучение симметрично: освоил правой → освоил левой автоматически

**Аксиома I**: *Зеркальное отражение схемы ЕТД сохраняет ЛЗП. Каждая схема имеет P-симметричный двойник.*

## ЧАСТЬ III: ГРУППА ПУАНКАРЕ ЕТД

### 3.1 Математический факт

Совокупность преобразований {трансляция, вращение, Лоренц} образует **группу Пуанкаре** — симметрийную группу специальной теории относительности.

### 3.2 Группа симметрий ЕТД

Аналогично, 4 преобразования ЕТД образуют группу симметрий системы сфер:

```python
class ETDSymmetryGroup:
    """
    Группа симметрий системы 4 сфер ЕТД.
    Аналог группы Пуанкаре для ЛЗП.
    """

    @staticmethod
    def translation(state: dict, a: tuple) -> dict:
        """T(a): параллельный перенос на вектор a"""
        return {s: {**p, 'rho': p['rho'] + sum(a)} for s, p in state.items()}

    @staticmethod
    def rotation(state: dict, angle: float) -> dict:
        """R(θ): поворот всей системы на угол θ"""
        return {
            s: {**p, 'direction': rotate_direction(p['direction'], angle)}
            for s, p in state.items()
        }

    @staticmethod
    def lorentz_boost(state: dict, v: float, c: float = 10.0) -> dict:
        """L(v): переход к системе отсчёта со скоростью v"""
        gamma = 1.0 / math.sqrt(1 - (v/c)**2)
        return {
            s: {**p, 'tau': gamma * p['tau']}   # замедление времени
            for s, p in state.items()
        }

    @staticmethod
    def inversion(state: dict) -> dict:
        """P: зеркальное отражение"""
        return {
            s: {
                **p,
                'direction': (-p['direction'][0], p['direction'][1], p['direction'][2])
            }
            for s, p in state.items()
        }

    def compose(self, *transforms):
        """Последовательное применение преобразований"""
        def apply_all(state):
            result = state
            for transform in transforms:
                result = transform(result)
            return result
        return apply_all
```

## ЧАСТЬ IV: НАРУШЕНИЯ СИММЕТРИИ → БОЕВЫЕ СИТУАЦИИ

### 4.1 Когда симметрия нарушается

В физике нарушение симметрии = **особо интересная ситуация** (например, нарушение P-симметрии в слабом взаимодействии открыло новую физику).

В ЕТД нарушение симметрии = **ключевой тактический момент**:

| Нарушенная симметрия | Что произошло | Тактическое следствие |
|---------------------|---------------|----------------------|
| Трансляция | Боец у стены/угла | Ограниченное пространство → смена схемы |
| Вращение | Боец потерял баланс | Нельзя использовать инерцию поворота |
| Лоренц | Экстремальная скорость | Иные реакции (адреналин → «туннельное» восприятие) |
| Инверсия | Только правая рука работает | Нет зеркального двойника → уязвимость |

### 4.2 Нарушение симметрии → переключение ЧВС

```python
def detect_symmetry_violation(current_state: dict) -> str:
    """
    Определение нарушения симметрии → рекомендация ЧВС
    """
    violations = []

    if current_state.get('wall_distance', float('inf')) < 0.5:
        violations.append('трансляция')   # у стены

    if current_state.get('balance', 1.0) < 0.5:
        violations.append('вращение')     # потеря баланса

    if current_state.get('speed_ratio', 1.0) > 3.0:
        violations.append('лоренц')       # экстрем. скорость

    if not current_state.get('both_hands', True):
        violations.append('инверсия')     # одна рука занята

    if not violations:
        return "Все симметрии сохранены — стандартная схема"

    recommendations = {
        'трансляция': "ЧВС-Пространство: работать с углом как с активом",
        'вращение':   "ЧВС-Тело: приоритет баланса, низкий центр тяжести",
        'лоренц':     "ЧВС-Домен: рефлекторный режим без анализа",
        'инверсия':   "ЧВС-Инструмент: использовать свободный инструмент"
    }

    return "; ".join(recommendations[v] for v in violations)
```

## ЧАСТЬ V: ИНВАРИАНТНОСТЬ И УНИВЕРСАЛЬНОСТЬ ЕТД

### 5.1 Теорема об универсальности ЕТД

**Теорема**: Если система ЕТД инвариантна относительно 4 преобразований Германа, то её ЛЗП является **универсальным инвариантом** — не зависящим от:
- места применения (трансляция)
- ориентации бойца (вращение)
- темпа схватки (Лоренц)
- ведущей руки (инверсия)

**Следствие**: Система ЕТД **полностью переносима** в любой контекст без потери эффективности. Это — математическое обоснование универсальности ЕТД.

### 5.2 Аксиоматика инвариантности

```
A-T: ЛЗП(T(a)·S) = ЛЗП(S)     — трансляционная инвариантность
A-R: ЛЗП(R(θ)·S) = ЛЗП(S)     — вращательная инвариантность
A-L: ЛЗП(L(v)·S) = ЛЗП(S)     — лоренц-инвариантность
A-P: ЛЗП(P·S)    = ЛЗП(S)     — P-симметрия (зеркало)
```

Эти 4 аксиомы = **основа универсальности ЕТД**.

## ЗАКЛЮЧЕНИЕ

4 преобразования Германа — трансляция, вращение, Лоренц, инверсия — порождают **4 аксиомы инвариантности ЕТД**:

1. **A-T**: Схема работает везде (независимость от места)
2. **A-R**: Схема работает в любой ориентации тела
3. **A-L**: Схема работает в любом темпе схватки
4. **A-P**: Схема имеет зеркальный двойник с тем же ЛЗП

> По теореме Нётер: 4 инвариантности → 4 закона сохранения → 4 неуничтожимых ресурса системы ЕТД.

> «4 преобразования, оставляющие инвариантными дифференциальные уравнения» (Герман) → 4 условия универсальности системы 4 сфер ЕТД.
