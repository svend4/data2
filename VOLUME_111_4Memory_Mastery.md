## ВВЕДЕНИЕ

Франц Герман (стр. 3):
> «4 типа памяти: **двигательная, эмоциональная, образная, смысловая**»

Это — не просто классификация. Это **иерархия глубины освоения** любого навыка. Каждый тип памяти = определённый уровень, на котором движение «записывается» в нервной системе.

**Тезис тома**: 4 типа памяти = 4 уровня мастерства ЕТД. Переход от уровня к уровню = переключение типа активной памяти. ЧВС активируется при переходе от двигательной к образной.

## ЧАСТЬ I: 4 ТИПА ПАМЯТИ И 4 УРОВНЯ ЕТД

### Таблица соответствий

| № | Тип памяти | Нейронная основа | Уровень ЕТД | ЧВС-роль |
|---|-----------|-----------------|------------|---------|
| 1 | **Двигательная** | Мозжечок, базальные ганглии | Уровень 1-2: приёмы, связки | ЧВС = домен (задача) |
| 2 | **Эмоциональная** | Амигдала, лимбическая система | Уровень 3: тактика | ЧВС = состояние (намерение) |
| 3 | **Образная** | Правая кора, теменные доли | Уровень 4: схемы, образы | ЧВС = метафора (дракон/огонь) |
| 4 | **Смысловая** | Лобные доли, ассоциативная кора | Уровень 5+: принципы Тай-Цзи | ЧВС = принцип (π/4) |

## ЧАСТЬ II: ПОДРОБНОЕ ОПИСАНИЕ КАЖДОГО УРОВНЯ

### Уровень 1-2: ДВИГАТЕЛЬНАЯ ПАМЯТЬ

**Нейронный механизм**: Автоматизация движений через повторение. Движение уходит из сознательного контроля в «мышечную память» мозжечка.

**Признаки освоения**:
- Не нужно думать — тело делает само
- Скорость и точность без усилия
- Повторяемость независимо от усталости

**В ЕТД**:
- МВС, СВС, БВС работают автоматически
- ЧВС = постановка задачи (хочу ударить/блокировать/захватить)
- Нет гибкости — только заученные паттерны

```python
class MotorMemoryLevel:
    """Уровень двигательной памяти"""
    lci_range = (0.3, 0.5)
    cvs_type = "домен-задача"
    description = "Приёмы и связки автоматизированы, но жёсткие"
    weakness = "Ломается при нестандартной ситуации"

    def execute(self, technique: str) -> str:
        return f"Автоматически: {technique}"
```

### Уровень 3: ЭМОЦИОНАЛЬНАЯ ПАМЯТЬ

**Нейронный механизм**: Амигдала связывает движения с эмоциональными состояниями. Страх, агрессия, спокойствие — меняют паттерн движения.

**Признаки освоения**:
- Движение окрашено намерением
- Разные схемы в зависимости от эмоционального состояния
- Начало работы с состоянием потока

**В ЕТД**:
- ЧВС = намерение (атаковать с яростью / защищаться спокойно)
- МВС/СВС/БВС следуют за эмоциональным ЧВС
- Первое появление настоящей гибкости

```python
class EmotionalMemoryLevel:
    """Уровень эмоциональной памяти"""
    lci_range = (0.5, 0.65)
    cvs_type = "намерение-состояние"

    emotional_cvs_map = {
        'ярость':     {'phi': 0.8, 'speed': 'максимальная'},
        'спокойствие':{'phi': 0.785, 'speed': 'оптимальная'},  # π/4
        'страх':      {'phi': 0.3, 'speed': 'хаотичная'},
        'уверенность':{'phi': 0.785, 'speed': 'уверенная'},
    }

    def execute(self, technique: str, emotion: str) -> str:
        params = self.emotional_cvs_map.get(emotion, {})
        return f"{technique} с {emotion}: φ={params.get('phi', 0):.3f}"
```

### Уровень 4: ОБРАЗНАЯ ПАМЯТЬ

**Нейронный механизм**: Правое полушарие кодирует движение через метафоры, образы, пространственные схемы. Работа «картинами», а не правилами.

**Признаки освоения**:
- Боец «видит» образ и двигается из образа
- ЧВС-ключи: «дракон», «огонь», «вода», «железо»
- Управление через внутренний образ, не через инструкцию

**В ЕТД** — это **уровень ЧВС-метафоры**:

```python
class ImageMemoryLevel:
    """Уровень образной памяти — ЧВС-образы"""
    lci_range = (0.65, 0.80)
    cvs_type = "метафора-образ"

    CVS_IMAGES = {
        'дракон':   {'phi': 0.785, 'description': 'гибкость + мощь'},
        'огонь':    {'phi': 0.9,   'description': 'взрыв + непредсказуемость'},
        'вода':     {'phi': 0.6,   'description': 'плавность + проникновение'},
        'железо':   {'phi': 0.4,   'description': 'жёсткость + прямолинейность'},
        'ветер':    {'phi': 0.785, 'description': 'скорость + касание'},
        'земля':    {'phi': 0.3,   'description': 'устойчивость + тяжесть'},
    }

    def set_image(self, image_key: str):
        """Установить образ как ЧВС — всё тело следует образу"""
        if image_key in self.CVS_IMAGES:
            params = self.CVS_IMAGES[image_key]
            print(f"ЧВС-образ: {image_key} — {params['description']}")
            return params['phi']
```

**Ключевой переход**: На этом уровне впервые появляется **полноценная ЧВС** — не задача и не состояние, а образ, который перестраивает всю систему сфер мгновенно.

### Уровень 5+: СМЫСЛОВАЯ ПАМЯТЬ

**Нейронный механизм**: Лобные доли формируют абстрактные принципы, применимые в любом контексте. Понимание «почему», а не только «что».

**Признаки освоения**:
- Движение из принципа, а не из приёма
- Одним принципом порождаются тысячи техник
- Состояние «у-вэй» (Тай-Цзи) — действие без усилия

**В ЕТД** — уровень π/4:

```python
class SemanticMemoryLevel:
    """Уровень смысловой памяти — принцип π/4"""
    lci_range = (0.80, 1.0)
    cvs_type = "принцип"

    PRINCIPLES = {
        'π/4':        'Оптимальный угол синхронизации всех 4 сфер',
        '3+1':        'Три физические + одна контекстная = полнота',
        'вложение':   'Каждая сфера содержит 4 подсферы',
        'инвариант':  'ЛЗП не зависит от места/ориентации/темпа',
    }

    def execute(self, situation: str) -> str:
        """На этом уровне нет 'техник' — только принципы"""
        return f"Применяю принцип π/4 к: {situation}"

    @property
    def is_master(self) -> bool:
        return True
```

## ЧАСТЬ III: ПЕРЕХОДЫ МЕЖДУ УРОВНЯМИ = ПЕРЕКЛЮЧЕНИЕ ЧВС

### 3.1 Почему ЧВС меняется при смене уровня памяти

| Переход | Тип смены ЧВС | Механизм |
|---------|--------------|---------|
| Двиг. → Эмоц. | Задача → Намерение | Амигдала подключается к движению |
| Эмоц. → Образная | Намерение → Образ | Правое полушарие берёт управление |
| **Образная → Смысловая** | **Образ → Принцип** | **Лобные доли абстрагируют образ** |

### 3.2 ЧВС-триггеры перехода

```python
def detect_memory_level(response_time_ms: float,
                         variability: float,
                         uses_metaphors: bool,
                         acts_from_principle: bool) -> str:
    """
    Определить текущий уровень памяти бойца по поведению.
    """
    if acts_from_principle:
        return "Смысловая (уровень 5+)"
    if uses_metaphors:
        return "Образная (уровень 4)"
    if variability > 0.5:
        return "Эмоциональная (уровень 3)"
    if response_time_ms < 200:
        return "Двигательная (уровень 1-2)"
    return "Предсознательная (уровень 0)"
```

## ЧАСТЬ IV: 4 ТИПА ПАМЯТИ × 4 СФЕРЫ = МАТРИЦА МАСТЕРСТВА

| Память \ Сфера | МВС | СВС | БВС | ЧВС |
|----------------|-----|-----|-----|-----|
| **Двигательная** | Автоматический хват | Автоматический рычаг | Автоматическая стойка | Заданный домен |
| **Эмоциональная** | Хват из намерения | Рычаг из состояния | Тело из эмоции | Намерение как ЧВС |
| **Образная** | Кисть как «коготь дракона» | Предплечье как «крыло» | Тело как «ось» | Образ = ЧВС |
| **Смысловая** | МВС из принципа π/4 | СВС из закона сохранения | БВС из инварианта | ЧВС = принцип |

---

## ЗАКЛЮЧЕНИЕ

4 типа памяти Германа = 4 уровня мастерства ЕТД:

1. **Двигательная** → Приёмы/автоматика → ЧВС = задача
2. **Эмоциональная** → Тактика/намерение → ЧВС = состояние
3. **Образная** → Схемы/метафоры → ЧВС = образ (дракон/огонь)
4. **Смысловая** → Принципы/у-вэй → ЧВС = π/4

> Движение от уровня к уровню = эволюция ЧВС: от конкретной задачи к универсальному принципу.
> Мастер ЕТД живёт на смысловом уровне — принцип π/4 как единственная «техника».
