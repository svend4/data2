## ВВЕДЕНИЕ

Франц Герман (стр. 2):
> «4 вида движений плоскости: **перенос, поворот, отражение, скользящее отражение**»

Математическая теорема: **любое** движение плоскости (изометрия, сохраняющая расстояния) является одним из этих четырёх типов. Исчерпывающая классификация.

**Тезис тома**: Любая операция со сферами ЕТД является одним из 4 типов движений. Это даёт **полную таксономию** всех возможных действий в системе сфер.

## ЧАСТЬ I: 4 ТИПА ДВИЖЕНИЙ → 4 ТИПА ОПЕРАЦИЙ СО СФЕРАМИ

### 1. ПЕРЕНОС (Трансляция)

**Геометрия**: Сдвиг всех точек на одинаковый вектор `a`.
```
(x, y) → (x + aₓ, y + aᵧ)
```
Не меняет ориентацию. Нет неподвижных точек.

**Операция со сферой ЕТД**:
- Смещение центра сферы без изменения её ориентации и вращения
- МВС-перенос: шаг вперёд кистью без ротации
- СВС-перенос: вынос предплечья по прямой
- БВС-перенос: шаг вперёд/назад без разворота корпуса

```python
def translate_sphere(sphere_center: tuple, vector: tuple) -> tuple:
    """
    Перенос сферы на вектор.
    Ориентация, вращение — без изменений.
    """
    return (
        sphere_center[0] + vector[0],
        sphere_center[1] + vector[1],
        sphere_center[2] + vector[2]
    )

# Пример: вынос МВС вперёд
mvs_new = translate_sphere(mvs_center=(0,0,0), vector=(0,0,0.5))
# МВС переместилась на 0.5м вперёд — прямой удар без вращения
```

**ЧВС при переносе**: ЧВС НЕ переключается. Направление сохраняется.

### 2. ПОВОРОТ (Ротация)

**Геометрия**: Поворот вокруг фиксированной точки (центра вращения) на угол θ.
```
(x, y) → (x·cos θ - y·sin θ, x·sin θ + y·cos θ)
```
Одна неподвижная точка — центр вращения.

**Операция со сферой ЕТД**:
- Вращение сферы вокруг своей оси или вокруг другой сферы
- МВС-поворот: пронация/супинация кисти
- СВС-поворот: ротация предплечья вокруг локтя
- БВС-поворот: разворот корпуса вокруг ЦТ

```python
import math

def rotate_sphere(sphere_state: dict, angle: float, axis: str = 'z') -> dict:
    """
    Поворот сферы вокруг оси на угол angle (в радианах).
    Это основная операция синхронизации сфер.
    """
    cos_a, sin_a = math.cos(angle), math.sin(angle)
    x, y, z = sphere_state['direction']

    if axis == 'z':
        new_dir = (x*cos_a - y*sin_a, x*sin_a + y*cos_a, z)
    elif axis == 'x':
        new_dir = (x, y*cos_a - z*sin_a, y*sin_a + z*cos_a)
    elif axis == 'y':
        new_dir = (x*cos_a + z*sin_a, y, -x*sin_a + z*cos_a)

    return {**sphere_state, 'direction': new_dir, 'phi': angle}

# Оптимальный поворот = π/4
mvs_rotated = rotate_sphere(mvs_state, math.pi/4)
```

**ЧВС при повороте**: ЧВС может переключиться одновременно с поворотом (смена контекста через ротацию).

### 3. ОТРАЖЕНИЕ (Рефлексия)

**Геометрия**: Зеркальное отражение относительно прямой (оси симметрии).
```
Отражение относительно оси X: (x, y) → (x, -y)
```
Меняет ориентацию («правое» становится «левым»).

**Операция со сферой ЕТД**:
- Зеркальное переключение: правая рука → левая рука
- Внутреннее → внешнее (изнутри наружу)
- «Обратный» вариант любой техники

```python
def mirror_sphere(sphere_state: dict, mirror_axis: str = 'yz') -> dict:
    """
    Зеркальное отражение сферы.
    mirror_axis: 'yz' (зеркало лево↔право),
                 'xz' (зеркало верх↔низ),
                 'xy' (зеркало перёд↔зад)
    ЛЗП сохраняется (по теореме инвариантности инверсии, Том 107).
    """
    x, y, z = sphere_state['direction']
    if mirror_axis == 'yz':
        new_dir = (-x, y, z)   # лево ↔ право
    elif mirror_axis == 'xz':
        new_dir = (x, -y, z)   # верх ↔ низ
    elif mirror_axis == 'xy':
        new_dir = (x, y, -z)   # перёд ↔ зад

    return {
        **sphere_state,
        'direction': new_dir,
        'phi': -sphere_state['phi']  # скрут инвертируется
    }

# Зеркало правой руки = левая рука с тем же ЛЗП
```

**ЧВС при отражении**: Если схема зеркальная, ЧВС не переключается — тот же контекст, другая сторона.

### 4. СКОЛЬЗЯЩЕЕ ОТРАЖЕНИЕ (Глайд-рефлексия)

**Геометрия**: Отражение + перенос вдоль оси отражения.
```
Отражение + трансляция вдоль оси
```
Нет неподвижных точек. Самый сложный тип движения.

**Операция со сферой ЕТД**:
- Зеркальная техника + шаг одновременно
- «Обратный крюк со сдвигом»
- Переключение рук + смещение позиции

```python
def glide_reflect_sphere(sphere_state: dict, mirror_axis: str,
                          glide_vector: tuple) -> dict:
    """
    Скользящее отражение = отражение + перенос.
    Самая сложная операция — требует максимальной координации.
    """
    # Сначала отражение
    mirrored = mirror_sphere(sphere_state, mirror_axis)
    # Затем перенос
    new_center = translate_sphere(
        sphere_center=mirrored['center'],
        vector=glide_vector
    )
    return {**mirrored, 'center': new_center}

# Пример: обратный удар левой + шаг вправо
glide_result = glide_reflect_sphere(
    sphere_state=right_hook_state,
    mirror_axis='yz',        # зеркало право→лево
    glide_vector=(0.3, 0, 0) # шаг 0.3м вправо
)
```

**ЧВС при скользящем отражении**: ВСЕГДА переключается — это самая «дорогая» операция, требующая смены контекста.

## ЧАСТЬ II: ТАБЛИЦА ОПЕРАЦИЙ И ЧВС

| Операция | Изменение ориентации | Неподвижные точки | ЛЗП | ЧВС-переключение |
|---------|---------------------|------------------|-----|-----------------|
| Перенос | Нет | Нет | Сохраняется | НЕТ |
| Поворот | Нет | Одна (центр) | Сохраняется | Иногда |
| Отражение | Да (лево↔право) | Прямая (ось) | Сохраняется | НЕТ |
| **Скользящее отражение** | **Да** | **Нет** | **Сохраняется** | **ВСЕГДА** |

## ЧАСТЬ III: ГРУППА ДВИЖЕНИЙ СФЕР

### 3.1 Алгебраическая структура

4 типа движений образуют **группу изометрий** плоскости:

```python
class SphereIsometry:
    """Группа изометрий сфер ЕТД"""

    IDENTITY = 'identity'     # единичный элемент

    def compose(self, op1: str, op2: str) -> str:
        """Композиция двух операций (таблица умножения группы)"""
        composition_table = {
            ('translate', 'translate'):         'translate',
            ('translate', 'rotate'):            'rotate',
            ('rotate', 'rotate'):               'rotate',
            ('reflect', 'reflect'):             'translate',      # !
            ('reflect', 'translate'):           'glide_reflect',
            ('glide_reflect', 'reflect'):       'translate',
            ('rotate', 'reflect'):              'reflect',
        }
        return composition_table.get((op1, op2), 'unknown')
```

**Ключевой факт**: Отражение + отражение = перенос! В ЕТД: зеркальная схема двух зеркальных = оригинальная схема с переносом.

## ЧАСТЬ IV: АНАЛИЗ ТЕХНИК ЕТД ЧЕРЕЗ 4 ТИПА ДВИЖЕНИЙ

| Техника ЕТД | Тип движения | Сфера | Описание |
|------------|-------------|-------|---------|
| Прямой удар | Перенос | МВС→цель | МВС летит вперёд без вращения |
| Крюк | Поворот | БВС→МВС | Тело разворачивается, кисть следует |
| Обратный удар правой | Отражение | МВС | Зеркало прямого удара |
| Обратный удар со смещением | Скользящее отражение | МВС+БВС | Зеркало + шаг |
| Уход в сторону | Перенос | БВС | Тело смещается |
| Разворот на 180° | Поворот | БВС | Тело на полный разворот |
| Работа с двух сторон | Отражение | МВС↔МВС | Правая↔левая |

---

## ЗАКЛЮЧЕНИЕ

4 вида движений плоскости = **полная таксономия операций со сферами ЕТД**:

1. **Перенос** → Смещение без ротации, ЧВС стабильна
2. **Поворот** → Ротация вокруг точки, возможна смена ЧВС
3. **Отражение** → Зеркало, ЧВС стабильна, ЛЗП сохраняется
4. **Скользящее отражение** → Зеркало + смещение, ЧВС переключается

> По теореме математики: любое движение — комбинация этих четырёх. Значит, **любая техника ЕТД** разбирается на эти четыре типа операций. Полная таксономия достигнута.
