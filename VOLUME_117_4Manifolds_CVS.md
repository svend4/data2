## ЧАСТЬ I: 4 ТОПОЛОГИИ ПРОСТРАНСТВА ЧВС

### 1. СФЕРА S² — Закрытое ЧВС-пространство

**Топология**: Замкнутая поверхность без края. Ориентируема. Любой замкнутый контур сжимается в точку.

**Характеристика Эйлера**: χ = 2

**ЧВС-интерпретация**: ЧВС-пространство является сферой, когда:
- Все 5 направлений ЧВС симметрично распределены
- Нет «привилегированных» направлений
- Переключение в любом направлении эквивалентно

```python
class SphericalCVSTopology:
    """
    Сферическая топология ЧВС-пространства.
    Самая симметричная — мастерский уровень.
    """
    name = "Сфера S²"
    euler_characteristic = 2
    is_orientable = True

    description = (
        "Все ЧВС-направления равнодоступны. "
        "Нет 'любимого' контекста. "
        "Переключение мгновенно в любом направлении."
    )

    @staticmethod
    def distance(cvs_1: str, cvs_2: str) -> float:
        """На сфере: расстояние = угол большого круга"""
        CVS_POSITIONS = {
            'Внутреннее':      (0, 0, 1),     # северный полюс
            'Виртуальное':     (0, 0, -1),    # южный полюс
            'Инструментальное':(1, 0, 0),     # восток
            'Пространственное':(-1, 0, 0),    # запад
            'Доменное':        (0, 1, 0),     # север
        }
        import math
        p1, p2 = CVS_POSITIONS[cvs_1], CVS_POSITIONS[cvs_2]
        dot = sum(a*b for a,b in zip(p1, p2))
        return math.acos(max(-1, min(1, dot)))
```

**Мастер с сферической топологией ЧВС**: Равно готов к любому контексту. «Нет любимого направления» = нет слабого места.

### 2. ТОР T² — Циклическое ЧВС-пространство

**Топология**: «Бублик». Два независимых цикла. Ориентируема. χ = 0.

**ЧВС-интерпретация**: Тор возникает, когда:
- ЧВС-переключения образуют два независимых цикла
- Пространственное ↔ Доменное (первый цикл)
- Внутреннее ↔ Виртуальное (второй цикл)

```python
class ToricCVSTopology:
    """
    Торическая топология ЧВС — два независимых цикла.
    Характерна для бойцов с чётко выраженными двумя стилями.
    """
    name = "Тор T²"
    euler_characteristic = 0
    is_orientable = True

    # Два основных цикла
    cycle_1 = ['Пространственное', 'Доменное', 'Пространственное']
    cycle_2 = ['Внутреннее', 'Виртуальное', 'Внутреннее']

    def navigate(self, angle_1: float, angle_2: float) -> str:
        """
        Навигация по тору: два угла → состояние ЧВС.
        (θ₁, θ₂) → ЧВС-состояние.
        """
        import math
        # Первый угол → Пространство-Домен ось
        if math.cos(angle_1) > 0:
            spatial_component = 'Пространственное'
        else:
            spatial_component = 'Доменное'

        # Второй угол → Внутренний-Виртуальный ось
        if math.cos(angle_2) > 0:
            depth_component = 'Внутреннее'
        else:
            depth_component = 'Виртуальное'

        return f"{spatial_component}+{depth_component}"
```

### 3. БУТЫЛКА КЛЕЙНА — Неориентируемое ЧВС

**Топология**: Замкнутая неориентируемая поверхность. «Внутри» и «снаружи» не различимы. χ = 0.

**ЧВС-интерпретация**: Бутылка Клейна = ЧВС, где граница «внутренний/внешний» контекст исчезает.

```python
class KleinBottleCVSTopology:
    """
    ЧВС-пространство типа бутылки Клейна.
    Внутреннее = Внешнее (Виртуальное) — нет различия.
    Характерна для мастеров медитации/Тай-Цзи.
    """
    name = "Бутылка Клейна"
    euler_characteristic = 0
    is_orientable = False  # !

    description = (
        "Нет границы между внутренним и внешним контекстом. "
        "Мастер одновременно внутри и снаружи ситуации. "
        "ЧВС-Внутреннее плавно переходит в ЧВС-Виртуальное."
    )

    def inside_outside_unified(self) -> bool:
        """На бутылке Клейна нет 'внутри' и 'снаружи'"""
        return True  # всегда True — нет границы
```

### 4. ПРОЕКТИВНАЯ ПЛОСКОСТЬ RP² — ЧВС с отождествлением противоположностей

**Топология**: Неориентируемая. Противоположные точки сферы отождествлены. χ = 1.

**ЧВС-интерпретация**: Проективная плоскость = ЧВС, где противоположные направления **эквивалентны**:
- Атака ≡ Защита (одна и та же ЧВС)
- Твёрдое ≡ Мягкое (противоположности едины)

```python
class ProjectivePlaneCVSTopology:
    """
    Проективная плоскость как ЧВС-пространство.
    Противоположные ЧВС отождествлены (антиподы = одна точка).
    """
    name = "Проективная плоскость RP²"
    euler_characteristic = 1
    is_orientable = False

    ANTIPODAL_PAIRS = {
        'Внутреннее': 'Виртуальное',
        'Инструментальное': 'Пространственное',
        'Доменное': 'Доменное',    # самоантипод
    }

    def identify_antipodal(self, cvs: str) -> str:
        """На RP²: cvs ≡ anti-cvs (они одно и то же!)"""
        return self.ANTIPODAL_PAIRS.get(cvs, cvs)

    def is_same_point(self, cvs_1: str, cvs_2: str) -> bool:
        """На RP²: Внутреннее = Виртуальное!"""
        return (cvs_1 == cvs_2 or
                self.identify_antipodal(cvs_1) == cvs_2)
```

## ЧАСТЬ III: ЭВОЛЮЦИЯ ТОПОЛОГИИ В ПРОЦЕССЕ ОБУЧЕНИЯ

```
Новичок: Отрезок (1D) — ЧВС как прямая от А до Б
    ↓ Первые тренировки
Практик: Тор (T²) — два независимых цикла (страйк/борьба)
    ↓ Обучение у мастера
Мастер: Сфера (S²) — все направления равнодоступны
    ↓ Глубокая практика
Гранд-мастер: Бутылка Клейна — внутри = снаружи
    ↓ Философское постижение
Легенда: Проективная плоскость — атака = защита
```

## ЗАКЛЮЧЕНИЕ

4 замкнутых 2D-многообразия = 4 топологических типа ЧВС-пространства:

1. **Сфера** → Симметричный доступ ко всем 5 ЧВС (мастер)
2. **Тор** → Два независимых цикла переключений (практик)
3. **Бутылка Клейна** → Нет границы внутри/снаружи (гранд-мастер)
4. **Проективная плоскость** → Противоположности едины (философ)

> Топология ЧВС эволюционирует от простейшего отрезка к сфере и далее к неориентируемым поверхностям. Мастерство = расширение топологии пространства ЧВС.
