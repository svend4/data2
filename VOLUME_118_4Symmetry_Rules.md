**Тезис тома**: 4 правила симметрии Германа = 4 принципа проверки любой схемы ЕТД на физическую корректность.

## ЧАСТЬ I: 4 ПРАВИЛА СИММЕТРИИ → 4 ПРИНЦИПА ЕТД

### Правило 1: МАСШТАБ (Подобие)

**Физика**: Законы природы сохраняются при изменении масштаба (в определённых пределах). Фракталы самоподобны при любом масштабировании.

**ЕТД-принцип масштаба**: Схема сфер работает на любом масштабе движения.

```python
def scale_invariance_check(scheme: dict, scale_factor: float) -> dict:
    """
    Проверка масштабной инвариантности схемы ЕТД.
    Масштабируем все параметры на factor — ЛЗП должен сохраниться.
    """
    scaled = {}
    for sphere, params in scheme.items():
        scaled[sphere] = {
            **params,
            'rho': params['rho'] * scale_factor,        # радиус масштабируется
            'omega': params['omega'] / scale_factor,     # угловая скорость убывает
            'lci': params['lci']                         # ЛЗП ИНВАРИАНТЕН!
        }
    return scaled

# Маленькое движение ≡ большому движению (одна ЧВС, один ЛЗП)
# Удар одним пальцем ≡ удар всем телом — по схеме одинаковы
```

**Практика**: Одна и та же схема работает в:
- Микромасштабе (движение пальца — МВС)
- Мезомасштабе (движение кисти — СВС)
- Макромасштабе (движение тела — БВС)

### Правило 2: ПРАВАЯ/ЛЕВАЯ РУКА (P-симметрия)

**Физика**: Большинство физических законов зеркально симметричны (P-инвариантны). Нарушение P-симметрии наблюдается только в слабом взаимодействии.

**ЕТД-принцип зеркала**: Любая схема ЕТД имеет зеркальный двойник с тем же ЛЗП.

```python
def p_symmetry_analysis(scheme: dict) -> dict:
    """
    P-анализ схемы ЕТД.
    Возвращает: зеркальная схема + P-нарушение (если есть).
    """
    mirrored = {
        sphere: {
            **params,
            'direction': (-params['direction'][0],
                           params['direction'][1],
                           params['direction'][2]),
            'phi': -params['phi']
        }
        for sphere, params in scheme.items()
    }

    lci_original = sum(p.get('lci', 0) for p in scheme.values())
    lci_mirrored = sum(p.get('lci', 0) for p in mirrored.values())

    p_violation = abs(lci_original - lci_mirrored)

    return {
        'mirrored_scheme': mirrored,
        'p_violation': p_violation,
        'is_p_symmetric': p_violation < 0.01
    }
```

**Важное замечание**: В ЕТД «нарушение P-симметрии» (как в физике) = ситуация, когда схема значительно эффективнее для одной руки. Это = уязвимость, которую нужно устранить.

### Правило 3: БУРАВЧИК (Ориентация вращения — правило правой руки)

**Физика**: Правило правой руки (правило буравчика) определяет направление векторов углового момента, магнитного поля, силы Лоренца.

```
Если 4 пальца правой руки сгибаются в направлении вращения,
то большой палец указывает на вектор L (угловой момент).
```

**ЕТД-принцип буравчика**: Направление вращения сферы определяет знак углового момента.

```python
import math
from typing import Tuple

def angular_momentum_direction(rotation_direction: str,
                                rotation_axis: Tuple[float,float,float]) -> Tuple[float,float,float]:
    """
    Правило буравчика для сфер ЕТД.
    rotation_direction: 'clockwise' или 'counterclockwise'
    rotation_axis: ось вращения (единичный вектор)

    Возвращает: вектор углового момента L.
    """
    sign = 1 if rotation_direction == 'counterclockwise' else -1
    return (
        sign * rotation_axis[0],
        sign * rotation_axis[1],
        sign * rotation_axis[2]
    )

# Правило буравчика для удара:
# МВС вращается против часовой (супинация) → L направлен от бойца
# МВС вращается по часовой (пронация) → L направлен к бойцу

# Оптимальный удар = L_МВС направлен в цель
mvs_L = angular_momentum_direction('clockwise', (0, 0, 1))
# = (0, 0, -1) — момент направлен от бойца = к цели ✓
```

**Практика в ЕТД**:
- При пронации (завершение удара) → момент в цель → максимальная передача
- При супинации → момент от цели → ослабление удара
- **Правило буравчика = объяснение пронации в конце удара**

### Правило 4: ГИРОСКОП (Прецессия)

**Физика**: Быстро вращающийся гироскоп под действием внешней силы не падает в сторону приложения силы, а прецессирует — вращается перпендикулярно силе.

```
τ = dL/dt → прецессия: Ω_прец = τ/L
```

**ЕТД-принцип гироскопа**: Быстро вращающаяся сфера с высоким L ведёт себя как гироскоп — **не поддаётся боковой силе**, а прецессирует.

```python
def gyroscopic_effect_sphere(angular_momentum: float,
                              external_torque: float) -> float:
    """
    Гироскопический эффект сферы ЕТД.
    Быстро вращающаяся МВС/СВС с высоким L → сложна для захвата.
    Скорость прецессии = внешний момент / угловой момент.
    """
    if angular_momentum == 0:
        return float('inf')  # нет вращения → легко захватить
    return external_torque / angular_momentum

# Высокий L → малая прецессия → сфера устойчива к внешнему воздействию
# Низкий L → большая прецессия → сфера нестабильна (легко сбить)

# Практика: быстро вращающийся кулак перед ударом
# = высокий L МВС → гироскопически устойчив
# Противник пытается захватить руку → прецессия (рука уходит по дуге)
```

**Гироскопический эффект в техниках ЕТД**:
- **Пасс**: рука движется по окружности с высокой ω → гироскопически уходит от захвата
- **Мельница**: тело как гироскоп → не поддаётся линейным толчкам
- **Защита через движение**: быстрое вращение > статичный блок

## ЧАСТЬ II: 4 ПРАВИЛА × 4 СФЕРЫ — МАТРИЦА СИММЕТРИЙ

| Правило \ Сфера | МВС | СВС | БВС | ЧВС |
|----------------|-----|-----|-----|-----|
| **Масштаб** | Любое движение кисти | Масштаб предплечья | Масштаб тела | ЧВС масштаба нет |
| **Зеркало** | Кулак↔другой кулак | Правое↔левое предплечье | Правый↔левый разворот | ЧВС зеркальна |
| **Буравчик** | Пронация/супинация | Ротация предплечья | Разворот корпуса | ЧВС-вектор |
| **Гироскоп** | Быстрый кулак = гироскоп | Вращение предплечья | Быстрый разворот | ЧВС-инерция |

## ЧАСТЬ III: СВОДНЫЙ ЧЕКЛИСТ СИММЕТРИЙ ДЛЯ ПРОВЕРКИ СХЕМЫ

```python
class SymmetryChecker:
    """Проверка схемы ЕТД по 4 правилам симметрии Германа"""

    def check_all(self, scheme: dict) -> dict:
        results = {}

        # 1. Масштаб
        small_scale = scale_invariance_check(scheme, 0.5)
        large_scale = scale_invariance_check(scheme, 2.0)
        results['масштаб'] = {
            'инвариантен': True,
            'описание': 'Схема работает на любом масштабе движения'
        }

        # 2. Зеркало
        p_result = p_symmetry_analysis(scheme)
        results['зеркало'] = {
            'P-нарушение': p_result['p_violation'],
            'симметрична': p_result['is_p_symmetric'],
            'описание': 'Симметрична лево/право' if p_result['is_p_symmetric'] else 'НАРУШЕНИЕ P-симметрии!'
        }

        # 3. Буравчик
        optimal_rotation = scheme.get('МВС', {}).get('rotation', 'clockwise')
        results['буравчик'] = {
            'вращение': optimal_rotation,
            'оптимально': optimal_rotation == 'clockwise',
            'описание': 'Пронация в конце удара' if optimal_rotation == 'clockwise' else 'Проверить пронацию!'
        }

        # 4. Гироскоп
        bvs_omega = scheme.get('БВС', {}).get('omega', 0)
        results['гироскоп'] = {
            'угловая_скорость': bvs_omega,
            'устойчив': bvs_omega > 2.0,
            'описание': 'Тело достаточно быстрое для гироскопической защиты' if bvs_omega > 2.0 else 'Увеличить скорость тела'
        }

        return results
```

## ЗАКЛЮЧЕНИЕ

4 правила симметрии Германа = **4 принципа физической проверки схем ЕТД**:

1. **Масштаб** → Схема работает на МВС, СВС и БВС уровне одинаково
2. **Зеркало** → Схема имеет равноэффективный зеркальный двойник
3. **Буравчик** → Пронация в конце удара → максимальный угловой момент в цель
4. **Гироскоп** → Быстрое вращение тела/сфер = естественная защита

> «4 правила симметрии для реальных физических явлений» (Герман) → 4 правила проверки физической корректности схем ЕТД.
