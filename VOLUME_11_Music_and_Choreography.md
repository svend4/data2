## ПРЕДИСЛОВИЕ

Музыкант и боец решают одну задачу.

Боец: переместить тело оптимально в пространстве, синхронизировав три уровня (MВС/СВС/БВС) в единый момент максимальной силы.

Музыкант: переместить звук оптимально во времени, синхронизировав технику (пальцы), фразу (рука/дыхание) и форму (всё произведение) в единый момент максимальной выразительности.

Это буквально одно и то же — в разных пространствах.

Данная книга исследует **изоморфизм** между системой Крюкова и теорией музыки и хореографии. Мы покажем, что:
- Музыкальная фраза — это петля
- Ритм — это закон нечётности
- Гармония — это резонанс
- Контрапункт — это камуфляж/угроза
- Музыкальная форма — это три сферы
- Импровизация — это пятый уровень мастерства

## ЧАСТЬ I. МУЗЫКАЛЬНЫЕ АРХЕТИПЫ

### Глава 1. Петля в Музыке

#### 1.1 Музыкальная фраза как петля

В системе Крюкова **петля** — замкнутая траектория, всегда возвращающаяся к начальной точке. Это точное определение **музыкальной фразы**:

```
МУЗЫКАЛЬНАЯ ФРАЗА = ПЕТЛЯ В ЗВУКОВОМ ПРОСТРАНСТВЕ

Структура петли (тезис → развитие → возврат):
  Начальный тон (устой) → движение (неустои) → возврат (устой)
  До → Ре-Ми-Фа-Соль-Ля-Си → До (октава выше)

Математически:
  Фраза начинается на тоне f₀
  Проходит через множество промежуточных высот {f₁, f₂, ..., fₙ}
  Завершается на f₀ (или его октавном эквиваленте)

  Это петля в частотном пространстве!

Параметры петли:
  Амплитуда петли = диапазон фразы (малая/большая терция/октава)
  Форма петли = контур мелодии (восходящая/нисходящая/дугообразная)
  Длительность петли = метрическая длина фразы
  Скорость = темп исполнения
```

**LCI музыкальной фразы:**

```python
def musical_lci(phrase_pitches):
    """
    Вычислить Loop Closure Index музыкальной фразы.

    Параметры:
        phrase_pitches: список частот (Гц) нот фразы

    LCI = насколько фраза возвращается к начальному тону

    Идеальная петля (тоника → тоника): LCI = 1.0
    Незавершённая фраза (антецедент): LCI ≈ 0.4–0.6
    Полная каденция: LCI = 0.9–1.0
    Прерванная каденция: LCI ≈ 0.3
    """
    if len(phrase_pitches) < 2:
        return 0.0

    start_pitch = phrase_pitches[0]
    end_pitch = phrase_pitches[-1]

    # Октавная нормализация: До 4-й октавы = До 5-й (те же функции)
    start_pitch_norm = start_pitch % 12  # Питч-класс (0–11)
    end_pitch_norm = end_pitch % 12

    # Расстояние между начальным и конечным питч-классами (в полутонах)
    distance = min(
        abs(end_pitch_norm - start_pitch_norm),
        12 - abs(end_pitch_norm - start_pitch_norm)
    )

    # LCI: 0 = октава (полный возврат) до 6 (тритон, максимальное расстояние)
    lci = 1.0 - (distance / 6.0)

    # Дополнительный бонус за тональное разрешение (V → I)
    if is_dominant_to_tonic(phrase_pitches[-2], phrase_pitches[-1]):
        lci = min(1.0, lci + 0.15)

    return lci

def is_dominant_to_tonic(pitch_before_end, end_pitch):
    """Проверить: разрешается ли доминанта в тонику (V → I)."""
    interval = (end_pitch - pitch_before_end) % 12
    return interval == 5  # Квартовый скачок вниз: G → C (доминанта → тоника)
```

#### 1.2 Форма-петля в крупных произведениях

Принцип петли работает на всех масштабах музыкальной формы:

```
МАСШТАБНАЯ ИНВАРИАНТНОСТЬ ПЕТЛИ В МУЗЫКЕ:

МВС (микро-петля): мотив — 2–4 ноты
  Главный мотив 5-й симфонии Бетховена: «та-та-та-ТАМ»
  Петля: ненаправленное движение → акцент → точка

СВС (средняя петля): фраза и период — 4–16 тактов
  Восьмитактовый период: антецедент (незамкнутый) + консеквент (замкнутый)
  Вместе = полная петля

БВС (макро-петля): форма произведения
  Сонатная форма: Экспозиция → Разработка → Реприза
  Это петля! Реприза = возврат к исходному материалу
  Рондо: A–B–A–C–A–D–A (главная тема = петля возврата)
  Тема с вариациями: тема повторяется в разных обличиях (петля + камуфляж)

Вывод: вся западная музыкальная форма организована
по принципу петли на трёх масштабных уровнях.
```

### Глава 2. Три Сферы в Музыке

#### 2.1 Аналог МВС/СВС/БВС для исполнителя

```
ТРИ СФЕРЫ МУЗЫКАНТА:

МВС (техника — пальцы/амбушюр):
  Инструмент: пальцы (пианист), губы+язык (духовик), смычок (струнник)
  Задача: извлечь правильный тон с правильной артикуляцией
  Временной горизонт: миллисекунды
  Патология МВС: неточность нот, неровность техники

СВС (фраза — рука/дыхание):
  Инструмент: вся рука (пианист), дыхательная колонна (певец)
  Задача: оформить фразу (нарастание → кульминация → спад)
  Временной горизонт: 2–15 секунд (длина фразы)
  Патология СВС: «рубленая» игра без фраз, механичность

БВС (форма — тело/художественный замысел):
  Инструмент: всё тело, архитектурный слух
  Задача: выстроить драматургию всего произведения
  Временной горизонт: минуты — часы (длина произведения)
  Патология БВС: потеря «нити», непонимание целого

РЕЗОНАНС МУЗЫКАНТА:
  Когда техника (МВС), фраза (СВС) и форма (БВС) работают в единстве →
  это и есть то, что называют «пением» инструмента,
  «живым» исполнением, «магией» концерта.

  ω_МВС = ω_СВС = ω_БВС → МУЗЫКАЛЬНЫЙ РЕЗОНАНС

  Практически: тот момент, когда исполнитель «перестаёт думать»
  и музыка «играет сама» — это резонанс всех трёх уровней.
```

#### 2.2 Три сферы для слушателя

```
ТРИ СФЕРЫ СЛУШАТЕЛЯ:

МВС (тембральное восприятие):
  Слышу: отдельные звуки, тембр, артикуляцию
  Уровень: физический, акустический
  Работает: всегда, даже у немузыкантов

СВС (синтаксическое восприятие):
  Слышу: мелодию, ритм, фразы, каденции
  Уровень: паттерн-распознавание
  Работает: при наличии «музыкального слуха»

БВС (семантическое восприятие):
  Слышу: форму, смысл, эмоциональную дугу произведения
  Уровень: музыкальный интеллект, контекстное знание
  Работает: при музыкальной образованности

Резонанс слушателя:
  «Пробирает до мурашек» = временная синхронизация МВС+СВС+БВС
  Нейробиологически: синхронный разряд систем восприятия на всех уровнях
```

### Глава 3. Закон Нечётности в Ритме

#### 3.1 Нечётные ритмы как «живые» структуры

```
ЗАКОН НЕЧЁТНОСТИ И МЕТР:

Чётные метры (2/4, 4/4, 6/8):
  «Маршевые», «квадратные», «механические»
  Математически: симметричная пульсация, нет «центра тяжести»
  Ощущение: стабильность, предсказуемость (→ танцевальность)

Нечётные метры (3/4, 5/4, 7/8, 9/8, 11/8):
  «Живые», «дышащие», «непредсказуемые»
  Математически: есть «тяжёлая» доля, которая асимметрично смещена
  Ощущение: органичность, напряжение, «разговорность»

Почему нечётные ощущаются как «живые»?
  В речи: ударение падает нечётно (не «та-та | та-та», а «ТА-та-та»)
  В природе: сердечный ритм — не 2/4, а ≈72 уд/мин → нечётный цикл
  В движении: шаг = нечётная структура (3 фазы: перенос-опора-отталкивание)

Примеры нечётных ритмов в музыке:
  3/4  — Вальс, Мазурка, Менуэт (Крюков: «тройка естественна»)
  5/4  — «Take Five» (Дэйв Брубек), 3-я часть Шостакович-10
  7/8  — Балканская музыка, «All You Need Is Cash»
  11/8 — Армянская народная музыка, Месечина (Горан Брегович)
  13/8 — Экстремальный джаз, прогрессивный рок
```

#### 3.2 Нечётность в структуре произведения

```
НЕЧЁТНОСТЬ НА МАКРО-УРОВНЕ:

Соната-аллегро:
  Разделов: 3 (Экспозиция — Разработка — Реприза) ✓ нечётно
  Тем в Экспозиции: 2 (главная + побочная) — чётно!
  Вот почему разработка воспринимается как «напряжение»:
  чётная основа разрушается нечётной разработкой

Рондо:
  Тем: A–B–A–C–A → 5 секций (нечётно) ✓
  Возвратов к A: 3 (нечётно) ✓
  «Финальность» рондо = нечётная симметрия

Фуга:
  Проведений темы (идеально): 3, 5, 7 ✓
  Бах, «Хорошо темперированный клавир»: большинство фуг — нечётное число экспозиций

Вывод: классическая форма интуитивно использует нечётность
для создания ощущения завершённости — задолго до формализации закона.
```

### Глава 4. Гармония как Резонанс

#### 4.1 Физика гармонии

```
РЕЗОНАНС В АКУСТИКЕ И МУЗЫКЕ:

Унисон (1:1): два тона одной частоты
  Математика: f₂ = f₁
  Звучание: полное слияние, нет биений
  Аналог: ω_МВС = ω_СВС (полный резонанс)

Октава (2:1): f₂ = 2·f₁
  Математика: первая гармоника
  Звучание: «те же ноты» — ближайший резонанс
  Аналог: МВС и СВС работают с кратными частотами

Квинта (3:2): f₂ = 1.5·f₁
  Математика: третья гармоника / 2
  Звучание: стабильный консонанс
  Акустически: квинта уже «содержится» в обертоновом ряду
  Вот почему квинта звучит «правильно» — это природный резонанс!

Малая секунда (16:15): f₂ ≈ 1.067·f₁
  Математика: далеко от простого соотношения → биения
  Звучание: максимальный диссонанс
  Аналог: десинхронизация сфер (антирезонанс)

ТЕОРЕМА ГАРМОНИИ (формулировка Крюкова):
  Интервал звучит консонантно (в резонансе) тогда и только тогда,
  когда соотношение частот выражается простой дробью (малые целые числа).

  Это прямое применение условия резонанса к акустике.
```

#### 4.2 Тональность как система резонансов

```python
class TonalResonanceSystem:
    """
    Тональная система как иерархия резонансов.
    Моделирует отношения между ступенями гамм
    через принцип резонанса Крюкова.
    """

    # Соотношения частот для чистого строя
    JUST_INTONATION = {
        'I':    (1, 1),    # 1.000 — тоника (резонанс 1:1 с собой)
        'II':   (9, 8),    # 1.125 — секунда (слабый резонанс)
        'III':  (5, 4),    # 1.250 — терция (умеренный резонанс)
        'IV':   (4, 3),    # 1.333 — кварта (сильный резонанс)
        'V':    (3, 2),    # 1.500 — квинта (очень сильный резонанс)
        'VI':   (5, 3),    # 1.667 — секста (умеренный резонанс)
        'VII':  (15, 8),   # 1.875 — септима (слабый, тяготеет к I)
        'VIII': (2, 1),    # 2.000 — октава (резонанс 2:1)
    }

    def resonance_score(self, degree_a, degree_b):
        """
        Вычислить резонанс между двумя ступенями.
        Простые дроби = высокий резонанс.
        """
        ratio_a = self.JUST_INTONATION[degree_a]
        ratio_b = self.JUST_INTONATION[degree_b]

        # Интервальное соотношение
        num = ratio_b[0] * ratio_a[1]
        den = ratio_b[1] * ratio_a[0]

        # Упрощение дроби
        from math import gcd
        g = gcd(num, den)
        num, den = num // g, den // g

        # Простота дроби = мера резонанса
        simplicity = 1.0 / (num + den)

        return simplicity * 10  # Нормализуем к [0, 10]

    def cadence_closure(self, chord_progression):
        """
        Вычислить LCI для аккордовой последовательности.
        LCI = насколько прогрессия «замыкается» на тонику.
        """
        if not chord_progression:
            return 0.0

        start = chord_progression[0]
        end = chord_progression[-1]

        # Лучшая каденция: V→I (доминанта→тоника)
        if start == 'I' and end == 'I':
            closure = 1.0  # Идеальная петля: I → ... → I
        elif chord_progression[-2] == 'V' and end == 'I':
            closure = 0.95  # Полная каденция V→I
        elif chord_progression[-2] == 'IV' and end == 'I':
            closure = 0.85  # Плагальная каденция IV→I
        elif end == 'V':
            closure = 0.5   # Половинная каденция: незамкнутая петля
        elif end == 'VI':
            closure = 0.3   # Прерванная каденция: обман ожидания
        else:
            closure = 0.2

        return closure

    def analyze_piece(self, harmonic_reduction):
        """
        Анализ произведения через LCI гармонических петель.
        """
        phrase_groups = self._segment_into_phrases(harmonic_reduction)
        lcis = []

        for phrase in phrase_groups:
            lci = self.cadence_closure(phrase)
            lcis.append(lci)

        return {
            'mean_lci': sum(lcis) / len(lcis),
            'lci_profile': lcis,
            'interpretation': self._interpret_lci_profile(lcis),
            'resonance_moments': [i for i, lci in enumerate(lcis) if lci > 0.85]
        }

    def _interpret_lci_profile(self, lcis):
        """Интерпретация LCI-профиля произведения."""
        mean_lci = sum(lcis) / len(lcis)
        if mean_lci > 0.80:
            return 'Сильно тональное, замкнутое — классика, народная музыка'
        elif mean_lci > 0.60:
            return 'Умеренно тональное — романтика, джаз'
        elif mean_lci > 0.40:
            return 'Слабо тональное — импрессионизм, модальность'
        else:
            return 'Атональное, открытое — авангард, серийная техника'
```

### Глава 5. Контрапункт как Камуфляж/Угроза

#### 5.1 Двойственность в полифонии

```
КОНТРАПУНКТ = КАМУФЛЯЖ/УГРОЗА В МУЗЫКЕ

В системе Крюкова: каждое действие двойственно —
  явное движение (угроза) + скрытое намерение (камуфляж)

В полифонии: два или более голосов движутся независимо, создавая:
  Явный уровень: горизонтальная мелодия каждого голоса
  Скрытый уровень: вертикальные интервалы (гармония) между голосами

  Слушатель может фокусироваться на любом уровне:
    → Следить за сопрано (угроза — явная мелодия)
    → Следить за «разговором» голосов (камуфляж — скрытая структура)

ДВОЙНОЕ ПРОТИВОДВИЖЕНИЕ (инвертируемый контрапункт):
  Верхний голос: восходящее движение (активная угроза)
  Нижний голос: нисходящее движение (скрытый контрмотив)
  Совмещение: конструктивный/деструктивный резонанс

  При инверсии (когда голоса меняются местами):
    Угроза становится камуфляжем, камуфляж — угрозой
    Это точно «смена фаз» в системе Крюкова!
```

#### 5.2 Фуга как система управления

```
ФУГА КАК ИНФОРМАЦИОННАЯ СИСТЕМА:

Тема (Dux/Comes): главный архетип (= ОБД Крюкова)
  Все остальные — вариации на тему

Экспозиция: тема проходит все голоса (= первичное распределение)
  Нечётное число голосов: 3, 5 (нечётность!)
  Порядок вступления: строгий (= SEQUENTIAL режим)

Разработка: тема дробится, стреттируется, инвертируется
  (= ADAPTIVE режим — система ищет новые комбинации)

Стретто: темы накладываются друг на друга
  (= DUAL режим — параллельное исполнение)
  Резонанс стретто: темы в стретто = звучат «плотнее» = усиление

Завершение: тема возвращается в исходном виде
  (= петля замкнулась)

УПРАВЛЕНЧЕСКАЯ МЕТАФОРА:
  Фуга = идеально управляемая организация:
  Один принцип (тема) → развивается всей командой → через кризис (разработка)
  → параллельные потоки (стретто) → синтез (заключение)
```

## ЧАСТЬ II. ХОРЕОГРАФИЯ

### Глава 6. Танец как Трёхмерная Петля

#### 6.1 Танцевальное движение через архетипы

```
ХОРЕОГРАФИЯ И СИСТЕМА КРЮКОВА:

Петля в танце:
  Любое законченное движение = петля в 3D-пространстве
  Rond de jambe (балет): буквально круговое движение ноги
  Пируэт: петля вокруг вертикальной оси
  Grand battement: дуга — незамкнутая петля, ищущая продолжения

Три сферы тела в танце:
  МВС: кисти, стопы, пальцы — детали и акценты
  СВС: руки, ноги — основное движение, линии
  БВС: торс, позвоночник — опора и баланс

Резонанс в танце:
  Pas de deux: два тела в резонансе → единое движение
  Кордебалет: 20+ тел в резонансе → «одно движение»
  Нарушение резонанса = видимая ошибка в ансамбле

Закон нечётности в хореографии:
  Комбинация: нечётное число движений → заканчивается «правильной» ногой
  8 тактов = 8 шагов → нечётный вариант: 7 шагов + 1 акцент
  Профессиональные хореографы: интуитивно считают восьмёрками (8 = 2×4),
  но делают нечётными фразами!
```

#### 6.2 LCI хореографического движения

```python
class ChoreographyAnalyzer:
    """
    Анализ хореографии через архетипы движения Крюкова.
    Использует данные motion capture для вычисления метрик.
    """

    def analyze_sequence(self, mocap_data, fps=60):
        """
        Анализ последовательности движений.

        mocap_data: словарь {joint_name: [(x,y,z,t), ...]}
        """
        results = {}

        # Вычислить LCI для каждой сферы
        mvs_joints = ['left_wrist', 'right_wrist', 'left_ankle', 'right_ankle']
        svs_joints = ['left_elbow', 'right_elbow', 'left_knee', 'right_knee']
        bvs_joints = ['spine', 'pelvis', 'left_shoulder', 'right_shoulder']

        lci_mvs = self._sphere_lci(mocap_data, mvs_joints)
        lci_svs = self._sphere_lci(mocap_data, svs_joints)
        lci_bvs = self._sphere_lci(mocap_data, bvs_joints)

        # Резонанс: синхронность частот трёх сфер
        freq_mvs = self._dominant_frequency(mocap_data, mvs_joints, fps)
        freq_svs = self._dominant_frequency(mocap_data, svs_joints, fps)
        freq_bvs = self._dominant_frequency(mocap_data, bvs_joints, fps)

        f_mean = (freq_mvs + freq_svs + freq_bvs) / 3
        if f_mean > 0:
            resonance = 1.0 - (
                abs(freq_mvs - f_mean) +
                abs(freq_svs - f_mean) +
                abs(freq_bvs - f_mean)
            ) / (3 * f_mean)
        else:
            resonance = 0.0

        # Нечётность ритмической структуры
        phrase_lengths = self._detect_phrases(mocap_data, fps)
        odd_ratio = sum(1 for l in phrase_lengths if l % 2 == 1) / len(phrase_lengths) \
                    if phrase_lengths else 0.0

        results = {
            'lci_mvs': round(lci_mvs, 3),
            'lci_svs': round(lci_svs, 3),
            'lci_bvs': round(lci_bvs, 3),
            'overall_lci': round((lci_mvs + lci_svs + lci_bvs) / 3, 3),
            'resonance_score': round(max(0.0, resonance), 3),
            'odd_phrase_ratio': round(odd_ratio, 3),
            'interpretation': self._interpret(lci_mvs, lci_svs, lci_bvs, resonance)
        }

        return results

    def _sphere_lci(self, mocap_data, joints):
        """LCI для группы суставов (одной сферы)."""
        lcis = []
        for joint in joints:
            if joint in mocap_data:
                trajectory = [(p[0], p[1]) for p in mocap_data[joint]]
                lcis.append(self._compute_lci(trajectory))
        return sum(lcis) / len(lcis) if lcis else 0.0

    def _compute_lci(self, trajectory):
        """LCI траектории через площадь выпуклой оболочки."""
        import numpy as np
        pts = np.array(trajectory)
        if len(pts) < 4:
            return 0.0
        try:
            from scipy.spatial import ConvexHull
            hull = ConvexHull(pts)
            hull_area = hull.volume
        except Exception:
            return 0.0
        x_range = pts[:, 0].max() - pts[:, 0].min()
        y_range = pts[:, 1].max() - pts[:, 1].min()
        bbox = x_range * y_range
        return min(1.0, hull_area / bbox) if bbox > 1e-6 else 0.0

    def _dominant_frequency(self, mocap_data, joints, fps):
        """Доминирующая частота движения группы суставов."""
        import numpy as np
        freqs = []
        for joint in joints:
            if joint in mocap_data:
                signal = [p[0] for p in mocap_data[joint]]
                fft_vals = np.abs(np.fft.rfft(signal))
                fft_freqs = np.fft.rfftfreq(len(signal), d=1.0/fps)
                dominant = fft_freqs[np.argmax(fft_vals[1:]) + 1]
                freqs.append(dominant)
        return sum(freqs) / len(freqs) if freqs else 0.0

    def _detect_phrases(self, mocap_data, fps):
        """Обнаружить длины фраз через точки минимальной скорости."""
        import numpy as np
        # Используем позицию запястья как индикатор фраз
        if 'right_wrist' not in mocap_data:
            return []
        positions = np.array([p[:3] for p in mocap_data['right_wrist']])
        velocities = np.diff(positions, axis=0)
        speeds = np.linalg.norm(velocities, axis=1)

        # Точки минимальной скорости = границы фраз
        threshold = speeds.mean() * 0.3
        phrase_boundaries = np.where(speeds < threshold)[0]

        if len(phrase_boundaries) < 2:
            return []

        # Длины в «счётных единицах» (такты ≈ 0.5 сек)
        phrase_lengths = []
        for i in range(1, len(phrase_boundaries)):
            length_frames = phrase_boundaries[i] - phrase_boundaries[i-1]
            length_beats = round(length_frames / (fps * 0.5))
            if length_beats > 0:
                phrase_lengths.append(length_beats)

        return phrase_lengths

    def _interpret(self, lci_mvs, lci_svs, lci_bvs, resonance):
        """Интерпретация результатов для хореографа."""
        issues = []
        if lci_mvs < 0.5:
            issues.append('МВС: угловатые движения рук/стоп — нужны петлевые переходы')
        if lci_svs < 0.6:
            issues.append('СВС: резкость в локтях/коленях — добавить плавность')
        if lci_bvs < 0.7:
            issues.append('БВС: жёсткий торс — работа с позвоночником')
        if resonance < 0.65:
            issues.append('РЕЗОНАНС: части тела двигаются несинхронно')
        if not issues:
            return 'Отличная техника! Все сферы в резонансе.'
        return '; '.join(issues)
```

#### 8.1 Генерация музыки на основе архетипов

```python
import numpy as np
import random

class KryukovMusicGenerator:
    """
    Генератор музыкальных фраз на основе архетипов движения Крюкова.
    Принципы: петли, нечётность, резонанс, закон памяти.
    """

    # Пентатоника C: C D E G A (5 нот — нечётное число!)
    PENTATONIC_C = [60, 62, 64, 67, 69]  # MIDI-ноты

    # Нечётные длины фраз (в четвертях)
    ODD_PHRASE_LENGTHS = [3, 5, 7, 9]

    def generate_loop_phrase(self, start_pitch, amplitude=5, phrase_len=None):
        """
        Генерировать петлевую мелодическую фразу.

        start_pitch: начальная нота (MIDI)
        amplitude: диапазон фразы (в полутонах)
        phrase_len: длина в нотах (нечётное)
        """
        if phrase_len is None:
            phrase_len = random.choice(self.ODD_PHRASE_LENGTHS)

        if phrase_len % 2 == 0:
            phrase_len += 1  # Принудительно нечётное!

        phrase = [start_pitch]

        # Генерировать «восходящую» половину
        ascending = phrase_len // 2
        for i in range(ascending):
            # Петлевое движение: плавное восхождение
            step = random.choice([1, 2])  # Секунда или терция
            new_pitch = phrase[-1] + step
            if new_pitch - start_pitch > amplitude:
                new_pitch = phrase[-1] - 1  # Разворот петли
            phrase.append(new_pitch)

        # Генерировать «нисходящую» половину (возврат петли)
        descending = phrase_len - ascending - 1
        for i in range(descending):
            step = random.choice([1, 2])
            new_pitch = phrase[-1] - step
            phrase.append(new_pitch)

        # Замыкаем петлю: последняя нота близка к первой
        phrase.append(start_pitch + random.choice([-1, 0, 1]))

        return phrase

    def generate_three_sphere_piece(self, duration_bars=16):
        """
        Генерировать пьесу с трёхсферной архитектурой.

        МВС: быстрые восьмые ноты (украшения)
        СВС: мелодические фразы (четверти)
        БВС: гармонический план (целые ноты)
        """
        piece = {
            'bvs_harmony': [],   # Аккорды (одна на такт)
            'svs_melody': [],    # Мелодия (четверти)
            'mvs_ornaments': []  # Украшения (восьмые)
        }

        # БВС: нечётное число гармонических секций
        n_sections = random.choice([3, 5, 7])
        harmony_cycle = ['I', 'IV', 'V', 'I', 'VI', 'II', 'V']
        for bar in range(duration_bars):
            chord = harmony_cycle[bar % len(harmony_cycle)]
            piece['bvs_harmony'].append(chord)

        # СВС: петлевые фразы (нечётная длина)
        current_pitch = 60  # C4
        for bar in range(duration_bars):
            phrase = self.generate_loop_phrase(current_pitch, amplitude=7, phrase_len=5)
            piece['svs_melody'].extend(phrase)
            # Каждая фраза начинается там, где закончилась предыдущая
            current_pitch = phrase[-1]

        # МВС: украшения вокруг мелодических нот
        for note in piece['svs_melody']:
            ornament = self._generate_ornament(note)
            piece['mvs_ornaments'].append(ornament)

        # Вычислить резонанс: синхронность трёх слоёв
        resonance = self._compute_piece_resonance(piece)
        piece['resonance_score'] = resonance

        return piece

    def _generate_ornament(self, base_note):
        """Генерировать МВС-украшение для ноты."""
        ornament_types = ['none', 'mordent', 'trill', 'turn']
        choice = random.choice(ornament_types)
        if choice == 'none':
            return [base_note]
        elif choice == 'mordent':
            return [base_note, base_note + 1, base_note]  # Морденте (петля!)
        elif choice == 'trill':
            # Трель = быстрая петля двух нот
            return [base_note, base_note + 2] * 3 + [base_note]
        else:  # turn
            return [base_note + 1, base_note, base_note - 1, base_note]

    def _compute_piece_resonance(self, piece):
        """Вычислить резонанс трёх уровней произведения."""
        # Упрощённая оценка: соответствие мелодии гармонии
        harmony_notes = {
            'I': [60, 64, 67],   # C E G
            'IV': [65, 69, 72],  # F A C
            'V': [67, 71, 74],   # G B D
            'VI': [69, 72, 76],  # A C E
            'II': [62, 65, 69],  # D F A
        }

        total = 0
        matches = 0
        for i, chord in enumerate(piece['bvs_harmony']):
            # Ноты мелодии в этом такте
            bar_notes = piece['svs_melody'][i*5:(i+1)*5]
            chord_tones = harmony_notes.get(chord, [])

            for note in bar_notes:
                total += 1
                if note % 12 in [c % 12 for c in chord_tones]:
                    matches += 1

        return matches / total if total > 0 else 0.0
```

#### 9.1 Музыкотерапия на основе архетипов

```
ПРОТОКОЛ «МУЗЫКАЛЬНАЯ РЕАБИЛИТАЦИЯ» (связь с Томом 6):

Приложение к ДЦП и нарушениям резонанса:
  (см. Том 6, Глава 5 — Музыкотерапия как резонансный инструмент)

Расширение через архетипы музыки:

1. Выбор инструмента по уровню поражения:
   МВС нарушена → барабан (крупные движения)
   СВС нарушена → ксилофон (предплечье активно)
   БВС нарушена → хоровое пение (корпус, дыхание)

2. Нечётный ритм для «встряхивания» паттернов:
   7/8 или 5/4 разрушают спастические «чётные» паттерны
   Непредсказуемость → мозг ищет новые нейронные пути → нейропластичность

3. Петлевые мелодические задания:
   Пациент должен завершить начатую петлю-фразу:
     Терапевт: До-Ре-Ми-Фа-Соль...
     Пациент:  ...Ля-Си-До (замыкает петлю)
   LCI задания: насколько пациент «замкнул» мелодическую петлю

4. Резонансный дуэт:
   Терапевт и пациент синхронизируют ритм
   Постепенно пациент «ведёт» — терапевт следует
   Цель: пациент достигает резонанса своей инициативой
```

## ЗАКЛЮЧЕНИЕ

**Ключевые выводы Книги 11:**

1. **Музыкальная фраза = петля** в звуковом пространстве. LCI фразы измеряет степень тонального «замыкания» (0 = атональность, 1 = полная каденция).

2. **Три сферы исполнителя**: МВС (техника/пальцы), СВС (фраза/рука), БВС (форма/художественный замысел). Резонанс трёх сфер = «магия» живого исполнения.

3. **Нечётный метр** (3/4, 5/4, 7/8) — «живые» структуры, соответствующие естественным ритмам тела и речи. Нечётность создаёт ощущение завершённости.

4. **Гармония = резонанс**: консонантные интервалы = простые соотношения частот. Теорема резонанса Крюкова — это и есть теория гармонии.

5. **Контрапункт = камуфляж/угроза**: явный голос (угроза) + скрытая полифоническая структура (камуфляж). Фуга — идеально управляемая система с единым «архетипом» (темой).

6. **`KryukovMusicGenerator`**: алгоритмическая генерация музыки на основе архетипов. Петлевые фразы нечётной длины + трёхсферная архитектура + LCI-оценка.

7. **Музыкотерапевтический протокол**: расширение методов Тома 6 через нечётные ритмы, петлевые задания и резонансный дуэт.
