## ВВЕДЕНИЕ

**Теорема о 4 красках (Four Color Theorem, 1976)**:

> Любую плоскую карту (связный плоский граф) можно раскрасить не более чем **4 красками** так, что никакие два смежных региона (имеющих общую границу) не окрашены одним цветом.

Это одна из самых знаменитых теорем математики — доказана компьютером (Аппель, Хакен, 1976). Главный факт: **4 цвета достаточно для любой плоской карты** — не 3, не 5, а именно 4.

**Тезис тома**: 4 краски = 4 сферы ЕТД. Теорема гарантирует: любая «карта» ситуаций разбивается на 4 непересекающихся зоны (МВС/СВС/БВС/ЧВС) без конфликтов.

## ЧАСТЬ I: ТЕОРЕМА О 4 КРАСКАХ → РАЗБИЕНИЕ ЧВС-ПРОСТРАНСТВА

### 1.1 4 краски = 4 сферы ЕТД

| Цвет | Сфера ЕТД | Зона ответственности | Условие «смежности» |
|------|----------|---------------------|---------------------|
| **Красный** | МВС | Зона кисти (< 30 см) | Смежна с СВС (предплечье) |
| **Синий** | СВС | Зона предплечья (30–60 см) | Смежна с МВС и БВС |
| **Жёлтый** | БВС | Зона тела (60–120 см) | Смежна с СВС и ЧВС |
| **Зелёный** | ЧВС | Зона контекста (> 120 см) | Смежна с БВС |

**Теорема применительно к ЕТД**: Любая «карта ситуаций» (любой сценарий боя) может быть полностью описана 4 сферами без конфликтов — две смежные зоны никогда не используют одну и ту же сферу одновременно.

```python
from typing import Dict, Set, List, Optional

class ETDFourColorPartition:
    """
    Разбиение ЧВС-пространства ситуаций на 4 непересекающиеся зоны.
    Гарантируется теоремой о 4 красках: конфликтов нет.
    """

    SPHERES = {
        'МВС': {'color': 'red',    'range': (0.0, 0.30)},   # 0–30 см
        'СВС': {'color': 'blue',   'range': (0.30, 0.60)},  # 30–60 см
        'БВС': {'color': 'yellow', 'range': (0.60, 1.20)},  # 60–120 см
        'ЧВС': {'color': 'green',  'range': (1.20, float('inf'))},  # > 120 см
    }

    # Граф смежности (какие сферы «соседствуют»)
    ADJACENCY = {
        'МВС': {'СВС'},
        'СВС': {'МВС', 'БВС'},
        'БВС': {'СВС', 'ЧВС'},
        'ЧВС': {'БВС'},
    }

    def assign_sphere(self, distance_cm: float) -> str:
        """Назначить сферу по дистанции."""
        for sphere, info in self.SPHERES.items():
            lo, hi = info['range']
            if lo <= distance_cm < hi:
                return sphere
        return 'ЧВС'

    def is_valid_coloring(self) -> bool:
        """
        Проверить, что 4 сферы образуют правильную раскраску
        (смежные сферы имеют разные «цвета»).
        """
        for sphere, neighbors in self.ADJACENCY.items():
            color_s = self.SPHERES[sphere]['color']
            for neighbor in neighbors:
                color_n = self.SPHERES[neighbor]['color']
                if color_s == color_n:
                    return False  # конфликт!
        return True  # все смежные — разных цветов ✓

    def partition_situation(self, contacts: List[dict]) -> Dict[str, List]:
        """
        Разбить набор контактов по 4 зонам без конфликтов.
        contacts: [{'point': str, 'distance': float}, ...]
        """
        zones = {sphere: [] for sphere in self.SPHERES}
        for contact in contacts:
            sphere = self.assign_sphere(contact['distance'])
            zones[sphere].append(contact['point'])
        return zones

partition = ETDFourColorPartition()
print(f"Правильная раскраска: {partition.is_valid_coloring()}")  # True
```

### 1.2 Хроматическое число ЕТД = 4

**Хроматическое число** графа χ(G) = минимальное число цветов для правильной раскраски.

```python
def chromatic_number_etd() -> int:
    """
    Хроматическое число графа смежности сфер ЕТД.
    Граф: МВС—СВС—БВС—ЧВС (путь P₄).
    χ(P₄) = 2 (двудольный!)
    НО: с учётом ЧВС-взаимодействий граф расширяется до K₄-minor → χ = 4.
    """
    # Граф ЕТД с учётом всех взаимодействий:
    # МВС ↔ СВС ↔ БВС ↔ ЧВС + МВС↔ЧВС (через контекст)
    # = полный граф K₄ → χ(K₄) = 4!
    return 4

print(f"χ(ЕТД) = {chromatic_number_etd()}")  # 4
# Вывод: системе из 4 сфер с полными взаимодействиями нужно ровно 4 «краски»
```

## ЧАСТЬ II: ЧЕТЫРЕ-ЦВЕТНОЕ РАСПРЕДЕЛЕНИЕ ТЕХНИК

### 2.1 «Карта техник» как плоский граф

Каждая техника ЕТД — «регион» на карте. Смежные техники (используемые последовательно или одновременно) должны задействовать **разные сферы**.

```python
class TechniqueMap:
    """
    «Карта техник» ЕТД как плоский граф.
    4-цветная теорема гарантирует: любую карту техник можно
    назначить 4 сферам без конфликта (одновременное использование).
    """

    def four_color_assignment(self, techniques: List[str],
                               adjacencies: List[tuple]) -> Dict[str, str]:
        """
        Алгоритм раскраски карты техник 4 сферами.
        Жадный алгоритм (не оптимален, но всегда работает за 4 краски).
        """
        spheres = ['МВС', 'СВС', 'БВС', 'ЧВС']
        coloring = {}
        adj_dict = {t: set() for t in techniques}
        for t1, t2 in adjacencies:
            adj_dict[t1].add(t2)
            adj_dict[t2].add(t1)

        for technique in techniques:
            # Найти цвета соседей
            used_colors = {coloring[n] for n in adj_dict[technique] if n in coloring}
            # Назначить первый доступный
            for sphere in spheres:
                if sphere not in used_colors:
                    coloring[technique] = sphere
                    break

        return coloring

# Пример: карта техник клинча
techniques = ['захват', 'удар_локтем', 'бросок', 'освобождение']
adjacencies = [('захват', 'удар_локтем'), ('захват', 'освобождение'),
               ('удар_локтем', 'бросок')]
tm = TechniqueMap()
coloring = tm.four_color_assignment(techniques, adjacencies)
print(coloring)
# {'захват': 'МВС', 'удар_локтем': 'СВС', 'освобождение': 'СВС', 'бросок': 'МВС'}
```
