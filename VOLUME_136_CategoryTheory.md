## ВВЕДЕНИЕ

**Теория категорий** (1945) — «математика математики». Четыре ключевых понятия:

1. **Объект** (Object) — «то, что существует»
2. **Морфизм** (Morphism / Arrow) — «стрелка» между объектами
3. **Функтор** (Functor) — «стрелка» между категориями
4. **Натуральное преобразование** — «стрелка» между функторами

Эти 4 уровня образуют **иерархию абстракции**. Теория категорий — наиболее абстрактный язык математики.

**Тезис тома**: Система ЕТД — категория. 4 элемента теории = 4 уровня описания движений: от конкретного (объект) до универсального (натуральное преобразование = мастерство).

## ЧАСТЬ I: 4 КАТЕГОРИАЛЬНЫХ ЭЛЕМЕНТА → 4 УРОВНЯ ЕТД

### 1.1 Объект → Состояние сферы

```python
from dataclasses import dataclass
from typing import Callable, Dict, Any

@dataclass
class ETDObject:
    """
    Объект категории ЕТД = состояние системы сфер в данный момент.
    Объект — «снимок» конфигурации четырёх сфер.
    """
    mvs_angle: float   # угол МВС (рад)
    svs_angle: float   # угол СВС (рад)
    bvs_angle: float   # угол БВС (рад)
    cvs_state: str     # состояние ЧВС (одно из 5)
    lci: float         # текущий ЛЗП

    def __repr__(self):
        return f"ETD({self.cvs_state}, МВС={self.mvs_angle:.2f}, ЛЗП={self.lci:.2f})"
```

### 1.2 Морфизм → Техника (движение между состояниями)

```python
@dataclass
class ETDMorphism:
    """
    Морфизм категории ЕТД = техника или приём:
    переводит систему из состояния A → состояние B.

    Аксиомы морфизмов:
    1. Тождественный морфизм: id_A: A → A (нейтральная позиция)
    2. Композиция: (g∘f): A→B→C (цепочка техник)
    3. Ассоциативность: h∘(g∘f) = (h∘g)∘f
    """
    source: ETDObject
    target: ETDObject
    name: str
    lci_delta: float    # изменение ЛЗП при выполнении

    def compose(self, other: 'ETDMorphism') -> 'ETDMorphism':
        """
        Композиция техник: self; other (сначала self, потом other).
        Условие: self.target = other.source.
        """
        assert self.target == other.source, "Несовместимые техники!"
        return ETDMorphism(
            source=self.source,
            target=other.target,
            name=f"{self.name} → {other.name}",
            lci_delta=self.lci_delta + other.lci_delta
        )

    @classmethod
    def identity(cls, state: ETDObject) -> 'ETDMorphism':
        """Тождественный морфизм: нейтральная позиция."""
        return cls(source=state, target=state, name='id', lci_delta=0.0)
```

### 1.3 Функтор → Перевод системы ЕТД в другую систему

```python
class ETDFunctor:
    """
    Функтор категории ЕТД:
    Переводит объекты и морфизмы одной системы в другую.

    Пример: F: ЕТД_стоя → ЕТД_лёжа
    Каждая техника стоя → соответствующая техника лёжа.
    """

    def __init__(self, name: str):
        self.name = name

    def map_object(self, obj: ETDObject) -> ETDObject:
        """Перевод объекта (состояния) в другую систему."""
        raise NotImplementedError

    def map_morphism(self, morph: ETDMorphism) -> ETDMorphism:
        """Перевод морфизма (техники) в другую систему."""
        raise NotImplementedError

    def check_functoriality(self, f: ETDMorphism, g: ETDMorphism) -> bool:
        """
        Проверить функториальность:
        F(g ∘ f) = F(g) ∘ F(f)
        «Функтор сохраняет структуру» = универсальный принцип переноса.
        """
        # В реальной системе: техника стоя → техника лёжа с сохранением структуры
        return True   # предполагаем сохранение структуры

class GroundToStandingFunctor(ETDFunctor):
    """
    Функтор F: ЕТД_лёжа → ЕТД_стоя.
    Каждая техника в партере → соответствующая техника в стойке.
    """

    def map_object(self, obj: ETDObject) -> ETDObject:
        # В стойке углы немного другие
        return ETDObject(
            mvs_angle=obj.mvs_angle,
            svs_angle=obj.svs_angle + 0.2,   # компенсация позиции
            bvs_angle=obj.bvs_angle - 0.1,
            cvs_state=obj.cvs_state,
            lci=obj.lci * 0.9   # немного теряем в лёжа
        )
```

### 1.4 Натуральное преобразование → Мастерство (перевод между стилями)

```python
class NaturalTransformation:
    """
    Натуральное преобразование η: F ⟹ G
    «Стрелка» между двумя функторами.

    В ЕТД: η = мастерство.
    Мастер переводит ЛЮБУЮ технику одного стиля в другой,
    сохраняя все структурные отношения.

    Условие натуральности (квадрат коммутирует):
    G(f) ∘ η_A = η_B ∘ F(f)

    Физический смысл: «как бы ни менялась техника,
    мастерство переводит её корректно».
    """

    def __init__(self, functor_F: ETDFunctor, functor_G: ETDFunctor):
        self.F = functor_F
        self.G = functor_G

    def component_at(self, obj: ETDObject) -> ETDMorphism:
        """
        Компонента η_A: F(A) → G(A).
        Конкретный «перевод» в данном состоянии.
        """
        f_obj = self.F.map_object(obj)
        g_obj = self.G.map_object(obj)
        return ETDMorphism(
            source=f_obj,
            target=g_obj,
            name=f'η_{obj.cvs_state}',
            lci_delta=g_obj.lci - f_obj.lci
        )

    def naturality_check(self, morph: ETDMorphism) -> bool:
        """
        Проверка условия натуральности.
        Диаграмма должна коммутировать.
        """
        # G(f) ∘ η_A == η_B ∘ F(f)
        # Если мастерство истинное → коммутирует всегда
        return True
```

## ЧАСТЬ II: КАТЕГОРИЯ ЕТД — ФОРМАЛЬНОЕ ОПРЕДЕЛЕНИЕ

```
Категория C_ЕТД:

Объекты: Ob(C) = {все состояния системы 4 сфер}
Морфизмы: Hom(A, B) = {все техники, переводящие A → B}
Тождественный морфизм: id_A для каждого A ∈ Ob
Композиция: ∘ (цепочки техник)

Аксиомы:
✓ Тождественность: f ∘ id_A = f = id_B ∘ f
✓ Ассоциативность: h ∘ (g ∘ f) = (h ∘ g) ∘ f
```

| **Морфизм** | Техника | Приём | Секунды |
| **Функтор** | Стиль/система | Дисциплина | Годы |

## ЗАКЛЮЧЕНИЕ

**4 элемента теории категорий** → **4 уровня системы ЕТД**:

1. **Объект** → Мгновенное состояние 4 сфер
2. **Морфизм** → Техника (переводит A→B)
3. **Функтор** → Стиль/дисциплина (переводит систему целиком)
4. **Натуральное преобразование** → Мастерство (переводит стиль в стиль, сохраняя всё)

> Натуральное преобразование = мастерство: оно «работает» для ЛЮБОЙ техники одновременно, сохраняя все структурные отношения. Это — математическое определение универсальности.
