## ВВЕДЕНИЕ

В комплексном анализе аналитическая функция может иметь **особые точки** — места, где она перестаёт быть аналитической. Ровно **4 типа**:

1. **Устранимая особенность** — предел существует, функцию можно «доопределить»
2. **Полюс** — функция уходит в бесконечность (|f(z)| → ∞)
3. **Существенная особенность** — поведение хаотично (теорема Пикара)
4. **Точка ветвления** — многозначность (корень, логарифм)

**Тезис тома**: 4 типа особых точек = 4 типа «критических ситуаций» в ЕТД, где стандартное ЧВС-поведение нарушается.

## ЧАСТЬ I: 4 ОСОБЫХ ТОЧКИ → 4 ТИПА КРИТИЧЕСКИХ СИТУАЦИЙ ЕТД

### 1.1 Таблица соответствий

| Особая точка | Математика | ЧВС-ситуация | Реакция ЕТД |
|-------------|-----------|-------------|------------|
| **Устранимая** | lim f(z) конечен | Мнимая угроза — нет реальной атаки | Доопределить: игнор / провокация |
| **Полюс** | \|f(z)\| → ∞ | Атака нарастает до максимума | Контратаковать в точке |
| **Существенная** | Нет предела (теорема Пикара) | Хаотичная непредсказуемая ситуация | Перейти в ЧВС-Виртуальное |
| **Ветвление** | f(z) многозначна | Двусмысленная ситуация (два исхода) | Выбрать ветвь осознанно |

```python
import cmath
import math
from typing import Optional

class ComplexSingularityETD:
    """
    4 типа особых точек комплексного анализа
    как 4 типа критических ЧВС-ситуаций.
    """

    @staticmethod
    def classify_singularity(situation: dict) -> dict:
        """
        Классифицировать тип критической ситуации.
        """
        threat_level = situation.get('угроза', 0.0)
        predictability = situation.get('предсказуемость', 1.0)
        ambiguity = situation.get('двусмысленность', False)
        real_attack = situation.get('реальная_атака', True)

        if not real_attack and threat_level < 0.3:
            return {
                'тип': 'Устранимая особенность',
                'описание': 'Мнимая угроза — «доопределить» нейтральной реакцией',
                'ЧВС': 'Виртуальное',
                'действие': 'Игнорировать / Провокация',
                'формула': 'lim_{z→z₀} f(z) = конечное значение'
            }
        elif threat_level > 0.8 and predictability > 0.7:
            return {
                'тип': 'Полюс порядка n',
                'описание': 'Атака достигает максимума — полная концентрация',
                'ЧВС': 'Инструментальное',
                'действие': 'Контратаковать в точке максимума угрозы',
                'формула': 'f(z) ~ C/(z−z₀)ⁿ при z→z₀'
            }
        elif predictability < 0.3:
            return {
                'тип': 'Существенная особенность',
                'описание': 'Хаотичная ситуация — теорема Пикара (принимает все значения)',
                'ЧВС': 'Пространственное',
                'действие': 'Перейти в ЧВС-Пространственное, дистанцироваться',
                'формула': 'f принимает любые значения (кроме м.б. одного) в окр. z₀'
            }
        elif ambiguity:
            return {
                'тип': 'Точка ветвления',
                'описание': 'Двусмысленная ситуация — два равнозначных исхода',
                'ЧВС': 'Доменное',
                'действие': 'Выбрать одну «ветвь» и полностью её реализовать',
                'формула': 'f(z) = z^{1/n}, log(z) — многозначные функции'
            }

        return {'тип': 'Регулярная точка', 'ЧВС': 'Внутреннее', 'действие': 'Стандартная схема'}

    def residue_at_pole(self, order: int, lci: float) -> float:
        """
        Вычет в полюсе = «захваченный потенциал» при контратаке в точке максимума.
        Res f = lim_{z→z₀} (z−z₀)^n · f(z) / (n−1)!
        ЕТД: Вычет ЛЗП = мгновенный захват потенциала атакующего.
        """
        # Вычет полюса порядка n = ЛЗП × (n−1)! коэффициент
        import math
        factorial_n_minus_1 = math.factorial(max(0, order - 1))
        return lci * order / factorial_n_minus_1
```

### 1.2 Теорема Пикара = «Хаотичный противник»

В комплексном анализе: вблизи существенной особенности f принимает все комплексные значения (кроме, возможно, одного). Эта теорема — самый «экзотический» результат.

```python
def picard_theorem_etd(chaos_level: float) -> str:
    """
    Теорема Пикара в ЕТД:
    «Непредсказуемый противник в окрестности точки хаоса
    реализует ВСЕ возможные действия (кроме, м.б., одного).»

    Следствие: нельзя угадать — нужно реагировать на любое.
    Стратегия: ЧВС-Пространственное (максимальная дистанция и наблюдение).
    """
    if chaos_level > 0.8:
        return ("Существенная особенность: противник непредсказуем. "
                "Пикар: он реализует ВСЕ возможные атаки. "
                "Стратегия: дистанция + наблюдение (ЧВС-Пространственное).")
    return "Регулярная ситуация — стандартный ЧВС."
```

## ЧАСТЬ II: ВЫЧЕТЫ И ТЕОРЕМА КОШИ-ГУРСА → СУММАРНЫЙ ЛЗП

### 2.1 Формула Коши = суммарный ЛЗП по контуру

```python
def cauchy_lci_formula(residues: list) -> float:
    """
    Теорема о вычетах Коши:
    ∮_C f(z) dz = 2πi · Σ Res(f, z_k)

    ЕТД-аналог:
    Суммарный ЛЗП по схеме = 2π × (сумма ЧВС-источников внутри контура).

    Каждая ЧВС — «особая точка» (источник ЛЗП).
    Суммарный ЛЗП = 2π × сумма вычетов.
    """
    return 2 * math.pi * sum(residues)

# При 4 ЧВС с вычетами π/4 каждый:
residues = [math.pi/4, math.pi/4, math.pi/4, math.pi/4]
total_lci = cauchy_lci_formula(residues)
print(f"Суммарный ЛЗП: {total_lci:.3f}")  # = 2π × π = 2π² ≈ 19.74
```

## ЗАКЛЮЧЕНИЕ

**4 типа особых точек** → **4 типа критических ЧВС-ситуаций**:

1. **Устранимая** → Мнимая угроза: доопределить нейтральной реакцией
2. **Полюс** → Атака в максимуме: контратаковать точно в пике
3. **Существенная** → Хаос: дистанция (теорема Пикара — всё возможно)
4. **Ветвление** → Двусмысленность: выбрать одну ветвь осознанно

> Формула Коши: Суммарный ЛЗП = 2π × Σ вычетов. Каждая ЧВС — «полюс» (источник ЛЗП). При 4 ЧВС с вычетом π/4 каждый → ЛЗП_total = 2π².
