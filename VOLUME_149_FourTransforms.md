## ВВЕДЕНИЕ

В математике существуют **4 фундаментальных интегральных преобразования**, каждое из которых переводит функцию в «другую область» для удобного анализа:

1. **Преобразование Фурье** — разложение в спектр частот (гармонический анализ)
2. **Преобразование Лапласа** — перевод дифференциальных уравнений в алгебраические
3. **Преобразование Хартли** — вещественный аналог Фурье (только вещественные числа)
4. **Вейвлет-преобразование** — частотно-временной анализ (локальный спектр)

**Тезис тома**: 4 интегральных преобразования = 4 способа «видеть» ЛЗП в разных базисах. Каждое раскрывает свой аспект системы сфер.

## ЧАСТЬ I: 4 ПРЕОБРАЗОВАНИЯ → 4 ВИДА АНАЛИЗА ЛЗП

```python
import math
import cmath
from typing import Callable, List

class IntegralTransformsETD:
    """
    4 интегральных преобразования применительно к ЛЗП-сигналу.
    ЛЗП(t) = сигнал = «временной ряд» потенциала системы.
    """

    @staticmethod
    def fourier_etd(lci_signal: List[float], dt: float = 1.0) -> List[complex]:
        """
        ПРЕОБРАЗОВАНИЕ ФУРЬЕ (МВС-анализ):
        F̂(ω) = ∫ ЛЗП(t) · e^{−iωt} dt.

        Разложение ЛЗП по гармоническим составляющим.
        Каждая частота ω = «ритм» включения МВС.

        Ключевая частота: ω* = 1/(π/4) = 4/π ≈ 1.27 Гц.
        = естественная частота π/4-синхронизации.
        """
        N = len(lci_signal)
        spectrum = []
        for k in range(N):
            s = sum(lci_signal[n] * cmath.exp(-2j * math.pi * k * n / N)
                    for n in range(N))
            spectrum.append(s / N)
        return spectrum

    @staticmethod
    def laplace_etd(lci_signal: List[float], s: complex,
                     dt: float = 0.01) -> complex:
        """
        ПРЕОБРАЗОВАНИЕ ЛАПЛАСА (БВС-анализ):
        L{ЛЗП}(s) = ∫₀^∞ ЛЗП(t) · e^{−st} dt.

        Переводит динамику БВС (дифф. уравнения движения тела)
        в алгебрические выражения.

        Передаточная функция: H(s) = ЛЗП_выход(s) / ЛЗП_вход(s).
        При s = iω: H(iω) = Фурье-образ (связь с Фурье).
        """
        total = 0.0 + 0.0j
        for n, lci in enumerate(lci_signal):
            t = n * dt
            total += lci * cmath.exp(-s * t) * dt
        return total

    @staticmethod
    def hartley_etd(lci_signal: List[float]) -> List[float]:
        """
        ПРЕОБРАЗОВАНИЕ ХАРТЛИ (СВС-анализ):
        H(ω) = ∫ ЛЗП(t) · [cos(ωt) + sin(ωt)] dt.

        Вещественный аналог Фурье — работает только с вещественными числами.
        СВС-анализ: «предплечье» видит сигнал через вещественный спектр.
        ħ_ЕТД = π/4 → характеристическая «хартлиевская» частота.
        """
        N = len(lci_signal)
        result = []
        for k in range(N):
            h = sum(lci_signal[n] * (math.cos(2*math.pi*k*n/N) +
                                      math.sin(2*math.pi*k*n/N))
                    for n in range(N))
            result.append(h / N)
        return result

    @staticmethod
    def wavelet_etd(lci_signal: List[float],
                     scale: float, shift: float) -> float:
        """
        ВЕЙВЛЕТ-ПРЕОБРАЗОВАНИЕ (ЧВС-анализ):
        W(a, b) = (1/√a) ∫ ЛЗП(t) · ψ*((t−b)/a) dt.

        Анализирует «локальный» ЛЗП вблизи момента b с масштабом a.
        ЧВС: переключение ЧВС = локальное событие (имеет место и масштаб).

        Материнский вейвлет: гауссиан (ψ = e^{−t²/2}).
        Масштаб a = 1/ω = 1/(4/π) = π/4 = ħ_ЕТД!
        """
        n = len(lci_signal)
        result = 0.0
        inv_sqrt_scale = 1.0 / math.sqrt(abs(scale))
        for i in range(n):
            t = (i - shift) / scale
            # Гауссиан = материнский вейвлет
            psi = math.exp(-t**2 / 2)
            result += lci_signal[i] * psi * inv_sqrt_scale
        return result / n
```

### 1.2 Спектральная теорема ЕТД

```python
def spectral_lci_theorem(lci_signal: List[float]) -> dict:
    """
    Теорема Парсеваля: ∫|ЛЗП(t)|² dt = ∫|F̂(ω)|² dω.
    «Энергия» ЛЗП сохраняется при преобразовании Фурье.

    ЕТД-смысл: Полный ЛЗП одинаков в любом «базисе» анализа.
    Смена метода анализа не меняет суммарный потенциал.
    """
    # «Энергия» во временно́й области
    energy_time = sum(x**2 for x in lci_signal) / len(lci_signal)

    # «Энергия» в спектральной области (Фурье)
    transforms = IntegralTransformsETD()
    spectrum = transforms.fourier_etd(lci_signal)
    energy_freq = sum(abs(c)**2 for c in spectrum)

    return {
        'теорема': 'Парсеваль',
        'энергия_время': energy_time,
        'энергия_частота': energy_freq,
        'сохраняется': abs(energy_time - energy_freq) < 0.01,
        'смысл_ЕТД': 'Суммарный ЛЗП не зависит от способа анализа (МВС/СВС/БВС/ЧВС)',
    }

# Тест: ЛЗП-сигнал с частотой π/4
t_grid = [i * 0.01 for i in range(100)]
lci_sig = [math.cos(4/math.pi * t * 2 * math.pi) for t in t_grid]   # ω* = 4/π
result = spectral_lci_theorem(lci_sig)
print(f"Теорема Парсеваля: {result['сохраняется']}")
```

## ЧАСТЬ II: СРАВНЕНИЕ 4 ПРЕОБРАЗОВАНИЙ

| Преобразование | Область | Сфера | Что раскрывает |
|---------------|---------|-------|----------------|
| **Фурье** | Частотная | МВС | Ритм и частота ударов |
| **Лаплас** | Комплексная s | БВС | Динамика тела (устойчивость) |
| **Хартли** | Вещественная | СВС | Вещественный спектр предплечья |
| **Вейвлет** | Время-частота | ЧВС | Локальные ЧВС-переключения |

## ЗАКЛЮЧЕНИЕ

**4 интегральных преобразования** → **4 способа «видеть» ЛЗП**:

1. **Фурье** (МВС) → Ритм и частота: ω* = 4/π ≈ 1.27 Гц — естественная частота π/4
2. **Лаплас** (БВС) → Динамика тела: передаточная функция H(s) = ЛЗП_выход/ЛЗП_вход
3. **Хартли** (СВС) → Вещественный спектр: только реальные компоненты предплечья
4. **Вейвлет** (ЧВС) → Локальный анализ: масштаб ЧВС-переключения = π/4 = ħ_ЕТД

> Теорема Парсеваля: полный ЛЗП сохраняется при любом преобразовании. Суммарный потенциал не зависит от того, смотрим ли мы через МВС (Фурье), БВС (Лаплас), СВС (Хартли) или ЧВС (Вейвлет).
