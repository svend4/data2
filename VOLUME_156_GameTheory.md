## ВВЕДЕНИЕ

Теория игр — математика стратегических взаимодействий. 4 ключевых типа стратегий:

1. **Доминирующая стратегия** — лучшая вне зависимости от противника
2. **Равновесие Нэша** — ни один не может улучшить результат в одностороннем порядке
3. **Минимакс-стратегия** — минимизировать максимальные потери (Нейман)
4. **Кооперативная** — коалиции и кооперация для суммарного выигрыша

**Тезис тома**: Спарринг ЕТД — это игра двух игроков. 4 типа стратегий = 4 режима ЧВС-взаимодействия с противником.

## ЧАСТЬ I: 4 СТРАТЕГИИ → 4 ЧВС-РЕЖИМА ВЗАИМОДЕЙСТВИЯ

```python
import math
from typing import Dict, List, Tuple

class GameTheoryETD:
    """
    Теория игр применительно к спаррингу ЕТД.
    Игроки: Мастер (M) и Противник (P).
    Стратегии: ЧВС-состояния + техники.
    Выигрыш: ΔЛЗП (изменение потенциала).
    """

    # Матрица выигрышей (упрощённая 4×4)
    # Строки = стратегии Мастера: МВС-удар, СВС-захват, БВС-выход, ЧВС-переключение
    # Столбцы = стратегии Противника: Атака, Защита, Контратака, Уход
    PAYOFF_MATRIX = [
        # Атака  Защита  Контр.  Уход
        [  2.0,  -1.0,   1.5,   3.0],   # МВС-удар
        [  1.0,   2.5,  -0.5,   1.0],   # СВС-захват
        [ -0.5,   1.0,   2.0,  -1.0],   # БВС-выход
        [  1.5,   1.5,   1.5,   1.5],   # ЧВС-переключение
    ]

    MASTER_STRATEGIES = ['МВС-удар', 'СВС-захват', 'БВС-выход', 'ЧВС-переключение']
    OPP_STRATEGIES = ['Атака', 'Защита', 'Контратака', 'Уход']

    # 1. ДОМИНИРУЮЩАЯ СТРАТЕГИЯ
    def dominant_strategy(self) -> dict:
        """
        Доминирующая стратегия:
        Стратегия A доминирует B, если A лучше при ЛЮБЫХ действиях противника.

        ЕТД-анализ: Есть ли стратегия, лучшая при любом противнике?
        """
        n_master = len(self.PAYOFF_MATRIX)
        n_opp = len(self.PAYOFF_MATRIX[0])

        for i, strat_i in enumerate(self.MASTER_STRATEGIES):
            dominates_all = True
            for j, strat_j in enumerate(self.MASTER_STRATEGIES):
                if i == j:
                    continue
                # Проверить: strat_i > strat_j при всех действиях противника?
                for k in range(n_opp):
                    if self.PAYOFF_MATRIX[i][k] <= self.PAYOFF_MATRIX[j][k]:
                        dominates_all = False
                        break
                if not dominates_all:
                    break
            if dominates_all:
                return {'доминирующая': strat_i, 'найдена': True}

        # Обычно нет строго доминирующей → переходим к Нэшу
        return {'доминирующая': None, 'найдена': False,
                'вывод': 'Нет строго доминирующей → нужно равновесие Нэша'}

    # 2. РАВНОВЕСИЕ НЭША
    def nash_equilibrium(self) -> dict:
        """
        Равновесие Нэша: пара стратегий (i*, j*) такая, что
        — Мастер не хочет менять i* при фиксированном j*
        — Противник не хочет менять j* при фиксированном i*

        Нахождение: «седловая точка» матрицы.
        """
        matrix = self.PAYOFF_MATRIX
        n_i = len(matrix)
        n_j = len(matrix[0])

        # Для каждой строки: максимум (лучший ответ мастера)
        # Для каждого столбца: минимум (лучший ответ противника)
        nash_points = []
        for i in range(n_i):
            for j in range(n_j):
                # Мастер не может улучшить: matrix[i][j] = max по строке i
                row_max = matrix[i][j] == max(matrix[i])
                # Противник не может улучшить: matrix[i][j] = min по столбцу j
                col_min = matrix[i][j] == min(matrix[r][j] for r in range(n_i))
                if row_max and col_min:
                    nash_points.append((i, j, matrix[i][j]))

        if nash_points:
            i*, j*, val = nash_points[0]
            return {
                'равновесие': (self.MASTER_STRATEGIES[i*],
                               self.OPP_STRATEGIES[j*]),
                'выигрыш': val,
                'вывод': f'Мастер: {self.MASTER_STRATEGIES[i*]}, ЛЗП = {val}'
            }
        return {'равновесие': None, 'вывод': 'Нет чистого равновесия → смешанное'}

    # 3. МИНИМАКС-СТРАТЕГИЯ (Нейман)
    def minimax_strategy(self) -> dict:
        """
        Минимакс (Нейман, 1928):
        Мастер выбирает стратегию, максимизирующую минимальный выигрыш.
        min_j max_i payoff[i][j] = max_i min_j payoff[i][j].

        Теорема Неймана: в игре с нулевой суммой min-max = max-min!
        """
        matrix = self.PAYOFF_MATRIX
        # Для каждой стратегии мастера: худший исход (min по j)
        min_payoffs = [min(row) for row in matrix]
        # Мастер выбирает стратегию с максимальным min:
        best_i = max(range(len(min_payoffs)), key=lambda i: min_payoffs[i])
        maximin_val = min_payoffs[best_i]

        # Для каждой стратегии противника: лучший исход (max по i)
        max_payoffs = [max(matrix[i][j] for i in range(len(matrix)))
                       for j in range(len(matrix[0]))]
        best_j = min(range(len(max_payoffs)), key=lambda j: max_payoffs[j])
        minimax_val = max_payoffs[best_j]

        return {
            'стратегия_мастера': self.MASTER_STRATEGIES[best_i],
            'maximin_ЛЗП': maximin_val,
            'стратегия_противника': self.OPP_STRATEGIES[best_j],
            'minimax_ЛЗП': minimax_val,
            'теорема_Неймана': abs(maximin_val - minimax_val) < 0.01,
        }

    # 4. КООПЕРАТИВНАЯ ИГРА
    def cooperative_etd(self) -> dict:
        """
        Кооперативная стратегия ЕТД:
        Не «победить» противника, а «обучить» (кооперация в тренировке).

        Ядро: разделение выигрыша между сферами.
        Значение Шепли: φᵢ = среднее предельного вклада сферы i.
        """
        # Значение Шепли для 4 сфер с одинаковыми вкладами:
        n = 4   # сфер
        h = math.pi / 4
        shapley_value = h   # при симметрии: φᵢ = ЛЗП/n

        return {
            'стратегия': 'Кооперативная',
            'значение_Шепли_каждой_сферы': shapley_value,
            'суммарный_ЛЗП': 4 * shapley_value,   # = π
            'вывод': 'Справедливое распределение: каждая сфера вносит π/4',
            'в_спарринге': 'Обе стороны «выигрывают» опыт (не нулевая сумма!)',
        }

gt = GameTheoryETD()

dom = gt.dominant_strategy()
print(f"Доминирующая: {dom['вывод']}")

nash = gt.nash_equilibrium()
print(f"Нэш: {nash['вывод']}")

minimax = gt.minimax_strategy()
print(f"Минимакс: мастер применяет {minimax['стратегия_мастера']}")
```

## ЗАКЛЮЧЕНИЕ

**4 типа игровых стратегий** → **4 ЧВС-режима взаимодействия**:

1. **Доминирующая** → ЧВС-переключение: наивысший стабильный выигрыш (1.5 при любом противнике)
2. **Равновесие Нэша** → Ситуационная пара: мастер не выигрывает от смены, противник тоже
3. **Минимакс** → Принцип Неймана: минимизировать потери = выбирать «безопасную» ЧВС
4. **Кооперативная** → Значение Шепли = π/4 на каждую сферу; суммарный ЛЗП = π

> Значение Шепли для каждой сферы = π/4. Суммарный выигрыш кооперации = **π**. Спарринг — не нулевая игра: оба участника выигрывают опыт.
