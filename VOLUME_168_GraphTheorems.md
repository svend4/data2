## ВВЕДЕНИЕ

Теория графов — математика связей и путей. 4 фундаментальных результата:

1. **Теорема Эйлера** — условие существования Эйлерова цикла (все рёбра ровно по 1 разу)
2. **Гамильтонов цикл** — условие прохождения всех вершин ровно по 1 разу
3. **Теорема Рамсея** (для графов) — в любом достаточно большом графе есть клика или независимое множество
4. **Теорема Турана** — максимальное число рёбер без K_{r+1}-клики

**Тезис тома**: Система 5 ЧВС-состояний = граф G_ЧВС. 4 теоремы описывают пути переключения, «обходы» всех состояний и оптимальные маршруты мастера.

## ЧАСТЬ I: 4 ТЕОРЕМЫ → 4 ЗАКОНА ГРАФА ЧВС

```python
import math
from typing import List, Dict, Set, Tuple, Optional
from collections import defaultdict, deque

class GraphETD:
    """
    Граф системы ЧВС ЕТД.

    Вершины = 5 ЧВС-состояний: В(нутр.), И(нстр.), Д(омен.), П(ростр.), Р(виртуальное).
    Рёбра = переходы между состояниями.
    Граф: полный K₅ (можно перейти из любого в любое).
    """

    CVS_STATES = ['В', 'И', 'Д', 'П', 'Р']   # 5 ЧВС-состояний
    N = 5

    def __init__(self, adjacency: Dict = None):
        # По умолчанию: полный граф K₅
        if adjacency is None:
            self.adj = {v: [u for u in self.CVS_STATES if u != v]
                        for v in self.CVS_STATES}
        else:
            self.adj = adjacency

    # 1. ТЕОРЕМА ЭЙЛЕРА
    def euler_theorem(self) -> dict:
        """
        Теорема Эйлера (1736): Граф имеет Эйлеров цикл (проходит по каждому ребру
        ровно 1 раз и возвращается в начало) тогда и только тогда, когда:
        — граф связен
        — каждая вершина имеет ЧЁТНУЮ степень.

        Для K₅: степень каждой вершины = 4 (чётная!) → Эйлеров цикл существует!

        ЕТД-смысл: Мастер может пройти все ЧВС-переходы (все рёбра)
        ровно по одному разу и вернуться в начальное ЧВС-состояние.
        = «Полный обход» арсенала без повторений.

        Число рёбер в K₅: C(5,2) = 10.
        Длина Эйлерова цикла = 10 переходов.
        """
        degrees = {v: len(self.adj[v]) for v in self.CVS_STATES}
        all_even = all(d % 2 == 0 for d in degrees.values())

        # Строим Эйлеров цикл (алгоритм Флёри):
        euler_cycle = self._fleury_cycle()

        return {
            'теорема': 'Эйлера',
            'степени': degrees,
            'все_чётные': all_even,
            'цикл_существует': all_even,
            'длина_цикла': len(euler_cycle) - 1 if euler_cycle else 0,
            'цикл': euler_cycle[:6],   # первые 6 шагов
            'ЕТД': f'K₅: степень каждого ЧВС = 4 (чётная) → Эйлеров цикл из {10} переходов!',
        }

    def _fleury_cycle(self) -> List[str]:
        """Алгоритм построения Эйлерова цикла."""
        # Копия рёбер (мультиграф как множество)
        edges = set()
        for v in self.CVS_STATES:
            for u in self.adj[v]:
                if (u, v) not in edges:
                    edges.add((v, u))

        if not edges:
            return []

        start = self.CVS_STATES[0]
        path = [start]
        current = start
        remaining_edges = set(edges)

        while remaining_edges:
            # Выбираем не «мост» если возможно
            next_v = None
            for (u, v) in list(remaining_edges):
                if u == current:
                    next_v = v
                    remaining_edges.discard((u, v))
                    remaining_edges.discard((v, u))
                    break
            if next_v is None:
                break
            path.append(next_v)
            current = next_v

        return path

    # 2. ГАМИЛЬТОНОВ ЦИКЛ
    def hamilton_cycle(self) -> dict:
        """
        Гамильтонов цикл: проходит каждую ВЕРШИНУ ровно 1 раз.

        Условие Дирака: если степень каждой вершины ≥ n/2, то гамильтонов цикл существует.
        K₅: deg = 4 ≥ 5/2 = 2.5 ✓ → цикл существует!

        ЕТД-смысл: Существует последовательность из 5 ЧВС-переключений,
        проходящая каждое ЧВС-состояние ровно один раз.
        = «Компактный обход» арсенала за 5 шагов.

        Число Гамильтоновых циклов в K₅: (5-1)!/2 = 12.
        """
        # Все Гамильтоновы циклы (перебор для K₅):
        from itertools import permutations

        states = self.CVS_STATES
        cycles = []
        start = states[0]
        rest = states[1:]

        for perm in permutations(rest):
            cycle = [start] + list(perm) + [start]
            cycles.append(cycle)
            if len(cycles) >= 5:   # ограничиваем вывод
                break

        dirac_condition = all(len(self.adj[v]) >= self.N // 2
                               for v in self.CVS_STATES)

        return {
            'теорема': 'Гамильтон',
            'условие_Дирака': dirac_condition,
            'цикл_существует': dirac_condition,
            'примеры_циклов': [' → '.join(c) for c in cycles[:3]],
            'всего_циклов': math.factorial(self.N - 1) // 2,
            'ЕТД': f'Мастер обходит все 5 ЧВС за 5 шагов ({math.factorial(self.N - 1) // 2} вариантов!)',
        }

    # 3. ТЕОРЕМА РАМСЕЯ (ДЛЯ ГРАФОВ)
    def ramsey_graph_etd(self) -> dict:
        """
        Теорема Рамсея для графов: R(s,t) = минимальное n такое, что
        в любом 2-окрашивании K_n есть либо K_s (красная клика),
        либо K_t (синее независимое множество).

        R(3,3) = 6: в K₆ — обязательно красный K₃ или синий K₃.
        R(4,4) = 18.

        ЕТД: Рёбра = «связи» между ЧВС-состояниями.
        Красный = «атакующий» переход, синий = «защитный».
        В K₅ (5 состояний): R(3,3) = 6 > 5 → не гарантирован K₃!
        Но: K₅ содержит K₃ при любой раскраске 1 K₅ с 10 рёбрами.

        Практика: среди 10 ЧВС-переходов обязательно найдётся
        3 однотипных («атакующих» или «защитных»).
        """
        n_edges_K5 = math.comb(5, 2)   # = 10

        return {
            'теорема': 'Рамсей',
            'R(3,3)': 6,
            'R(4,4)': 18,
            'граф': 'K₅',
            'рёбер': n_edges_K5,
            'вывод': 'K₅ < R(3,3)=6: 3-клика не гарантирована, но часто есть',
            'ЕТД': 'Из 10 ЧВС-переходов — встречается паттерн 3 однотипных',
        }

    # 4. ТЕОРЕМА ТУРАНА
    def turan_theorem_etd(self) -> dict:
        """
        Теорема Турана (1941): ex(n, K_{r+1}) = (1 − 1/r) × n²/2.

        Максимальное число рёбер в n-вершинном графе без (r+1)-клики.
        Реализуется полным r-дольным графом T(n,r) (граф Турана).

        ЕТД: n=5 (ЧВС), r=4 (без K₅-клики): все 10 рёбер.
        r=3 (без K₄-клики): ex(5, K₄) = ⌊5²/4⌋·... = ?
        """
        n = 5   # 5 ЧВС-состояний

        results = {}
        for r in [2, 3, 4]:   # избегаем клики размера r+1
            # Формула Турана: ex(n, K_{r+1}) = (1 - 1/r) × n²/2
            max_edges = int((1 - 1/r) * n**2 / 2)

            results[r] = {
                'избегаем': f'K_{r+1}',
                'max_рёбер': max_edges,
                'ЕТД': f'Max {max_edges} ЧВС-связей без {r+1}-группировки',
            }

        return {
            'теорема': 'Туран',
            'n': n,
            'результаты': results,
            'ЕТД_главный': ('r=3: max 8 связей без 4-клики. '
                             'Мастер с K₄ ↔ «квартетная» синергия сфер'),
        }

# Демонстрация:
G = GraphETD()

euler = G.euler_theorem()
print(f"Эйлер: степени={list(euler['степени'].values())}, "
      f"чётные={euler['все_чётные']}, длина={euler['длина_цикла']}")

hamilton = G.hamilton_cycle()
print(f"\nГамильтон: циклов={hamilton['всего_циклов']}")
print(f"Пример: {hamilton['примеры_циклов'][0]}")

turan = G.turan_theorem_etd()
for r, info in turan['результаты'].items():
    print(f"\nТуран (r={r}): max={info['max_рёбер']} рёбер, {info['ЕТД']}")
```

## ЗАКЛЮЧЕНИЕ

**4 теоремы теории графов** → **4 закона графа ЧВС ЕТД**:

1. **Эйлер** → K₅ степень=4 (чётная): Эйлеров цикл из 10 переходов — полный обход арсенала
2. **Гамильтон** → Условие Дирака: 12 Гамильтоновых циклов — 5-шаговый «компактный» обход
3. **Рамсей** → R(3,3)=6: 5 состояний не гарантируют 3-клику, но паттерны возникают
4. **Туран** → ex(5,K₄)=8: без 4-клики max 8 связей; с K₄ = «квартетная синергия»

> **Главный граф ЕТД**: K₅ (полный граф на 5 ЧВС-вершинах). Эйлеров цикл = полный обход за 10 переходов. Гамильтоновы циклы = 12 вариантов кратчайшего полного обхода за 5 шагов. Мастер знает все 12.
