## ВВЕДЕНИЕ

Теория сложности изучает ресурсы (время, память) для решения задач. 4 ключевых класса:

1. **P** — задачи, решаемые полиномиально (практически эффективно)
2. **NP** — решения проверяемы полиномиально (но нахождение может быть трудным)
3. **PSPACE** — решаемые с полиномиальной памятью (но, возможно, экспоненциальным временем)
4. **EXPTIME** — решаемые за экспоненциальное время

**Тезис тома**: Задачи ЕТД имеют разную сложность. Распознать «правильную» технику (верификация) — в P. Найти оптимальную стратегию (оптимизация) — в NP. Стратегическое планирование — PSPACE. Полный анализ — EXPTIME.

## ЧАСТЬ I: 4 КЛАССА → 4 УРОВНЯ ЗАДАЧ ЕТД

```python
import math
from typing import List, Tuple, Optional
import time

class ComplexityETD:
    """
    Вычислительная сложность задач системы 4 сфер ЕТД.

    P ⊆ NP ⊆ PSPACE ⊆ EXPTIME (иерархия включений).
    P ≠ EXPTIME (доказано). P = NP? — открытый вопрос ($1M Clay).
    """

    # 1. КЛАСС P: ЭФФЕКТИВНЫЕ ЗАДАЧИ ЕТД
    @staticmethod
    def class_P_etd() -> dict:
        """
        P = задачи, решаемые за O(nᵏ) шагов.

        ЕТД-задачи класса P:
        — Вычислить ЛЗП данного состояния: O(4) = O(1) — тривиально!
        — Проверить, является ли переход «π/4-оптимальным»: O(4)
        — Найти ближайшую «π/4-точку»: O(4) (по 4 сферам)
        — Сортировать техники по ЛЗП: O(n log n)
        — Найти кратчайший путь (Дейкстра) в K₅: O(5² log 5) ≈ O(1)

        ЕТД-вывод: Базовые операции с 4 сферами эффективны.
        «Мастер думает в P»: ситуационный анализ = полиноминальный.
        """
        n = 4   # размер входа (4 сферы)

        tasks_P = [
            {'задача': 'Вычислить ЛЗП', 'сложность': 'O(4) = O(1)', 'пример': True},
            {'задача': 'Проверить π/4-баланс', 'сложность': 'O(4)', 'пример': True},
            {'задача': 'Сортировать техники', 'сложность': 'O(n log n)', 'пример': True},
            {'задача': 'Кратчайший путь K₅', 'сложность': 'O(25)', 'пример': True},
        ]

        # Демонстрация: O(4) вычисление ЛЗП
        start = time.monotonic()
        state = [math.pi/4] * 4
        lci = math.sqrt(sum(x**2 for x in state))
        elapsed = time.monotonic() - start

        return {
            'класс': 'P',
            'определение': 'Решаемо за O(nᵏ)',
            'задачи': tasks_P,
            'ЛЗП_вычисление': lci,
            'время_нс': elapsed * 1e9,
            'ЕТД': 'Мастер "думает в P": ситуационный анализ мгновенен',
        }

    # 2. КЛАСС NP: ВЕРИФИЦИРУЕМЫЕ ЗАДАЧИ ЕТД
    @staticmethod
    def class_NP_etd(n_techniques: int = 16) -> dict:
        """
        NP = решение можно ПРОВЕРИТЬ за O(nᵏ), но найти — трудно.

        ЕТД-задачи класса NP:
        — Найти оптимальный «квартет» техник (из 16 по 4): C(16,4) = 1820 вариантов
        — Задача о рюкзаке: набрать ЛЗП = π, используя минимум техник
        — Оптимальное расписание тренировок 4 сфер (задача планирования)

        NP-трудность: Задача 3-SAT → задача о рюкзаке → оптим. техники.

        Но: «Угадать» оптимальный квартет — трудно.
        «Проверить», оптимален ли данный квартет — легко (O(4) вычисление ЛЗП).

        P = NP? Если да → мастер может быстро найти идеальную технику.
        """
        from itertools import combinations

        pi4 = math.pi / 4

        # Задача: найти 4 техники из 16, дающих ЛЗП ≈ π
        techniques = [pi4 * (1 + 0.1 * i) for i in range(n_techniques)]
        target_lci = math.pi

        # Проверка (O(4)):
        def verify_quartet(quartet: Tuple) -> bool:
            lci = math.sqrt(sum(t**2 for t in quartet))
            return abs(lci - target_lci) < 0.1

        # Поиск (экспоненциальный по большому N):
        found = None
        search_count = 0
        for combo in combinations(techniques, 4):
            search_count += 1
            if verify_quartet(combo):
                found = combo
                break

        return {
            'класс': 'NP',
            'определение': 'Верификация за O(nᵏ), поиск — возможно экспонента',
            'задача': f'Найти 4 техники из {n_techniques} с ЛЗП = π',
            'вариантов': math.comb(n_techniques, 4),
            'поисков_до_ответа': search_count,
            'найдено': found is not None,
            'ЛЗП_найденного': math.sqrt(sum(t**2 for t in found)) if found else None,
            'ЕТД': 'Оптимизация стратегии = NP-задача; верификация = P',
        }

    # 3. КЛАСС PSPACE: СТРАТЕГИЧЕСКИЕ ЗАДАЧИ ЕТД
    @staticmethod
    def class_PSPACE_etd(depth: int = 4) -> dict:
        """
        PSPACE = задачи, решаемые с полиномиальной памятью.
        Игры с полной информацией (шахматы, го) — PSPACE-complete.

        ЕТД-задача PSPACE: «Игра двух мастеров»
        — Первый мастер выбирает ЧВС-состояние (5 вариантов)
        — Второй отвечает (5 вариантов)
        — Глубина: d уровней

        Дерево игры: 5^(2d) узлов. Память: O(d) = линейна.
        d=4: 5⁸ = 390625 узлов, память O(4).

        PSPACE > P (предположительно): стратегическое планирование
        сложнее реактивного анализа.
        """
        n_cvs = 5   # 5 ЧВС-состояний
        n_nodes = n_cvs ** (2 * depth)
        memory_needed = depth   # O(глубина) = линейная

        # Минимакс оценка (упрощённо):
        def minimax(d: int, maximizing: bool, lci: float) -> float:
            if d == 0:
                return lci
            pi4 = math.pi / 4
            children = [lci + pi4 * (i - 2) * 0.1 for i in range(5)]

            if maximizing:
                return max(minimax(d - 1, False, c) for c in children)
            else:
                return min(minimax(d - 1, True, c) for c in children)

        start = time.monotonic()
        optimal_lci = minimax(min(depth, 3), True, math.pi / 4)
        elapsed = time.monotonic() - start

        return {
            'класс': 'PSPACE',
            'определение': 'Полиномиальная ПАМЯТЬ, возможно экспон. время',
            'n_ЧВС': n_cvs,
            'глубина': depth,
            'узлов': n_nodes,
            'память': memory_needed,
            'оптимальный_ЛЗП': optimal_lci,
            'ЕТД': 'Стратегическое планирование 4-х уровней = PSPACE',
        }

    # 4. КЛАСС EXPTIME: ПОЛНЫЙ АНАЛИЗ ЕТД
    @staticmethod
    def class_EXPTIME_etd() -> dict:
        """
        EXPTIME = задачи, требующие экспоненциального времени.

        ЕТД-задача EXPTIME: «Полный анализ» всех стратегий мастера.
        — N = 11520 стратегий (Том 163)
        — Полный перебор: O(2^{11520}) — астрономически!
        — Оптимальная стратегия для бесконечного горизонта

        Практически: EXPTIME = «Что знает мастер высшего уровня»
        (всё теоретически возможное, но не вычислимое за разумное время).

        Обходной путь: Эвристики + приближения (NP-аппроксимация).
        """
        n_strategies = 11520   # из Тома 163

        # Мощность пространства задач:
        exptime_states = 2 ** min(n_strategies, 100)   # ограничим для вычисления

        return {
            'класс': 'EXPTIME',
            'определение': 'Требует 2^{O(n)} времени',
            'N_стратегий': n_strategies,
            'пространство_задач': '2^{11520} (астрономически!)',
            'практика': 'Эвристики + Monte Carlo + Deep Learning',
            'ЕТД': 'Полное знание всех стратегий = EXPTIME (удел теоретика)',
            'иерархия': 'P ⊆ NP ⊆ PSPACE ⊆ EXPTIME',
        }

comp = ComplexityETD()

p_result = comp.class_P_etd()
print(f"P: ЛЗП = {p_result['ЛЗП_вычисление']:.4f} за {p_result['время_нс']:.1f} нс")

np_result = comp.class_NP_etd(16)
print(f"NP: вариантов = {np_result['вариантов']}, поисков = {np_result['поисков_до_ответа']}")

psp = comp.class_PSPACE_etd(3)
print(f"PSPACE: узлов = {psp['узлов']}, оптим_ЛЗП = {psp['оптимальный_ЛЗП']:.4f}")

exp = comp.class_EXPTIME_etd()
print(f"EXPTIME: {exp['пространство_задач']}")
print(f"\nИерархия: {exp['иерархия']}")
```

## ЗАКЛЮЧЕНИЕ

**4 класса сложности** → **4 уровня задач ЕТД**:

1. **P** → Вычислить ЛЗП, проверить π/4-баланс: O(4) — мгновенно (рефлекс мастера)
2. **NP** → Найти оптимальный «квартет» из 16 техник: C(16,4)=1820 вариантов (тактическая задача)
3. **PSPACE** → Стратегическое планирование на 4 уровня: 5⁸=390625 узлов, память O(4)
4. **EXPTIME** → Полный анализ 11520 стратегий: 2^{11520} (теоретически полное знание)

> **Вопрос P=NP в ЕТД**: Если P=NP, то «найти оптимальную стратегию» столь же легко, как «проверить» её. Большинство учёных считают P≠NP: мастерство требует ВРЕМЕНИ, нельзя «угадать» оптимум. Мастер ЕТД «работает в NP»: видит решение быстро, но выработать его — долгие тренировки.
