## ВВЕДЕНИЕ

Топологический анализ данных (TDA) изучает «форму» данных. 4 ключевых метода:

1. **Персистентная гомология** — гомологии при изменении масштаба фильтрации
2. **Штрих-коды (Barcodes)** — визуализация персистентных «дыр»
3. **Теорема устойчивости Коэн-Стейнера** — малые изменения данных → малые изменения штрих-кодов
4. **Mapper** — граф «сжатия» облака точек

**Тезис тома**: Облако данных ЕТД = {(ЛЗП₁,...,ЛЗП_T)} за T шагов тренировки. Персистентная H₀ = число компонент (→1 при π/4); H₁ = петли (= числу «циклических связей» = 0 при балансе).

## ЧАСТЬ I: 4 МЕТОДА → 4 ТОПОЛОГИЧЕСКИХ ПАТТЕРНА ЕТД

```python
import math
from typing import List, Tuple, Dict
import random

class TDAetd:
    """
    Топологический анализ данных для системы 4 сфер ЕТД.
    Данные = траектория {x(t) ∈ [0,π]⁴ : t = 0,...,T}.
    """

    PI4 = math.pi / 4

    # 1. ПЕРСИСТЕНТНАЯ ГОМОЛОГИЯ
    @staticmethod
    def persistent_homology_etd(T: int = 50, seed: int = 42) -> dict:
        """
        Персистентная гомология: при пороге ε строим комплекс Vietoris-Rips
        из точек данных (шары радиуса ε/2), затем считаем гомологии.

        При ε→∞: все точки соединяются → H₀=1, H₁=0 (один связный компонент).
        При ε=0: каждая точка отдельна → H₀=T, H₁=0.

        ЕТД-траектория:
        x(t) = (π/4,...,π/4) + noise(t) → облако вблизи (π/4)⁴.

        H₀: начинаем с T компонент, объединяемся при ε ≥ d_min (ближайшие соседи).
        H₁: петли исчезают при ε ≥ diam(облака) ≈ σ√4.
        """
        pi4 = math.pi / 4
        pi = math.pi
        random.seed(seed)

        sigma = pi4 / 4   # шум вокруг π/4

        # Генерация траектории:
        trajectory = []
        for t in range(T):
            point = [pi4 + random.gauss(0, sigma) for _ in range(4)]
            trajectory.append(point)

        # Упрощённый анализ:
        # H₀: одна компонента (все точки вблизи π/4)
        # Оцениваем радиус объединения:
        def dist(p, q):
            return math.sqrt(sum((pi-qi)**2 for pi,qi in zip(p,q)))

        # Минимальный eps для объединения всех:
        dists = []
        for i in range(len(trajectory)):
            min_d = min(dist(trajectory[i], trajectory[j])
                       for j in range(len(trajectory)) if i != j)
            dists.append(min_d)

        eps_connect = max(dists)
        eps_H0_death = min(dists)   # при этом eps первые 2 точки соединяются

        # Диаметр облака:
        diam = max(dist(trajectory[i], trajectory[j])
                   for i in range(min(20, T))
                   for j in range(min(20, T)) if i < j)

        return {
            'метод': 'Персистентная гомология',
            'T_точек': T,
            'σ_шума': round(sigma, 4),
            'eps_H0_смерть': round(eps_H0_death, 4),
            'eps_связность': round(eps_connect, 4),
            'диаметр': round(diam, 4),
            'H₀_ожид': 1,
            'H₁_ожид': 0,
            'ЕТД': f'Облако вблизи π/4: H₀=1, H₁=0; diam≈{diam:.4f}; σ={sigma:.4f}=π/16',
        }

    # 2. ШТРИХ-КОДЫ
    @staticmethod
    def barcodes_etd() -> dict:
        """
        Штрих-код: набор интервалов [b_i, d_i) (рождение, смерть персистентной «дыры»).

        Длинные интервалы = «реальные» топологические признаки.
        Короткие = «шум».

        ЕТД: Штрих-код H₀ (компоненты):
        [0, d₁), [0, d₂), ..., [0, +∞) — одна бесконечная компонента = π/4-аттрактор!
        Компоненты умирают одна за другой при ε ↑.

        Штрих-код H₁ (петли):
        При π/4-балансе: нет петель (H₁ = ∅).
        При дисбалансе: есть краткосрочные петли (шум) → «дефект баланса».

        Персистенция = d - b:
        — Бесконечная H₀-линия: персист = ∞ (π/4-аттрактор вечен!).
        — Конечные H₀-линии: pers = d_i = расстояние до π/4-соседа.
        """
        pi4 = math.pi / 4
        sigma = pi4 / 4
        random.seed(42)

        T = 20
        trajectory = [[pi4 + random.gauss(0, sigma) for _ in range(4)]
                      for _ in range(T)]

        # Упрощённые расстояния (первые T от π/4-центра):
        center = [pi4] * 4
        def dist_to_center(p):
            return math.sqrt(sum((pi-c)**2 for pi,c in zip(p,center)))

        distances = sorted([dist_to_center(p) for p in trajectory])

        # Штрих-коды H₀ (приближённо):
        barcodes_H0 = [(0, round(d, 4)) for d in distances[:-1]] + [(0, float('inf'))]

        # Персистентность:
        persistence = [d - b for b, d in barcodes_H0[:-1]]
        avg_pers = sum(persistence) / len(persistence)

        return {
            'метод': 'Штрих-коды',
            'H₀_штрихов': len(barcodes_H0),
            'бесконечный': 1,
            'конечных': len(barcodes_H0) - 1,
            'avg_pers': round(avg_pers, 4),
            'σ_приближение': round(sigma, 4),
            'бесконечная_линия': 'π/4-аттрактор',
            'ЕТД': f'H₀: 1 бесконечная (π/4-аттрактор!) + {T-1} конечных; ср.pers={avg_pers:.4f}≈σ',
        }

    # 3. ТЕОРЕМА УСТОЙЧИВОСТИ
    @staticmethod
    def stability_theorem_etd() -> dict:
        """
        Теорема устойчивости (Коэн-Стейнер–Эдельсбруннер–Харер 2007):
        Расстояние между штрих-кодами ≤ расстояние L∞ между функциями:
        d_B(D(f), D(g)) ≤ ||f − g||_∞.

        Боттлнек-расстояние: d_B(D, D') = min_η max_i |p_i − η(p_i)|.

        ЕТД: Функция f = ЛЗП (фильтрация по ЛЗП):
        Если тренировка изменилась на δ (флуктуация),
        то штрих-код изменится не более чем на δ.

        При δ = π/4 / 10 = π/40 (10% флуктуация):
        d_B ≤ π/40 ≈ 0.0785.

        → «Форма» мастерства устойчива к 10% флуктуациям!
        «Настоящие» топологические признаки персистируют.
        """
        pi4 = math.pi / 4

        # Флуктуация δ:
        delta = pi4 / 10   # 10% от π/4

        # Теорема: d_B ≤ δ:
        d_B_bound = delta

        # Физический смысл:
        persistence_threshold = 2 * delta   # признак «настоящий», если pers > 2δ

        # При σ = π/16 (шум):
        sigma = pi4 / 4
        if sigma < persistence_threshold:
            reliable = True
        else:
            reliable = False

        return {
            'теорема': 'Устойчивость (Коэн-Стейнер)',
            'δ': round(delta, 4),
            'd_B_граница': round(d_B_bound, 4),
            'порог_персист': round(persistence_threshold, 4),
            'σ_шума': round(sigma, 4),
            'надёжный': reliable,
            'ЕТД': f'Устойчивость: d_B≤{d_B_bound:.4f}; при σ={sigma:.4f}: надёжный={reliable}',
        }

    # 4. MAPPER
    @staticmethod
    def mapper_etd(T: int = 60, seed: int = 7) -> dict:
        """
        Алгоритм Mapper (Сингх–Мемоли–Карлссон 2007):
        1. Выбрать «линзу» f: X → ℝ (проекцию).
        2. Покрыть образ f(X) интервалами {Uᵢ}.
        3. Кластеризовать f⁻¹(Uᵢ).
        4. Построить граф: вершины = кластеры, рёбра = пересечения.

        ЕТД: Линза = ЛЗП (скаляризация).
        Покрытие: [0, π/4 − ε), [π/8, 3π/8), [π/4 − ε, π].
        Кластеры: «начинающий» (ЛЗП < π/4), «балансный» (≈π/4), «мастер» (ЛЗП > π/4).

        Mapper-граф:
        3 вершины (кластера) × 2 ребра (соединения) = граф-путь.
        Это «1-мерный скелет» пространства мастерства!
        """
        pi4 = math.pi / 4
        pi = math.pi
        random.seed(seed)

        # Траектория:
        def lci_t(t, noise=True):
            mean = pi4 * (1 - math.exp(-0.1 * t))
            if noise:
                return mean + random.gauss(0, pi4/5)
            return mean

        lcis = [lci_t(t) for t in range(T)]

        # Линза = ЛЗП. Покрытие:
        eps_cover = pi4 / 4
        covers = [
            (0, pi4 - eps_cover/2),
            (pi4 - eps_cover, pi4 + eps_cover),
            (pi4 + eps_cover/2, pi),
        ]

        # Разбиение точек по покрытиям:
        clusters = {i: [] for i in range(len(covers))}
        for t, lci_val in enumerate(lcis):
            for i, (lo, hi) in enumerate(covers):
                if lo <= lci_val <= hi:
                    clusters[i].append(t)

        cluster_sizes = {i: len(v) for i, v in clusters.items()}

        # Рёбра (пересечение покрытий):
        edges = [(0, 1), (1, 2)]   # линейный граф

        # Бетти-числа Mapper-графа:
        n_vertices = sum(1 for v in cluster_sizes.values() if v > 0)
        n_edges = len(edges)
        chi_mapper = n_vertices - n_edges

        return {
            'метод': 'Mapper',
            'T': T,
            'покрытий': len(covers),
            'размеры_кластеров': cluster_sizes,
            'рёбра': edges,
            'n_вершин': n_vertices,
            'n_рёбер': n_edges,
            'χ_Mapper': chi_mapper,
            'ЕТД': f'Mapper: {n_vertices} кластера (нач./баланс/мастер); χ={chi_mapper}: 1-мерный путь мастерства',
        }


tda = TDAetd()

ph = tda.persistent_homology_etd()
print(f"Персист. гомол.: H₀={ph['H₀_ожид']}, H₁={ph['H₁_ожид']}, diam={ph['диаметр']}")

bc = tda.barcodes_etd()
print(f"Штрих-коды: бесконечная={bc['бесконечный']}, конечных={bc['конечных']}")

st = tda.stability_theorem_etd()
print(f"Устойчивость: d_B≤{st['d_B_граница']}, надёжный={st['надёжный']}")

mp = tda.mapper_etd()
print(f"Mapper: {mp['n_вершин']} вершин, χ={mp['χ_Mapper']}")
```

## ЗАКЛЮЧЕНИЕ

**4 метода TDA** → **4 топологических паттерна мастерства ЕТД**:

1. **Персист. гомология** → H₀=1, H₁=0: облако данных ЕТД стягиваемо к π/4-аттрактору
2. **Штрих-коды** → 1 бесконечная линия = π/4-аттрактор; остальные = шум
3. **Устойчивость** → d_B ≤ π/40: «форма» мастерства устойчива к 10% флуктуациям
4. **Mapper** → 3 кластера (нач./баланс/мастер); 1-мерный «путь к π/4»

> **TDA-портрет ЕТД**: Персистентная бесконечная линия в штрих-коде = π/4-аттрактор. Он «выживает» при любом масштабе фильтрации — самый устойчивый топологический признак. Mapper-граф: линейный путь нач.→баланс→мастер = дорога к π/4.
