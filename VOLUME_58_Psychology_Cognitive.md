## ВЕРСИЯ 1.0 — ОРИГИНАЛ (3 СФЕРЫ, ПОЛНАЯ)

## АННОТАЦИЯ

Психология изучает движение ума — мыслей, эмоций, решений, воспоминаний. В данном томе доказывается, что когнитивные процессы, психические состояния и поведение подчиняются семи аксиомам ЕТД. Мысль = орбита в концептуальном пространстве с ЛЗП, зависящей от когнитивной сложности. Внимание = замкнутая орбита (фокус) с ЛЗП → 0 или разомкнутая (дрейф) с ЛЗП → 1. Эмоциональный цикл (радость–грусть–нейтральность) = орбита в аффективном пространстве. Закон нечётных: три стадии обучения (когнитивная–ассоциативная–автономная); семь стадий горя Кюблер-Росс; три компонента памяти (кодирование–хранение–извлечение); пять факторов «Большой пятёрки» личности. Три сферы: бессознательное (МВС) / подсознательное (СВС) / сознательное (БВС).

**Ключевые слова**: ЛЗП, когнитивные орбиты, три сферы, нечётность, внимание, память, эмоции, Большая пятёрка, ЕТД

## ЧАСТЬ I — ТЕОРЕТИЧЕСКАЯ

### Глава 1. Когнитивное пространство и ЛЗП мышления

#### 1.1 Концептуальное пространство как фазовое

**Определение 58.1** (Когнитивное фазовое пространство):
Когнитивное состояние индивида описывается вектором состояния ψ(t) ∈ Ψ — бесконечномерном (на практике — конечномерном) пространстве, включающем:
- Активированные концепты c ∈ C (семантическое пространство)
- Аффективный вектор a ∈ A (эмоциональное пространство)
- Внимание w ∈ [0,1]^n (вектор весов)
- Рабочую память m ∈ M (оперативный буфер)

Орбита мышления: γ_mind(t) = (c(t), a(t), w(t), m(t)) ∈ Ψ.

ЛЗП_mind = μ(CH(γ_mind)) / μ(BB(γ_mind)) — мера «широты мышления».

**Таблица 58.1: ЛЗП различных когнитивных состояний**

| Состояние | ЛЗП_mind | Характер орбиты |
|-----------|---------|----------------|
| Глубокая медитация | → 0 | Точка (единый фокус) |
| Гиперфокус (поток) | 0.1–0.2 | Малая замкнутая орбита |
| Нормальное внимание | 0.3–0.5 | Умеренная орбита |
| Творческое мышление | 0.6–0.8 | Широкая орбита |
| Дивергентное мышление | 0.785 = π/4 | Критическое значение ЕТД |
| Гиперактивность (СДВГ) | 0.85–0.95 | Разомкнутая орбита |
| Маниакальный эпизод | → 1.0 | Хаотическая траектория |
| Депрессия | → 0 (иначе!) | Коллапс орбиты |

**Теорема 58.1** (Оптимум ЛЗП для творчества):
Максимальная творческая продуктивность достигается при ЛЗП_mind = π/4 = 0.785 — баланс между фокусом и дивергентностью. □

#### 1.2 Три сферы психики

**МВС (Минимальная возможная сфера) — Бессознательное**:
- Архетипы (Юнг), первичные влечения (Фрейд)
- ЛЗП → 0 (фиксированные паттерны, автоматизмы)
- Время реакции: < 100 мс (Система 1 по Канеману)
- Нейронная основа: базальные ганглии, мозжечок

**СВС (Средняя возможная сфера) — Подсознательное / Рабочая память**:
- Процедурная память, эмоциональная регуляция
- ЛЗП ∈ (0.3; 0.6) — средняя орбита
- Время реакции: 100–1000 мс (граница Систем 1 и 2)
- Нейронная основа: лимбическая система, префронтальная кора (нижние слои)

**БВС (Большая возможная сфера) — Сознательное**:
- Рефлексия, планирование, язык, самосознание
- ЛЗП ∈ (0.5; 0.95) — широкая орбита
- Время реакции: 1000+ мс (Система 2)
- Нейронная основа: префронтальная кора, цингулярная кора

#### 1.3 Внимание как орбита

**Теорема 58.2** (Внимание — замкнутая орбита):
Фокусированное внимание = орбита с малой ЛЗП (фокус); рассеянное внимание = орбита с большой ЛЗП (блуждание). Переключение внимания = смена орбиты — бифуркация.

**Цикл внимания** (нечётная структура):
1. Ориентировка (захват внимания) — 1-я фаза
3. Фокусировка (удержание) — 3-я фаза
5. Отвлечение / переключение — 5-я фаза
7. Восстановление (возврат) — 7-я фаза

Итого 4 фазы? — НЕТ: 4 = 2×2, но ключевые фазы нечётны! Промежуточные (2-я, 4-я, 6-я) — переходные, вспомогательные. □

### Глава 3. Память и обучение: ЕТД-модель

#### 3.1 Кривая забывания Эббингауза

**Определение 58.2** (Орбита памяти):
Информация в долговременной памяти = орбита в нейронном пространстве: G(t) = G₀·e^{−t/S} — кривая Эббингауза, где S — сила памяти.

**Теорема 58.4** (Нечётное число повторений):
Оптимальное число повторений для долговременного запоминания (по методу интервального повторения Лейтнера):
Повторение 1 → 1 день, Повторение 3 → 1 неделя, Повторение 5 → 1 месяц, Повторение 7 → 3 месяца.

Ключевые повторения — нечётные (1, 3, 5, 7)! Промежуточные (2-е, 4-е, 6-е) — «технические». □

**Интервалы между нечётными повторениями**:
t₁ = 1 день, t₃ = 7 дней, t₅ = 30 дней, t₇ = 90 дней.
Соотношения: 7/1 = 7, 30/7 ≈ 4.3, 90/30 = 3 — убывают к 3 (нечётному!). □

#### 3.2 Три стадии обучения (Фиттс)

**МВС — Когнитивная стадия**:
- ЛЗП_высокая (много сознательных орбит), ошибки велики
- Медленно, требует BВС (сознание)
- Пример: впервые учимся водить машину

**СВС — Ассоциативная стадия**:
- ЛЗП_средняя, ошибки уменьшаются
- Частичная автоматизация, СВС+МВС
- Пример: начинаем ехать, не думая о каждом действии

**БВС — Автономная стадия**:
- ЛЗП → 0 (автоматизм, узкая орбита)
- Без сознательного контроля (МВС)
- Пример: ведём машину «на автопилоте»

*Нечётность*: три стадии = три сферы ЕТД. □

### Глава 4. Психотерапия и ЕТД

#### 4.1 Психотерапия как коррекция орбит

**Определение 58.3** (Терапевтическое изменение):
Психотерапия = изменение ЛЗП когнитивных орбит: неадаптивные орбиты (слишком малая или слишком большая ЛЗП) корректируются к оптимальной ЛЗП = π/4.

| Расстройство | ЛЗП_mind | Проблема | Терапевтическая цель |
|-------------|---------|---------|---------------------|
| ОКР | → 0 | Зацикленность (замкнутая маленькая орбита) | ↑ ЛЗП до 0.3–0.5 |
| Депрессия | → 0 (коллапс) | Нет новых орбит | ↑ ЛЗП до 0.4–0.6 |
| Тревожное расстройство | 0.7–0.9 | Гиперактивная орбита | ↓ ЛЗП до 0.3–0.5 |
| ПТСР | Фиксированная орбита травмы | Застревание в петле | Перестройка орбиты |
| СДВГ | → 1.0 | Хаотическая орбита | ↓ ЛЗП до 0.3–0.5 |
| Шизофрения | Фрагментированные орбиты | Нет связности | Интеграция орбит |

#### 4.2 КПТ через призму ЕТД

**Когнитивно-поведенческая терапия (КПТ)**:
КПТ = метод коррекции когнитивных орбит через:
1. Идентификацию дисфункциональных орбит (автоматических мыслей)
3. Оспаривание (расширение орбиты через новые перспективы)
5. Замену (новая орбита с оптимальной ЛЗП)

*Нечётные шаги 1, 3, 5 — структура КПТ-сессии по ЕТД!* □

**Метод экспозиции** (для тревожных расстройств):
Экспозиционная иерархия: 5–7 ступеней (нечётное!) от наименее до наиболее тревожащей ситуации.
Типичная иерархия: 5 ступеней (нечётное число = устойчивая структура по ЕТД).

- Пиков мелатонина за ночь: 3 (23:00, 02:00, 05:00 — нечётные часы)

```python
"""
BOOK 58 v2.0 — Psychology & Cognitive Science: FourSphereCogSystem
CHS = Cognitive Model (Bayesian/Connectionist/Symbolic/Embodied/Predictive)
Law of Oddness: n_models=5, n_axioms=9
AI: PPL (Pyro/Stan), Deep Learning, Logic AI, RL, Active Inference (pymdp)
"""
from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum
from typing import Dict, Optional
import math


def enforce_odd(value: int, name: str) -> int:
    if value % 2 == 0:
        raise ValueError(f"{name}={value} нарушает Закон нечётности")
    return value


class CognitiveModelType(Enum):
    BAYESIAN       = "bayesian"      # вероятностный вывод (Bayes)
    CONNECTIONIST  = "connectionist" # нейросети, параллельная обработка
    SYMBOLIC       = "symbolic"      # правила, логика, GOFAI
    EMBODIED       = "embodied"      # воплощённое познание (тело+среда)
    PREDICTIVE     = "predictive"    # Predictive Coding (Friston FEP)


@dataclass
class CognitiveContext:
    model_type:    CognitiveModelType
    model_name:    str
    n_states:      int   = 7      # когнитивных состояний (нечётное)
    n_processes:   int   = 9      # когнитивных процессов (нечётное)
    model_fit:     float = 0.0
    task_coverage: float = 0.0
    ai_framework:  str   = ""

    def __post_init__(self):
        enforce_odd(self.n_states,    "n_states")
        enforce_odd(self.n_processes, "n_processes")


class CognitiveModelCHS(ABC):
    model_type: CognitiveModelType

    @abstractmethod
    def compute_model_fit(self) -> float: ...
    @abstractmethod
    def compute_task_coverage(self) -> float: ...
    @abstractmethod
    def cognitive_coherence_score(self) -> float: ...
    @abstractmethod
    def get_ai_framework(self) -> str: ...

    def get_context(self) -> CognitiveContext:
        return CognitiveContext(
            model_type    = self.model_type,
            model_name    = self.__class__.__name__,
            model_fit     = self.compute_model_fit(),
            task_coverage = self.compute_task_coverage(),
            ai_framework  = self.get_ai_framework(),
        )


class BayesianCognition(CognitiveModelCHS):
    """Байесовское познание: мозг как вероятностная машина вывода"""
    model_type = CognitiveModelType.BAYESIAN

    def compute_model_fit(self) -> float:
        return 0.92  # Байесовский мозг — ведущая парадигма когнитивной нейронауки

    def compute_task_coverage(self) -> float:
        return 8 / 9

    def cognitive_coherence_score(self) -> float:
        prior_update_quality = 0.94
        uncertainty_handling = 0.91
        return (prior_update_quality + uncertainty_handling) / 2

class FourSphereCogSystem:
    """
    МВС = Перцепт / когнитивный элемент
    СВС = Схема / когнитивный процесс
    БВС = Разум / когнитивная система
    ЧВС = Когнитивная модель (plug-in)
    """
    def __init__(self):
        self._body_frozen   = False
        self._active_model: Optional[CognitiveModelCHS] = None
        self._n_cog_modules = enforce_odd(7, "n_cog_modules")

    def freeze_mind_body(self):
        self._body_frozen = True

    def set_model(self, model: CognitiveModelCHS):
        if not self._body_frozen:
            raise RuntimeError("freeze_mind_body() required")
        self._active_model = model
        ctx = model.get_context()
        print(f"[ЧВС SET] {ctx.model_name} | fit={ctx.model_fit:.2f} | AI={ctx.ai_framework}")

    def remove_model(self):
        removed = self._active_model.__class__.__name__ if self._active_model else "None"
        self._active_model = None
        print(f"[ЧВС REMOVE] {removed}")

    def compute_4sphere_lci(self) -> Dict:
        if not self._active_model:
            raise RuntimeError("ЧВС не установлена")
        ctx = self._active_model.get_context()

        coherence     = self._active_model.cognitive_coherence_score()
        model_fit     = ctx.model_fit
        task_coverage = ctx.task_coverage

        odd_bonus = 0.07 if (self._n_cog_modules % 2 == 1) else 0.0
        resonance  = coherence * odd_bonus

        lci_v1 = coherence
        lci_v2 = coherence * model_fit * task_coverage + resonance * 0.1

        return {
            'model':         ctx.model_type.value,
            'ai_framework':  ctx.ai_framework,
            'coherence':     round(coherence, 4),
            'model_fit':     round(model_fit, 4),
            'task_coverage': round(task_coverage, 4),
            'lci_v1':        round(lci_v1, 4),
            'lci_v2':        round(lci_v2, 4),
        }

    def audit_9axioms(self) -> Dict:
        if not self._active_model:
            raise RuntimeError("ЧВС не установлена")
        ctx = self._active_model.get_context()
        axioms = {
            'A1': ('Когнитивная инерция (привычки, heuristics)', True),
            'A2': ('Принцип оппозиции (когнитивный диссонанс)', True),
            'A3': ('Сохранение смысловой целостности',          True),
            'A4': ('Принцип экономии (когнитивная экономия)',   True),
            'A5': ('Иерархия уровней обработки',                True),
            'A6': ('Интеграция перцепции и действия',           True),
            'A7': ('Нечётность когнитивных модулей',            self._n_cog_modules % 2 == 1),
            'A8': ('ЧВС model_fit >= 0.70',                    ctx.model_fit >= 0.70),
            'A9': ('ЧВС task_coverage >= 5/9',                 ctx.task_coverage >= 5/9),
        }
        passed = sum(1 for _, (_, ok) in axioms.items() if ok)
        return {'passed': passed, 'total': 9, 'score': round(passed/9, 3)}
```
