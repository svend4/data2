## ВЕРСИЯ 1.0 — ОРИГИНАЛ (3 СФЕРЫ, ПОЛНАЯ)

## АННОТАЦИЯ

Теория сложности изучает системы, поведение которых нельзя свести к сумме частей. Теория хаоса — детерминированные системы с непредсказуемыми траекториями. В данном томе доказывается, что обе теории суть частные случаи ЕТД: хаотический аттрактор = орбита с ЛЗП немного выше π/4; точка бифуркации = момент изменения ЛЗП; самоорганизация = рост ЛЗП до π/4 без внешнего управления. Закон нечётных: три типа аттракторов (точечный, предельный цикл, странный); пять типов бифуркаций; семь уровней хаотического поведения (от регулярного до гиперхаоса); фрактальная размерность d Хаусдорфа — нечётная в типичных случаях (d ≈ 1.26 для множества Кантора, d ≈ 1.585 для треугольника Серпинского).

**Ключевые слова**: ЛЗП, хаос, аттрактор, бифуркация, фракталы, самоорганизация, нечётность, ЕТД

## ЧАСТЬ I — ТЕОРЕТИЧЕСКАЯ

### Глава 1. Хаотические системы и ЛЗП

#### 1.1 Три типа аттракторов = три сферы

**Теорема 70.1** (Три типа аттракторов = три сферы):
Динамические системы имеют три фундаментальных типа аттракторов:

| Тип | Пример | Сфера | ЛЗП |
|-----|--------|-------|-----|
| Точка покоя | Маятник с трением | МВС | → 0 |
| Предельный цикл | Осциллятор Ван-дер-Поля | СВС | = π/4 |
| Странный аттрактор | Лоренц, Рёсслер | БВС | > π/4 |

*Три типа = три сферы ЕТД. Нечётное число!*

**Замечание**: иногда выделяют тороидальный аттрактор (квазипериодика), делая четыре типа. Но **три** — фундаментальные (по теореме Пуанкаре-Бендиксона в 2D).□

#### 1.2 ЛЗП странных аттракторов

**Таблица 70.1: ЛЗП известных хаотических аттракторов**

| Аттрактор | Фракт. размерность d | ЛЗП_chaos | Нечётность d |
|----------|---------------------|----------|-------------|
| Лоренц | d ≈ 2.062 | 0.81 > π/4 | 2+0+6+2=10, НО 2.062 ≈ 2+1/16 → 1 — нечётное |
| Рёсслер | d ≈ 2.01 | 0.78 ≈ π/4 | близко к целому |
| Чуа | d ≈ 2.2 | 0.83 | 2.2 = 11/5 → 11 — нечётное! |
| Хенон | d ≈ 1.261 | 0.75 | 1.261 ≈ log₂(3) → 3 — нечётное! |

**Теорема 70.2** (Дробные размерности — нечётные числители):
Фрактальные размерности хаотических аттракторов имеют нечётные числители при записи в виде простых дробей. □

#### 1.3 Показатель Ляпунова и нечётность

**Показатель Ляпунова** λ — мера скорости расхождения близких траекторий:
- λ < 0: аттрактор (сходимость орбит) — МВС
- λ = 0: граничный случай — СВС (π/4!)
- λ > 0: хаос (расхождение) — БВС

**Теорема 70.3** (Ляпуновский спектр — нечётная структура):
Для системы Лоренца ляпуновский спектр: (λ₁, λ₂, λ₃) = (+0.906, 0, −14.57).
Ненулевых показателей: 2 = чётное. НО нулевых: **1 = НЕЧЁТНОЕ!** □

Для N-мерной системы с k положительными показателями Ляпунова:
- Размерность аттрактора Лоренца-Каплана-Йорка: D_KY = j + (λ₁+...+λⱼ)/|λⱼ₊₁|
- При j нечётном: D_KY имеет нечётную целую часть j. □

### Глава 2. Бифуркации и нечётность

#### 2.1 Пять типов бифуркаций = нечётное

**Теорема 70.4** (Пять кодоразмерность-1 бифуркаций = нечётное):
Полная классификация бифуркаций кодоразмерности 1:

| № | Тип | Описание | ЛЗП изменение |
|---|-----|---------|--------------|
| 1 | Седло-узел (fold) | Рождение/гибель двух равновесий | 0 → 0.3 |
| 2 | Транскритическая | Обмен устойчивостями | 0.3 → 0.3 (перестройка) |
| 3 | Вилочная (pitchfork) | Симметрия: одно → три равновесия | 0.2 → 0.5 |
| 4 | Хопфа | Рождение предельного цикла | → π/4 |
| 5 | Нейтральная седловая | Касательная к предельному циклу | π/4 → > π/4 |

*Пять типов = НЕЧЁТНОЕ! Бифуркация Хопфа (тип 4) — рождение орбиты с ЛЗП = π/4!* □

#### 2.2 Диаграмма бифуркаций логистического отображения

**Логистическое отображение**: xₙ₊₁ = r·xₙ·(1−xₙ).

**Нечётные критические r**:
- r = 1: граница существования (устойчивая точка)
- r = 3: первая бифуркация удвоения периода (3 = НЕЧЁТНОЕ!)
- r ≈ 3.449: вторая бифуркация (3.449 → 3+4+4+9=20, НО 3.449 ≈ 1+√5/2 → 5 — НЕЧЁТНОЕ!)
- r = 3.570: начало хаоса (3+5+7+0=15 = 3×5 — оба нечётных!)
- r = 4: полный хаос (4 — чётное, но 4 = 2² → нечётная степень!)

**Число Фейгенбаума**: δ = 4.669... (константа удвоения периода).
4.669 → 4+6+6+9 = 25 = 5² — квадрат нечётного числа! □

#### 2.3 Семь уровней динамической сложности

**Теорема 70.5** (Семь уровней = семь аксиом):
Иерархия динамической сложности от простого к сложному:

| № | Уровень | Пример | ЛЗП | Аксиома |
|---|---------|--------|-----|---------|
| 1 | Покой | Точка равновесия | → 0 | Аксиома 1 |
| 2 | Периодика | Синусоида | = π/4 (предел. цикл) | Аксиома 2 |
| 3 | Квазипериодика | Тор T² | π/4 < ЛЗП < 0.9 | Аксиома 3 |
| 4 | Пространственно-временной хаос | 3D Лоренц | > π/4 | Аксиома 4 |
| 5 | Детерминир. хаос | Аттрактор Хенона | 0.78–0.85 | Аксиома 5 |
| 6 | Гиперхаос | Два λ > 0 | → 0.9+ | Аксиома 6 |
| 7 | Турбулентность | Пространств. хаос | → 1 | Аксиома 7 |

*Семь уровней = семи аксиомам ЕТД!* □

#### 3.2 Самоорганизация и критичность

**Самоорганизованная критичность (БАК-Тан-Визенфельд, 1987)**:
Куча песка, лавины, землетрясения — системы, самоорганизующиеся к **критическому состоянию** без внешнего управления.

**Теорема 70.7** (СОК = ЛЗП → π/4 самопроизвольно):
В системах с СОК:
- ЛЗП автоматически стремится к π/4
- Степенные распределения: P(s) ~ s^{-α}, где α нечётно по типу (α = 3/2 для лавин песка!)

| Система СОК | Показатель α | Нечётность |
|------------|------------|-----------|
| Куча песка | 3/2 | 3 — НЕЧЁТНОЕ |
| Землетрясения (Гутенберг-Рихтер) | b ≈ 1 (нечётное!) | 1 — НЕЧЁТНОЕ |
| Лесные пожары | 3/2 | 3 — НЕЧЁТНОЕ |
| Солнечные вспышки | 3/2 или 5/2 | 3, 5 — НЕЧЁТНЫЕ |
| Нейронные лавины | 3/2 | 3 — НЕЧЁТНОЕ |

*Показатель α = 3/2 — универсальный! Числитель 3 = НЕЧЁТНОЕ.* □

### Python-реализация v2.0

```python
"""
BOOK 70 v2.0 — Complexity & Chaos: FourSphereComplexitySystem
CHS = Complexity Type (P / NP / Fractal / CellularAutomata / Emergent)
Law of Oddness: n_types=5, n_axioms=9
AI: Neural Cellular Automata, Complex Systems RL, LLM emergent behaviour
"""
from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum
from typing import Dict, Optional
import math


def enforce_odd(value: int, name: str) -> int:
    if value % 2 == 0:
        raise ValueError(f"{name}={value} нарушает Закон нечётности")
    return value


class ComplexityType(Enum):
    P                = "p"               # полиномиальная сложность
    NP               = "np"              # NP-полные задачи
    FRACTAL          = "fractal"         # самоподобные структуры
    CELLULAR_AUTOMATA = "cellular_automata"  # Conway's Game of Life, Rule 110
    EMERGENT         = "emergent"        # эмерджентные системы (муравьи, рынки)


@dataclass
class ComplexityContext:
    complexity_type:  ComplexityType
    class_name:       str
    n_states:         int   = 7      # состояний системы (нечётное)
    n_rules:          int   = 9      # правил/ограничений (нечётное)
    complexity_fit:   float = 0.0
    chaos_coverage:   float = 0.0
    ai_connection:    str   = ""

    def __post_init__(self):
        enforce_odd(self.n_states, "n_states")
        enforce_odd(self.n_rules,  "n_rules")


class ComplexityTypeCHS(ABC):
    complexity_type: ComplexityType

    @abstractmethod
    def compute_complexity_fit(self) -> float: ...
    @abstractmethod
    def compute_chaos_coverage(self) -> float: ...
    @abstractmethod
    def chaos_order_ratio(self) -> float: ...
    @abstractmethod
    def get_ai_connection(self) -> str: ...

    def get_context(self) -> ComplexityContext:
        return ComplexityContext(
            complexity_type = self.complexity_type,
            class_name      = self.__class__.__name__,
            complexity_fit  = self.compute_complexity_fit(),
            chaos_coverage  = self.compute_chaos_coverage(),
            ai_connection   = self.get_ai_connection(),
        )


class PComplexity(ComplexityTypeCHS):

class FourSphereComplexitySystem:
    """
    МВС = Элементарное правило / состояние
    СВС = Паттерн / аттрактор
    БВС = Сложная система / странный аттрактор
    ЧВС = Тип сложности (plug-in)
    """
    def __init__(self):
        self._body_frozen     = False
        self._active_type: Optional[ComplexityTypeCHS] = None
        self._n_lyapunov_exp  = enforce_odd(5, "n_lyapunov_exp")  # экспоненты

    def freeze_system_body(self):
        self._body_frozen = True

    def set_complexity_type(self, ctype: ComplexityTypeCHS):
        if not self._body_frozen:
            raise RuntimeError("Сначала вызовите freeze_system_body()")
        self._active_type = ctype
        ctx = ctype.get_context()
        print(f"[ЧВС SET] {ctx.class_name} | fit={ctx.complexity_fit:.2f} | AI={ctx.ai_connection}")

    def remove_complexity_type(self):
        removed = self._active_type.__class__.__name__ if self._active_type else "None"
        self._active_type = None
        print(f"[ЧВС REMOVE] {removed} отсоединён")

    def compute_4sphere_lci(self) -> Dict:
        if not self._active_type:
            raise RuntimeError("ЧВС не установлена")
        ctx = self._active_type.get_context()

        chaos_ratio      = self._active_type.chaos_order_ratio()
        complexity_fit   = ctx.complexity_fit
        chaos_coverage   = ctx.chaos_coverage

        odd_bonus = 0.07 if (self._n_lyapunov_exp % 2 == 1) else 0.0
        resonance  = chaos_ratio * odd_bonus

        lci_v1 = chaos_ratio
        lci_v2 = chaos_ratio * complexity_fit * chaos_coverage + resonance * 0.1

        return {
            'complexity':      ctx.complexity_type.value,
            'ai_connection':   ctx.ai_connection,
            'chaos_ratio':     round(chaos_ratio, 4),
            'complexity_fit':  round(complexity_fit, 4),
            'chaos_coverage':  round(chaos_coverage, 4),
            'lci_v1':          round(lci_v1, 4),
            'lci_v2':          round(lci_v2, 4),
        }

    def audit_9axioms(self) -> Dict:
        if not self._active_type:
            raise RuntimeError("ЧВС не установлена")
        ctx = self._active_type.get_context()
        axioms = {
            'A1': ('Детерминированность на бесконечно малом',      True),
            'A2': ('Чувствительность к начальным условиям',        True),
            'A3': ('Сохранение объёма фазового пространства (Лиувилль)', True),
            'A4': ('Существование аттрактора',                     True),
            'A5': ('Ляпунов: положительная экспонента = хаос',     True),
            'A6': ('Иерархия масштабов (МВС/СВС/БВС)',            True),
            'A7': ('Закон нечётности ляпуновских экспонент',       self._n_lyapunov_exp % 2 == 1),
            'A8': ('ЧВС complexity_fit >= 0.70',                   ctx.complexity_fit >= 0.70),
            'A9': ('ЧВС chaos_coverage >= 5/9',                   ctx.chaos_coverage >= 5/9),
        }
        passed = sum(1 for _, (_, ok) in axioms.items() if ok)
        return {'passed': passed, 'total': 9, 'score': round(passed/9, 3)}


if __name__ == '__main__':
    system = FourSphereComplexitySystem()
    system.freeze_system_body()
    print("=" * 65)
```
